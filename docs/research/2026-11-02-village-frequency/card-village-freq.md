# Карточка запуска: исследование частоты деревень Новгородской земли XII–XIII вв.

**Что и зачем.** Пункт 11 issue #985 «Поселения на карте» и строка 17 плана #906. Размер деревни известен (3–6 дворов у 70 % селищ северо-запада, X–XIII вв.), а расстояния между деревнями и плотности поселений нет ни в данных проекта, ни в найденных работах. Без этого генерация не знает, как часто ставить деревни вокруг Вихтуя. Владелец выбрал исследование (D366, вариант «а»).

**Как.**
1. Codex `gpt-6.1-sol` `high`, основной аккаунт на кредитах, режим «Ведёт sol» (исследование): сам делит работу и одобряет внутренние планы, стоит только на `DONE` или `Q`. Помощники — `gpt-6-luna` `xhigh`, до 3 одновременно: поиск по разным группам источников.
2. Сначала имеющееся в проекте: `data/world-catalogs/novgorod/sources/books-evidence-v1/*`, база WK, rus13, мастер-архив на servak, `codex-direct/land1230/raw/S3-web.tsv` (что уже искали). Потом внешние источники: археологические обследования Новгородской земли (Приильменье, Поозерье, бассейны Волхова, Ловати, Шелони, Мсты), карты селищ, «гнёзда» поселений, расстояния между селищами по рекам, плотность на км², писцовые книги конца XV в. — как поздняя опора с пометкой.
3. Выход — файл `RESEARCH-village-freq.md`: числа (расстояние между деревнями, плотность, размещение относительно рек и дорог, доля одиночных дворов) с источником (автор, работа, страница или URL, короткая цитата), уверенностью A/B/C/D и регионом и датой каждого числа; отдельный раздел — предложение для игры: сколько деревень и на каком расстоянии ставить вокруг Вихтуя и каким родным механизмом CDDA (`overmap_special` с `occurrences` или настройки городов региона, файл:строка снимка `0d8843f`). Плюс таблица источников `sources.tsv`.
4. Проверка — один проход Claude Opus `xhigh` по артефактам (D365): выборочная сверка чисел с источниками и вывода для игры. Скриптом — ссылки и полнота таблицы источников.

**Источник истины.** Числа — только из названных источников с цитатой; без источника — «нет данных», не оценка. Предложение для игры — вывод, помеченный как вывод.
