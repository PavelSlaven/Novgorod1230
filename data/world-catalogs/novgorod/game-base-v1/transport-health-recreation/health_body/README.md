# health_body — здоровье, тело, болезни, уход (candidate)

## Что здесь

- `health_entities.csv` — 54 сущности, агрегированные скриптом из верифицированной книжной доказательной базы (`../sources/book_evidence_transport_health_recreation.csv`, домен `health_body`, 68 фактов), включая специализированную монографию по медицине Древней Руси (book_id 728823). Состав по `kind`: роли лечения (лечец, резалник, мирской лечец, иноземные лекари — 6), народная практика (волхвы, знахарки, заговоры, наузы — 5, помечены `historical practice only, not medical advice`), баня и роды (5), болезни (лихорадка/огневица, проказа, эрготизм, утин — 6), травмы (рана мечом, побои, трепанация, охотничьи травмы — 4), уход (уход за ранеными/больными, княжеская милостыня — 3), эпидемии/мор, включая мор 1230 и 1237 гг. и мор в Полоцке 1092 г. (2 записи мор, famine отдельно), голод 1230–31 и холопство от голода (3), детство и взросление (постриг, посажение на коня, кормильцы — 4), демография (продолжительность жизни, палеопатология городского населения — 2), институциональная забота (монастырская больница, монастыри — 2), конский мор (1), прочее — Вопрошание Кирика, диета по месяцам, скудельница и др. (11).

## Метод

Идентичен `transport_travel`: `scripts/build.cjs` группирует книжные факты по `entity_ru`, строит `facts_summary`, `source_refs` (`book:<id> §<section> ¶<para>`), консервативную `confidence`. `kind` — классификация по регулярным выражениям (детерминированная). Поле `period_care_practice_note` заполняется правилом: если сущность относится к народной/языческой практике (волхвы, знахарки, заговоры, наузы), помечается «historical practice only, not medical advice» — это выполняет требование брифа «как историческая практика, не медицинский совет».

## Источники

- Книжная доказательная база: 54 сущности / 68 фактов, включая монографию по медицине Древней Руси (историко-медицинский раздел X–XIII вв., устав Владимира о церковных людях, «Вопрошание Кирика»), «Древняя Русь. Быт и культура» (баня, роды, детство, палеопатология). Верификация — `../sources/book_evidence.VERIFICATION.md`; отклонённых строк по домену нет.
- WK production-v1, упомянутые в брифе (не читались построчно в этой сессии, только имена файлов подтверждены наличием в `data/world-catalogs/novgorod/world-knowledge/production-v1/`): `biology-physiology.json` (476 approved), `reconstructed-human-lifeways-v1.json` — вероятный носитель `reconstructed-healer-practice-v1` и `residual-postpartum-v1` (точные id claim не сверялись, требуется точечный `rg` по claim id в следующем проходе).
- `temporal-v4 body_time_effect_profiles` (4, approved) — упомянут в брифе, не найден в скопированных `sources/`; вероятно живёт в основном checkout вне зоны чтения этой сессии (только `Novgorod-game-base` и явно перечисленные пути были read-only доступны).

## Пробелы (для владельца/следующего прохода)

- Нет структурированной таблицы `course_stages` (течение болезни по стадиям) и `season_risk` — книжные факты по большинству сущностей — единичное качественное упоминание (`fact_count` в основном 1), недостаточно для построения полной клинической картины по каждому состоянию; это авторский, не скриптовый пробел.
- `visible_signs` (требуется приёмочным правилом брифа «у каждого состояния есть visible_signs») не выделено отдельным полем — частично содержится внутри `facts_summary` (например, огневица/лихорадка, проказа — кожные признаки), но не нормализовано построчно.
- Мор 1230–31 гг. (голодный мор) присутствует как отдельные сущности «голод», «мор 1230 г.», «голод и холопство»; связь с WK `macro-universal-health-lifecycle-v3` и с временным правилом `novgorod_famine_1230` (упомянуто в critic_problems брифа как approved в temporal-v4) не проверялась — файл вне read-only зоны этой сессии.
- Ссылки `WK biology_physiology 476` не резолвились построчно (нет id-уровневого сопоставления сущность↔claim); задача для авторского прохода с доступом к полному WK claim registry.
