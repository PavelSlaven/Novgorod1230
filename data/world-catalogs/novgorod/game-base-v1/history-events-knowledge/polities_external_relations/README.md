# polities_external_relations — соседние державы и внешние отношения 1230–1250

Домен предложен критиком брифа (`critic_problems`), в каталоге ранее не было домена-владельца для этого
семейства WK (`diplomacy-tribute-and-external-relations`). Статус: **candidate**, не утверждено. Приоритет
брифа M3.

## Что это

`polities_external_relations.csv` (26 строк): политические образования и их отношение к Новгороду 1230–1250 —
Владимиро-Суздальская земля и князья, Псков, даннические периферии (Обонежье, Корела, Белозерье, Заволочье,
Важская земля, Емца, Двина, Пинега, Печора, Югра), монгольское нашествие, Ливонский орден, Дерптское
епископство, Швеция, Литва (Миндовг), Готский берег/Висбю и немецкие города, Любек.

## Источники и метод (три слоя, не сведённые в один)

1. **`po_region_*` (6 строк)** — черновик `rus13tpl novgorod_neighbor_regions_v1.json`: региональные
   периферии (Псков, Ладожско-Ижорская, Корельская, Заволочье, Белозерье, Владимиро-Суздальская), привязаны к
   графу v6, `confidence=C`.
2. **`po_periphery_t16..t25` + `po_pskov_land` (11 строк)** — `sqlite novgorod_1230(1).territories`
   (confidence B/C для даннических зон, A для Пскова T09), источники S05/S07/S08/S30.
   **Эти строки описывают частично те же сущности, что и слой 1** (Псков, Белозерье, Корела, Заволочье) —
   слияние в одну каноническую запись на сущность **не выполнено самостоятельно**, решение о приоритете
   источника (rus13tpl draft vs. sqlite curated) оставлено владельцу.
3. **9 внешних держав/акторов (`po_vladimir_suzdal_principality` … `po_lubeck_german_merchants`)** — новое для
   этого прохода. Опирается на:
   - уже собранные фигуры `historical_figures.csv` (Батый, Биргер, Герман фон Буксгевден, Андреас фон
     Вельвен, Миндовг, Ярослав Всеволодович);
   - `sqlite.sources[S02]` — реальный действующий договор Новгорода с Готским берегом и немецкими городами
     1191–1192 (confidence A, это прямой источник для `po_gotland_german_towns`);
   - **веб-поиск 2026-09-26 (4 запроса)** для настоящих разрывов (общеизвестные, но не собранные в каталоге
     факты): формирование Ливонского ордена в мае 1237 г. после разгрома Ордена меченосцев при Сауле
     (22.09.1236); княжение Ярослава Всеволодовича в Новгороде 1231–1236 и во Владимире 1238–1246 (умер
     30.09.1246); взятие монголами Торжка 5 марта 1238 г. и поворот войска у Игнач-креста (~100 км от
     Новгорода) без разорения самого города; спорное авторство шведского похода на Неву 15 июля 1240 г.
     (Биргер ярл называется источниками только с середины XV в., историки называют и ярла Ульфа Фасе).
     Все четыре факта процитированы построчно в `source_refs` с заголовком+URL.

## Известные ограничения

- **Дублирование сущностей** между слоями 1 и 2 (см. выше) — не устранено.
- **`po_denmark_estonia` и `po_lubeck_german_merchants`** включены по прямому требованию брифа
  («Дания (Эстляндия)», «Любек и немецкие купцы»), но без сфокусированного исследования конкретно
  новгородского эпизода 1230–1250 — `confidence=D`/`C` с явным `ПРОБЕЛ:` в `source_refs`, а не заполнены
  правдоподобной, но непроверенной конкретикой.
- **Дерптское епископство**: датировка самого епископства (1224 г. основания) взята из черновика
  `key_npc_seeds`, не подтверждена отдельным веб-поиском в этом проходе — `confidence=C`.
- **Кросс-проверка с `historical_events`** выполнена только выборочно (Ярослав, монгольское нашествие,
  Невская битва упомянуты как `event_refs`); систематической сверки дат между двумя CSV одним скриптом нет —
  оставшийся разрыв для follow-up (acceptance-критерий брифа требует «перекрёстная сверка … без противоречий
  по датам»; выполнено содержательно вручную для перечисленных случаев, не автоматизировано).
- Договоры/дань (`tribute_or_treaty_refs`) заполнены только там, где источник даёт конкретику (даннические
  зоны, договор 1191–1192); для большинства внешних акторов поле пустое, а не выдумано.
