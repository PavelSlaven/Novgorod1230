# services_hire_labor — услуги, наём и оплата труда (candidate)

Домен группы `economy-trade-measures`, коллектор `collect-economy-trade-measures`. Статус: **candidate**. Приоритет по брифу — M3, но собран сейчас как часть той же группы источников (одна проверка/один tsv покрывают price_bands и services_hire_labor одновременно).

## Что здесь

- `services.csv` (34 строки) — перевоз (человека, груза, лодка, сани, телега), ночлег (простой; с местом для коня/саней), еда в дороге, уход за больным/раненым, починка (обувь, кузнец, плотник, лодка), хранение товара/залога, корм/дрова/уголь/смола, простая одежда/обувь, свеча, церковное даяние и поминальная еда, монастырское гостеприимство, пошлина/сбор, труд (грузчик, покос, волок), передача вести, письмо/запись, залог/долг работой/долг зерном, поручительство/свидетель; плюс проводник (со ссылкой на правила отказа и обмана проводника) и отдельная строка — правовой статус наймита/закупа/рядовича со ссылкой на approved WK-claims по статьям 52-55, 59 Пространной Правды.
- `scripts/build_services.mjs` — детерминированный генератор из `tools/rus13-novgorod-regional-templates/novgorod_goods_prices_v1.tsv` (те же 65 строк, что и `price_bands`, но категории услуг, не товаров) + `novgorod_trade_rules_v1.json#exchange_forms` (закрытый словарь форм оплаты) + `novgorod_route_knowledge_rules_v1.json#guide_rules` + `wk:residual-law-norms-v1` (approved).

## Метод

1. `service_kind`, `provider_roles`, `value_band_ref`, `season_periods` — прямое отображение из tsv-категорий услуг (transport_service, service, service_lodging, food_service, service_care, medical, repair, repair_transport, storage_service, religious_service, ritual_food, lodging_religious, dues, labor, labor_transport, service_message, service_literacy, credit, credit_labor, credit_food, law_custom).
2. `payment_forms` нормализованы к закрытому словарю `exchange_*` из `novgorod_trade_rules_v1.json` (barter→exchange_barter, debt→exchange_debt, pledge→exchange_pledge, labor→exchange_labor, witness_backed_promise→exchange_witness, наличие серебра/монеты→exchange_silver_coin) — проверка скриптом «оплата только в формах из exchange_forms» (acceptance-критерий брифа) технически выполнима: все значения `payment_forms` — подмножество этого словаря.
3. `labor_relation_ref` заполнен только там, где есть прямая правовая основа: для `labor`/`labor_transport` — approved WK claims по закупу (статьи 52-55 Пространной Правды: ответственность зависит от обстоятельств утраты, а не автоматична; закуп не приравнивается к обельному холопу) + единственная прямая ставка оплаты труда, найденная в корпусе (городнику: 1 куна при закладке, 1 ногата при окончании, 7 кун корма в неделю — Правда Русская, confidence A). Для `service` (проводник) — правила `guide_rules` (может отказать, может обмануть при конфликте/выгоде/страхе). Отдельная строка `sv_naymit_zakup_status` фиксирует сам правовой статус (наймит/закуп/рядович) со ссылкой на approved claims, не смешивая его с конкретной услугой.

## Известные ограничения и gaps

- `value_band_ref` указывает на тот же закрытый словарь, что и `price_bands.csv`, но НЕ на конкретный `pb_id` этой группы (услуги не входили в скрипт дерива price_bands, у них нет famine/war/road-модификаторов в отдельной таблице) — если понадобится, можно позже сгенерировать `pb_service_*` строки тем же скриптом с минимальной правкой набора категорий.
- Ставки оплаты труда почти не засвидетельствованы источниками для рядового найма (грузчик, работник на покосе, волочанин) — единственная прямая цифра во всём собранном корпусе (244 книжные строки + tsv + WK + sqlite) относится к городнику (строительство городни, Правда Русская). Остальные `labor`/`labor_transport` строки несут только качественную `value_band_ref` из draft tsv (confidence C), не историческую ставку.
- «Волочане отвечают всей общиной за товар, погибший при перевозке через волок» (book-evidence, домен trade_goods_markets, не перенесено сюда как отдельная строка, но релевантно для `labor_transport`/`sv_labor_volok`) — оставлено как перекрёстная ссылка в этом README, не дублировано в CSV, чтобы не размывать источник между двумя доменами.
- Как и в `price_bands`, `tools/rus13-novgorod-regional-templates/novgorod_goods_prices_v1.tsv` сам помечен `status=draft`, `requires_human_historical_audit_for_exact_prices` — наследуется как confidence C для всех строк, кроме двух с прямой правовой/летописной основой (A).
