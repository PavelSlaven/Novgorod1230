# buildings — типы построек, части, облик поселения (candidate)

Домены: `buildings_structures`, `settlement_form`.

## Файлы и счёт (scripts/build.py)

| Файл | Строк | Что |
|---|---|---|
| `building_types.csv` | 51 | типы построек `bt_*`: класс, семейства мест, комнаты, размеры (только из источника), материалы, состояния, возраст, пожарный риск, кто живёт/работает, свет-дым-запах, охрана от анахронизмов |
| `building_parts.csv` | 73 | каталог частей `bp_*` с материалом по умолчанию и ограничениями (`elite_or_church_only`, `only_reconstruction`) |
| `building_type_parts.csv` | 288 | состав каждого типа: часть, материал, size_min/max + единица + источник размера, count_rule, required |
| `materials_vocab.csv` | 41 | словарь материалов `mat_*`, каждый со ссылкой на предмет matcult или claim WK |
| `settlement_form.csv` | 22 | формы: 10 дворов/комплексов (бедная, рядовая, ремесленная, купеческая, прибрежная, боярская усадьба, церковная, крестьянский двор, монастырь, иноземный двор), улица, конец, Торг, Детинец, деревня, село, погост, пристань, рыбный и охотничий стан, отдельный двор, посад |
| `settlement_building_mix.csv` | 112 | состав формы: `bt_*` или вложенная форма `sf_*`, count_min/max, правило, основание |

Уверенность типов: A 9, B 32, C 10. Пожарный риск: high 13, medium 18, low 20.

## Метод

1. Ядро — предметы архитектуры matcult (ARC/CON/INT/FOR/STR, 182 записи) и claims WK `architecture_settlement` (97 уникальных) и смежные.
2. Размеры — только из источника, дословно по диапазону: изба 16–80 м² (ARC0020), чаще 20–70 м² (nov1230db B028), стороны 4–9 м (ref:arhitekto_2russ27); пятистенок 40–100 м² (ARC0019); клеть 4–6 м (ARC0021); подклет ~1,5 м (ARC0022); мостовая 3,5–5 м, главные до 8 м; крупная усадьба 1200–1500 м² (nov1230db S11). Где источник размера не даёт — поле пусто, в `size_note` причина.
3. Проверка датировок: пятистенок — есть в Новгороде с XI в., до середины XIII в. основная владельческая постройка (ref:dissercat_ljudin, ref:rsl_zasurcev_search) → A; «изба XIX в.» остаётся анти-паттерном AP001. Подклет — конец XII – начало XIII в. Печь ~95% в углу (сводка по Засурцеву, B, первоисточник не прочитан). Овин — C (только аналогия WK). Водяная мельница — C (matcult: «осторожная»), основной помол — ручные жернова. Жальник — B (с XII в.).
4. **FIRE_RULE**: high — деревянная постройка с открытым огнём/жаром внутри; medium — деревянная без огня, но с горючим запасом (сено, солома, зерно, товар) или в плотной застройке; low — земля/камень/вода, без огня и большого горючего запаса.
5. Состояния: `under_construction|sound|worn|needs_repair|damaged|burnt_ruin|abandoned`; возраст `new|seasoned|old|decrepit` — качественно (циклы перекладки мостовых «каждые десятилетия», nov1230db B026; числового срока жизни дома в источниках нет).
6. Облик поселения: дворы — из сцен matcult (SCN001–009) и nov1230db; сельские формы связаны с черновыми типами v6 (`template_type_note`, `place_template_id`), тексты `household_estimate/household_mix` импортируются скриптом, а `validate.py` сверяет суммы count_min/max дворов с диапазонами v6 (деревня 7–18, село 16–43 + 1 церковный, отдельный двор 1–3).

## Приёмка (validate.py)

- каждая часть ссылается на материал из `materials_vocab.csv`; min ≤ max; у каждого типа есть части;
- у каждого жилого и хозяйственного семейства мест (22 семейства) ≥1 тип постройки;
- анахронизмы: стекло только `bt_horomy`/`bt_church_stone`, плинфа только в монументальных постройках, у всех жилищ охрана «нет дымохода», denylist по текстам;
- каждый `bt_id`/`sf_id` в составе существует; каждая форма связана с `place_template_id` v6; счёт дворов согласован с `household_mix`.

## Известные пробелы

- Не прочитаны: МИА 65 (Засурцев и др.) и Колчин 1968 — нужен OCR. Числа по печам и пятистенкам из сводки поиска (ref:rsl_zasurcev_search) нужно сверить с первоисточником.
- Материалы: словарь локальный (`mat_*`); нужен crosswalk на домены `natural_materials_soils` / `materials_registry`, когда они появятся.
- Нет количественного срока службы построек и частоты бань на усадьбе (источник прямо говорит «неизвестна»).
- Овин, плетень как сельская ограда, ушат, водяная мельница — C.
- Дворы и Торг не имеют численной площади, кроме крупных усадеб; размеры торговых рядов и пристаней не нормированы.
- В коде v17 на building_templates 0 ссылок — нужна проводка (CR), данные сами по себе не читаются runtime.
