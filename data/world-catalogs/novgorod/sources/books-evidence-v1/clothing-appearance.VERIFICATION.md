- Типовые проблемы:

  3. **Факты вне 1230 с period=c1230** (row 119 XIV–XV вв.; row 212 контекст XIV в.): note есть не везде, а period их не отражает.
  4. Опора на позднюю этнографию внутри научного текста (row 65, лапти) без пометки.
