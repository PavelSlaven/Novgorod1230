# sources — реестр источников группы crafts-tools-processes

`sources.csv` — 25 источников, на которые ссылаются колонки `source_refs` четырёх доменов группы. Поля: `src_id, citation, url_or_path, kind, base_confidence, used_for_ru`.

- `kind`:
  - primary_archaeology — первичная археология: Колчин 1959, Изюмова 1959, Рыбина 2015, Колчин 1968, Седова 1981, ИА РАН, Смирнова 1998, Дубровин 2000;
  - scholarly_secondary — научная вторичная литература;
  - museum — музей;
  - ethnographic_analogy — этнографическая аналогия;
  - physics_reference — справочники по физике и материалам;
  - repo_candidate, repo_policy — наборы из репозитория, которые ещё не утверждены.
- `base_confidence` — наивысшая уверенность, которую строка может получить от одного этого источника. Если число взято не из самой публикации, а из конспекта (МИА 65 через rezansky.com), строка получает B, хотя первоисточник — A.
- WK claims и concepts (`claim:*`, `wk:*`) в этот реестр не входят: это одобренные утверждения production-v1, их id проверяет `build.cjs`.

Не вошли и остаются пробелами: постраничная OCR-выборка МИА 65 и Колчина 1968, «Геология СССР» т. 1 (болотная руда, глины), Волгина 2024 (с/х орудия; есть в v5 как `src_novgorod_agriculture`, но не прочитана), Медведев 1966 (стрелы).
