# Факты из книжной библиотеки (books-evidence-v1)

Кандидатные факты для групп игровой базы `game-base-v1`, извлечённые из частной fb2-библиотеки владельца на удалённой машине (2026-09-26).

## Как получены

1. Каталог INPX (705 588 записей) → отбор по ключевым словам и жанрам без художественной литературы (8 898 книг) → лексический индекс FTS5 (2 359 книг, 3,77 млн абзацев). Полные тексты в репозиторий не попадают.
2. По каждой группе: сборщик → независимый проверяющий (выборка 33–52 строки, сверка с абзацем книги) → правщик по замечаниям → повторная проверка. Итог всех 19 групп — `approve_with_limits`. Отклонённые строки в репозиторий не перенесены.
3. Скрипт проверил каждую цитату: она буквально есть в указанном абзаце, длина не больше 200 знаков, одно предложение. Метаданные книги берутся из индекса. Анахронизмы отсеивает denylist.

## Файлы

- `<group>.csv` — факты группы. Колонки: `domain, entity_ru, entity_latin, fact_type, value, book_id, authors, title, year, section_path, para_no, quote, confidence, period, note, book_type, flags`.
- `<group>.VERIFICATION*.md` — отчёт независимого проверяющего.
- `<group>.FIXES.md` — что исправил правщик.

Ссылка на строку в данных: `book:<book_id> §<section_path> ¶<para_no>`.

## Ограничения

- Уверенность: A 520, B 4 450, C 120. Потолок уверенности по типу книги ставит скрипт; тип книги определяется эвристикой по жанру и автору, `archaeology_report` ненадёжен.
- `period = medieval_general` и `ethnographic_late` — только аналогии для 1230 года, не прямые свидетельства.
- Перекос на одну книгу: «Древняя Русь. Быт и культура» (book 624953) даёт 63–75% строк в clothing и items, book 622242 — 77% в crafts.
- В индексе нет подлинного текста НПЛ, отдельной книги Колчина, «Древненовгородского диалекта» Зализняка, новгородской археозоологии и археоботаники.
- Книги не дают весов обилия по местам, расписаний по часам, чисел для психологии NPC и цен изделий XIII века: это выводится по правилу или решается владельцем.
- Группа `places-binding` книгами не собиралась (все её домены — derive/rule).
