## 1. Топ-10 ловушек: где исполнитель вероятнее всего построит дубль

1. **Второй механизм сохранения.** Своё «поколение на каждую операцию», журнал `operation_id`, квитанции поверх родного `game::save()` (`src/game_io.cpp:734-783`). Родное: сохранение по запросу (`ACTION_QUICKSAVE`), выход с проверкой результата (`ACTION_SAVE`, `src/handle_action.cpp:2940-2951`), автосейв (`src/do_turn.cpp:607-612`). Чего реально нет — только копии каталога мира в «принятое поколение» после успешного `save()` и правила «раз в игровой час» (одна строка `calendar::once_every(1_hours)` у `do_turn.cpp:607`). См. [08:14-15,25](areas/08-save-state.md); решения владельца: D215 — сохранение по запросу игрока и раз в игровой час, D216 — откат к последнему целому сохранению; внутренний разбор механизма сохранения (вне репозитория, далее «разбор сохранения») сводит нужное к копии каталога мира и указателю current/previous.
2. **Своё хранилище данных на NPC/мире/предмете** (поля `novgorod_*`, sidecar JSON, отдельная БД) вместо `global_vals` (`src/global_vars.h`, пишется в `.sav` `src/savegame.cpp:164`), `Creature::values` (`npc_val`/`u_val`), `item_vars` (`talker_item::set_value` `src/talker_item.cpp:151`). Родные сохраняются тем же `save()` и попадают в то же поколение, что и физика — согласованность бесплатно. [08:16-18](areas/08-save-state.md), [09:14](areas/09-eoc-scripting.md).
3. **Своя шина событий или разбор локализованного лога.** Родное: `event_bus` + 110 `event_type` (`src/event.h:24-138`), EVENT-EOC через `eoc_events`, эффект `trigger_event` (`src/npctalk.cpp:8476`, в doc не описан), `u_var_changed` от `u_add_var`/`npc_add_var`. Новый тип события — только когда нет ни одного подходящего, и это правка `event.h`. [07:21-23](areas/07-narration-log.md), [09:11,22](areas/09-eoc-scripting.md).
4. **Вторые часы и «цена реплики» через `mod_moves(-300)`.** Родное: одни часы `calendar::turn` (пишет только `do_turn`), занятие с длительностью из JSON — `ACT_GENERIC_EOC` (`data/json/player_activities.json:1095`) + `u_assign_activity`/`npc_assign_activity` с `duration` (`src/npctalk.cpp:5673`, регистрация `:8631`), `based_on: time` не зависит от скорости. [01:10-12](areas/01-time.md), [10:24](areas/10-player-actions.md).
5. **Свой планировщик таймеров.** Родное: `run_eocs` + `time_in_future` (`doc/JSON/EFFECT_ON_CONDITION.md:2186`), `RECURRING`-EOC, `timed_events`, `item_wakeups` — всё сериализуется само. Предел: глобальные EOC считаются только на ходу аватара; новый `timed_event_type` — правка C++ (`src/timed_event.h:17-38`). [01:22](areas/01-time.md), [08:19](areas/08-save-state.md).
6. **Свой движок распорядка и жизни NPC.** Родное: `work_hours`, behavior tree `npc_needs`, `RECURRING`-EOC → `u_run_npc_eocs` (с `unique_ids` достаёт NPC вне пузыря) → `npc_set_goal`/`npc_set_guard_pos`/`npc_assign_activity`; поход `NPC_MISSION_TRAVELLING`; лагерные миссии компаньонов как «работа за экраном». [02:11-16,22-23](areas/02-npc-life.md), [06:27-28](areas/06-movement-world-map.md).
7. **Второй бросок проверки.** Родное: `talk_trial` (LIE/PERSUADE/INTIMIDATE/SKILL_CHECK/CONDITION), бросок попадания `normal_roll(accuracy*5, 25)` (`src/melee.cpp:2963`), `crafting_success_roll`. Видимый d20 — только обёртка `rng(1,20)` в EOC, не замена родного расчёта (план среза :182 это прямо запрещает). [04:57-60](areas/04-combat-checks-states.md), [09:17](areas/09-eoc-scripting.md).
8. **Свой реестр идентичности и свойств вещей.** Родное: `item_uid` (копия получает новый uid, move переносит — `src/item_uid.h`; счётчик `next_item_uid` в `master.gsav`), `item_vars`, поля `Item_modifier`, `faction_owner` в mapgen. [05:19-22](areas/05-items-crafting.md).

[07:9,18-20,24](areas/07-narration-log.md), [03:23-24](areas/03-conversation.md), [05:29](areas/05-items-crafting.md).

Прочие ловушки (не дубли, но ломают): событие `game_save` уходит **до** записи файлов (`src/game_io.cpp:744`) — это не «сохранено»; EOC с глубиной вызовов > 5000 вызывает `query_yn` (`src/effect_on_condition.cpp:361-362`) — в безоконном запуске повиснет, EVENT-EOC, шлющие событие своего же типа, делать с условием остановки; `quicksave()`/`autosave()` возвращают `void` и после сбоя продолжают ход ([08:12-14](areas/08-save-state.md)); `game::draw` при `test_mode` сразу выходит (`src/game.cpp:3364`); опция `FOV_3D_Z_RANGE` удалена.

## 4. Чего в CDDA нет: кандидаты на новое (с доказательством в областях)

Сначала проверить обходной путь из столбца «как расширять» области; новое — только если он не годится.

- **Вход действий извне и безоконный режим.** Нет инъекции ввода, RPC, сокета; флаги `src/main.cpp` — только `--seed`, `--jsonverify`, `--check-mods`, `--world`, каталоги и т. п. (проверено Opus). Есть dummy-SDL фикстура тестов (`src/sdltiles.cpp:2389-2399`), тесты зовут `avatar_action::*` напрямую. Нужен тонкий C++-шов. [10 §4](areas/10-player-actions.md), [11 §4](areas/11-ui-display.md), [09 §4](areas/09-eoc-scripting.md).
- **Свободный текст → действие, групповой разговор, свободная реплика.** Ответы только из `responses`, `dialogue` — пара talker↔talker. Слой LLM Новгорода. [03 §4](areas/03-conversation.md), [10 §4](areas/10-player-actions.md).
- **Типизированные события «сказал / поднял / бросил / осмотрел / открыл / ждал».** В `event_type` нет; обход — `trigger_event` с существующим типом или `u_var_changed`; новый тип — правка `src/event.h`. [07 §4](areas/07-narration-log.md), [10 §4](areas/10-player-actions.md).
- **Модель знания:** слухи, provenance, личные связи NPC↔NPC, секреты с порогом. Есть только хранилища (переменные) и мнение NPC об игроке / отношения фракций. [03 §4](areas/03-conversation.md), [02 §4](areas/02-npc-life.md).
- **Жизнь NPC и хозяйств вне пузыря дольше 2 суток, групповые решения, домохозяйства.** Catch-up зашит `std::min(…, 2_days)` (`src/npc.cpp:3584`, проверено Opus). [02 §4](areas/02-npc-life.md), [01 §4](areas/01-time.md).
- **Время:** доли секунды; дата 1230 и юлианский календарь (секунды в `int`, год 4 сезона, неделя от четверга); разные солнце и погода по регионам одновременно; очередь событий вне хода аватара. [01 §4](areas/01-time.md), [12 §4](areas/12-mods-data-loading.md).
- **Сохранение:** вызов save из EOC (проверено Opus: среди вызовов `quicksave` EOC нет), установка опций из EOC, автосейв раз в игровой час опциями (`AUTOSAVE_TURNS` 10..1000, `src/options.cpp:1729`, проверено Opus), атомарный набор файлов / поколения / fsync / бэкапы, результат автосейва наружу. [08 §4](areas/08-save-state.md).
- **Предметы:** новый itype во время игры (проверено Opus: `Item_factory::add_runtime` даёт голый тип с именем и описанием для `DEBUG`/`undefined-` заглушек, `src/item_factory.cpp:3041-3054,3082,3086`; загрузка JSON после `finalize` запрещена `src/init.cpp:555-556,589-590`); свободный крафт без рецепта; контроль баланса массы; владелец вне фракций; `pre_specials`/`post_specials` строительства из JSON. [05 §4](areas/05-items-crafting.md), [12 §4](areas/12-mods-data-loading.md).
- **Карта:** сферическая Земля, ±180°, полюса; путь дальше `4 * OMAPX` (`src/overmapbuffer.cpp:1119`, проверено Opus) — обход сегментами; сила течения и волок; лёд в цене пути overmap; обоз как одно тело; стамина верхового; точная постановка special по координате из JSON. [06 §4](areas/06-movement-world-map.md).
- **Экран и журнал:** структурный экспорт видимых клеток; обновление памяти карты без отрисовки; id и источник у записи лога, push о новом сообщении, полный `time_point` наружу, флаги приватности; фильтр описаний по знанию игрока; публичное чтение мемориала. [11 §4](areas/11-ui-display.md), [07 §4](areas/07-narration-log.md).
