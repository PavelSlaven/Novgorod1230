# Идеи на потом

После первого полноценного региона владелец отдельно определит порядок новых направлений. Этапы 3–9 пакета D275 уже составляют утверждённую последовательность первого региона; прежние кандидаты ниже сохранены для прослеживаемости и не заменяют её. Кандидаты вне этой последовательности, в частности армии и другие старты, идут после первого региона; генерацию картинок (лицо героя, местность, NPC) владелец относит ближе к демо ([D304](decision-log.md)). ([D276/3](decision-log.md); [D275 §9](../plans/Novgorod1230_Approved_Design_37_Decisions_and_Implementation_Plan_2026-10-22.md))
