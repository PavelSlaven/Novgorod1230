# Условный двор мастера — dev fixture

Небольшая сцена для проверки живого CDDA: деревянная дверь, стол, один NPC и родные предметы `flint_steel`, `tinder`, `firewood`, `stick`. Это вымышленный двор возле Новгорода, не реконструкция города XIII века и не production world catalog. Вне стартового тайла остаётся обычный мир CDDA.

Мод подключается родным `MOD_INFO` (`data/mods/dda/modinfo.json`, `src/mod_manager.cpp:190–223`). `overmap_special`, `overmap_terrain`, `mapgen`, `start_location` и `scenario` задают место старта (`src/start_location.cpp:289–310,476`); `mapgen.place_npcs` создаёт NPC (`data/mods/aftershock_exoplanet/maps/mapgen/prepnet_orchard.json:71`). `flint_steel` использует штатный `firestarter` и требует трут (`data/json/items/tool/fire.json:70`). Новых C++-механизмов сцена не вводит.

Для первого мира: поместить каталог мода в `data/mods` изолированной native runtime, открыть CDDA с отдельным `--userdir`, создать новый мир через родное меню (`src/main_menu.cpp:1173`) с прежними `dda` и `test_data` плюс `novgorod_dev_world`, выбрать сценарий «Двор плотника», затем сохранить игру штатным действием CDDA (`src/handle_action.cpp:2940,2953`, `src/game_io.cpp:734`). Только полученный через родной `game::save()` каталог мира годится как initial fixture для launcher. После проверки fixture повторные запуски открывают тот же save; изменение мода не переписывает уже созданный мир.
`test_data` помечен obsolete и в родном списке модов не показывается; новый мир получает его из родного списка модов по умолчанию `config/user-default-mods.json` с `dependencies` `["dda", "test_data", "novgorod_dev_world"]` (`src/mod_manager.cpp:195-201,310-326`, `src/worldfactory.cpp:84`). Аватар стартует снаружи у закрытой двери комнаты (`ALLOW_OUTSIDE`), мастер и вещи внутри.

Структурная проверка JSON не доказывает, что CDDA выбрал нужный тайл, выдал подходящее снаряжение и сохранил NPC. До использования fixture нужен `--check-mods novgorod_dev_world` и интерактивный запуск с проверкой карты, одного NPC, предмета, двери, native save/reload. Проверка исторической достоверности отдельно; здесь она не заявлена.

Видимые игроку строки мода — по-русски прямо в JSON. Мастер — шаблон-персона `novgorod_dev_master` («Жирко», `gender`, `personality`, фракция `novgorod_dev_master_household`); `place_npcs` ставит его один раз через `unique_id`, `faction_owner` отдаёт фракции мастера все вещи тайла. `items.json` переопределяет русские названия родных вещей сцены через `copy-from` того же id; механика вещей не меняется. Так же переопределён `stick_common`: сцена его не ставит, но родной мир кладёт его рядом, и NPC видит вещь в кадре.
