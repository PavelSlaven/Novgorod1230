## Метод

1. Скрипт `_shared/scripts/extract-g4-index.mjs` читает (read-only) `pr98:data/world-catalogs/novgorod/m2c-natural/nature-successor-candidate-v2.json` и пишет компактный индекс 32 G4 (`_shared/g4_nature_index.json`: шаблоны ландшафта и воды, классы слоёв, члены пула, применимость слоёв).
2. Ландшафтные и хозяйственные шаблоны выгружены из `world_db` (`_shared/*.world_db.tsv`, draft).
3. Авторские данные — в `authoring/` (`soils.mjs`, `materials.mjs`, `tools.mjs`, `sources.mjs`). У каждого материала есть явное правило `lt()` по атрибутам шаблона (группа, тип грунта, влажность, растительность), правила по функции G4 и повышение класса, если в G4 есть член пула (например, `Salix` → ивовые прутья «common»).
4. `scripts/build.mjs` выводит все таблицы. `scripts/check.mjs` проверяет приёмку.

**Правила, а не придуманные числа:**
- класс частоты → вес 8/4/2/1 (соглашение каталога);
- запас на сгенерированное место: `порции = вес(класс) × 25`. База 25 откалибрована так, что ubiquitous = 200 = наибольший бюджет v17 (`m2c_finite_standing_wood_v1`). Итог: ubiquitous 200, common 100, contextual 50, rare 25. У воды запас не ограничен, пока существует водоём;
- порция — одна ручная ноша для указанного инструмента. Масса порции задана редакторски (C). Для валежника, плавника и тростника сохранена единица v17 (item = 50 г), чтобы не менять контракт;
- сезон: зимой копка закрыта. Основание: почва промерзает в среднем на 56 см (18–105), устойчивый снег лежит примерно с начала декабря до начала апреля (по григорианскому календарю). Весной на пойме доступ ограничен половодьем. Даты — в `../weather_climate/seasonal_phenomena.csv`;
- у G4 без растительных слоёв (открытая коса или отмель) растительное сырьё исключено;
- на могильнике (`zaostrovye_burial_area`) копка минерального сырья помечена как `restricted`, в поселении — как `ownership check`. Право решает владелец прав (`@rus/social-law` / property), а не этот датасет.

## Приёмка (скрипт `check.mjs` — OK)

- У каждого из 32 G4 есть ≥1 грунт и ≥3 природных сырья (минимум — 5).
- `stock_portions` пересчитывается по формуле для всех 258 + 360 строк.
- Сезонный доступ согласован с календарём: копка (минеральный грунт, торф, руда) зимой `closed`.
- У каждой строки есть `source_refs` и уверенность A/B/C. Все 1723 WK-утверждения проиндексированы; каждая ссылка `wk:claim:*` существует.
- Id уникальны, анахронизмов по `_shared/anachronism_denylist.json` нет.

## Проверка по известняку (Волхов)

Ордовикский плитчатый известняк выходит в **нижнем** течении Волхова и по Балтийско-Ладожскому глинту (район Старой Ладоги). Его нет в пойме Ильменя–Волхова, где лежат аллювиальные глины, пески и галька. Ни один из 7 ландшафтных шаблонов 32 стартовых G4 не даёт выхода известняка, поэтому `nm_limestone_slab` имеет `scope = universal_category_site_specific_presence` и присутствие 0 во всех шаблонах. Для конкретного места нужен флаг в `presence_rules`. Храмовый камень закупался в каменоломнях (Булкин, Антипов 2017).

## Известные пробелы

- **Геология СССР, т. 1** (`Downloads/geokniga-sssr-tom-1-…pdf`, скан, нужен OCR) не прочитана. Там первоисточник по глинам, пескам, болотным рудам и торфу области.
- Не подтверждены источниками (стоит C с примечанием): торф как топливо в 1230 г. (скорее не использовался); мох в пазах срубов (WK подтверждает только паклю — нужна страница Засурцева, МИА 123); дубление корой; ил для обмазки; «осмол» как промысел.
- Местные точильные камни и жернова не найдены.
- Липа (`Tilia`) в стартовых G4 не указана, поэтому лыка на старте нет — это честное следствие данных.
- Массы порций редакторские (C). Возобновление (`renewal`) — только класс; скорость пополнения остаётся за владельцем `party_resource_nodes`.
- Связь `pf_id` не заполнена: домен `place_families` делает другой сборщик. Привязка идёт через `landscape_template_id` и точный `g4_ref`.
