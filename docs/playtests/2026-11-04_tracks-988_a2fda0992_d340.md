## Findings

Первый вход в создание персонажа не состоялся из-за отсутствующего
завершающего `/` в аргументе `--datadir`; лог сохранён как
`.t988/out/logs/live-native-game-01.log`. После исправления аргумента
использован новый процесс. Неудачный запуск не считается игровым прогоном.

Родная команда Force temperature меняет `forced_temperature`, используемую
температурным getter, но накопление снега использует отдельную
`weather_manager::temperature` (`src/weather.cpp:1130`, `:1188`);
при тёплой погоде снегопад не доказывает наличие покрова. Погода движка
и календарь ради проверки не исправлялись.

Попытки debug-spawn `mon_rabbit` дали `Spawned 0`: исполнитель ошибочно
принял запись `MONSTER_BLACKLIST` за допуск. Родной tracker отклоняет
чёрный список, поэтому неудачные попытки не доказывают дефект следов.
Для следующего setup выбран `mon_hare` из `MONSTER_WHITELIST`.

Процесс 05 завершился после истечения собственного 1800-секундного
timeout Xvfb (exit 124); game/xterm потеряли X server. Это не штатный

### Исправление преобразования травы

Чтение сохранённых текущих снимков выявило 0 клеток `t_null` в
`after-process05-quicksave`, 23 в `rain-31m01-process07`, 25 в
`snow-31m-process08` и 48 в `dry-final-process12`. Последний checker
сообщает 24 диагностики: он выводит начало каждого RLE-фрагмента,
поэтому число диагностик не равно числу клеток. Все 48 конечных клеток
ранее содержали `t_grass`. Логи — `q05-current-origin-timeline.log`
и `q05-current-null-predecessors.log`. По этим снимкам нельзя установить,
какое конкретное существо изменило каждую из 48 клеток.

Причина воспроизводится отдельным родным вызовом выпаса. `ter_t::load`
в `src/mapdata.cpp:1378–1380` не наследует `transforms_into` при
`copy-from`; отсутствующее значение становится `t_null`. Родной
`mattack::graze` в `src/monattack.cpp:553–554` использует именно это
значение. Новые self-overrides трёх видов травы теряли штатные цели.
В разрешённом `footprints.json` явно сохранены `t_grass_grazed` для
`t_grass`, `t_grass` для `t_grass_long`, `t_grass_long` для `t_grass_tall`.
