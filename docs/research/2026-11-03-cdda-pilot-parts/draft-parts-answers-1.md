# Решения распорядителя по противоречиям черновиков частей 3–5 (03.11 14:20Z)

Вносятся в задание части при её запуске, текстом в разделы, к которым относятся.

1. **Часть 3, следы ласки у овина против запрета следов (#988).** Тот же вопрос, что п. 2 ответов поля: решается после DONE природного слоя, по тому, как её проверка допустила механизмы 8–9. До решения строка следов в задании части 3 — «не ставить (#988)».
2. **Часть 4, пастух C0294 против «не ставить людей».** Раздел плана «Что» требует скот на выгоне, а не человека; пастух в списке элементов каталога — ссылка. Люди окрестности идут через NPC (#985 «люди за делом»). Часть 4 пастуха не ставит; строка задания — «пастух — #985, не в этой части».
3. **Часть 4, скот: `place_monsters` с id существ против id группы.** Это один родной механизм. Форма — по разведке (`scout-part4.md:60`): группа существ мода с `mon_cow`, `mon_sheep`, `mon_horse` через `place_monsters`; каждое животное — отдельное существо (D296).
4. **Часть 4, «прясло».** Изгородь поля и выгона — один объект: тот, что поставит часть 2 (каталог C1855, название дословно из столбца «название»). Нового имени «прясло» и второго объекта нет.
5. **Часть 4, стог: родной `f_hay`.** Исполнитель читает в `ru.po` русское имя и описание `f_hay`. Если оба подходят стогу на лугу 1230 года (нет прессовки, шпагата, машин) — ставится родной `f_hay` без копии. Если описание не подходит — `copy-from f_hay` с именем «стог» и описанием по каталогу C2901, как в плане.
6. **Часть 5, зарастание лядины.** Срез — один день, 20 августа 1230 года; многолетней смены по ходу игры нет. Лядина ставится в нынешнем состоянии (зарастающая вырубка: подрост и травы — родными объектами по разведке). Превращение `transforms_into` в этой части не делается.
