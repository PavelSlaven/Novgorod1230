## 2. Родные механизмы области, которые наши документы ещё не упомянули

- `dialogue::apply_speaker_effects` (npctalk.cpp:1872) и `json_dynamic_line_effect` с `sentinel` (:9383, :9390–9395): эффект выполняется при показе реплики один раз за разговор. Годится для «NPC вспомнил/узнал» в момент реплики.
- Типы `talker` (talker_npc, talker_character, talker_avatar, talker_monster, talker_furniture, talker_item, talker_vehicle, talker_topic, talker_zone): разговор и условия работают не только с NPC; `talker_npc::will_talk_to_u` talker_npc.cpp:84 — единая точка отказа от разговора (talker.h:122).
- Параметр `radio_contact` в `avatar::talk_to` (npctalk.cpp:1666) и присвоение `dialogue_by_radio` (:1677): разговор на расстоянии без присутствия — готовый канал для вестей.
- `repeat_responses` (`for_item`, `for_category`; NPCs.md:877–897) — меню из предметов (торг по предметам, выкуп).
- `u_buy_monster`, `add_debt`, `u_bulk_trade_accept` (NPCs.md:938–956) — не только предметная торговля.
- `calc_npc_owes_you`/`update_npc_owed` (npctrade.cpp:264/284): долг NPC перед игроком — родной механизм «услуга за услугу».
- `EOC_camp_rumor_spread` (`data/json/effects_on_condition/misc_effect_on_condition.json:204`) — единственный родной «слух»: одно `u_message`. Шаблон, не модель.

- Теги `<u_val:VAR>`, `<npc_val:VAR>`, `<context_val:VAR>`, `<global_val:VAR>` в тексте реплик (`parse_tags`).
- Math-функции для условий и эффектов: `npc_trust/anger/fear/value` (math_parser_diag.cpp:1960–1963), `faction_like/respect/trust/food_supply/wealth/power/size` (:1904–1909), `price`/`price_postapoc` (:1938–1939), `event_statistic`.
