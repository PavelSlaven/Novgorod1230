## 1. Итог

1. **Н1, Н2.** Вход ответчика раскладывают под кэш префикса: неизменные блоки (личность, правила, формат, список действий отдельной точкой кэша) — в начале, изменчивое этой реплики — в последнем сообщении; окно истории начинают с «якорного» события, номер которого кратен шагу, чтобы начало истории не сдвигалось на каждой реплике (SkyrimNet). Это прямое решение для #827 и дополнение к образцу D357 правилом для истории.
2. **Н1.** Рабочие промпты NPC малы: шаблон Mantella около 200 токенов плюс биография (медиана около 300), порог для собранного system — 45 % окна с заданным порядком сброса; у мода 194492 system — около 2 тыс. знаков (≈500 токенов, оценка). Наш образец D357 (порядка 1,5 тыс. токенов по его же подсчёту, `npc-prompt-plain.md` строка 125) в том же классе.
3. **Н3.** Модель зовут последней, после каскада кодовых «ворот»: не идёт ли уже ответ, кулдаун, предусловия мира, есть ли из чего выбирать (NarrativeEngine); события мира сами модель не зовут, а копятся до ближайшей реплики (Mantella). Ложится на эскалацию #966.
4. **Н3, Н6.** Решения — отдельными малыми запросами: модель выбирает из вариантов, перечисленных кодом, и вариант «никто / ничего» есть всегда (SkyrimNet). Для #966: эскалация — выбор из разрешённых сейчас родных действий CDDA плюс «ничего не делать».
5. **Н6.** Список допустимых действий строит код на каждый момент; модель дописывает одну строку действия после речи; неизвестное действие отвергается, один повтор, потом отказ; после ответа код заново проверяет условия мира; исполняет код, а итог или отказ возвращается NPC событием (SkyrimNet, CHIM, NarrativeEngine, Mantella-Spell). Наш закрытый словарь уже есть в движке — родные эффекты диалога CDDA (`src/npctalk.cpp:8777-8847`).
6. **Н5.** «Deterministic» мода 194492 — детерминированный проверяющий код вокруг «недоверенного предложения» модели: состояние квеста меняет только код, по пересечению «что заявила модель» и «что разрешает политика»; текст речи не проверяется ничем. Ни один из семи проектов не проверяет опору сказанного — наш аудитор опоры остаётся своим.
7. **Н7.** В вход идёт только изменение (место, время, погода, состав людей рядом, новые события, по умолчанию не больше 5), однородные события склеиваются (удары — по источнику, бой — списком целей), реплики помечены «сказано тебе» или «подслушано» (Mantella, Mantella-Spell, SkyrimNet). Родная склейка повторов есть в журнале сообщений CDDA (`src/messages.cpp:142`).
8. **Н8, Н4.** Допуск NPC к знаниям решает код без модели: у статьи знаний — классы, у NPC — теги, есть запрещающие классы и три уровня «подробно / кратко / отказ», во вход — не больше 3 статей (CHIM, подсистема Oghma). Устройство переносится на наши знания мира по сословию, ремеслу и месту.
9. **Н4.** Память NPC — личные записи от первого лица с типом, важностью и игровой датой; во вход — одна или несколько отобранных записей, выбор кодом (CHIM) или моделью с обязательным «ничего» (SkyrimNet); итоги разговоров помечены игровой датой (Mantella).
10. **Н2.** Измеренной задержки почти нигде нет. Единственные числа — у автора мода 194492 (дообученная Gemma около 2B, system ≈500 токенов): медиана 0,98 с, но P95 по его же CSV — 4,9 с, а не 1,25 с, как в README. Общие меры: потоковая выдача, вывод по предложениям, `max_tokens` 250 по умолчанию и стоп-токен, вызов функций (tool calling) выключен по умолчанию, потому что замедляет ответ (Mantella, PR #692).
11. **Н8, Н2.** Знания по теме кодом: постоянные записи плюс записи по ключевым словам последних сообщений, с бюджетом в токенах, привязкой к персонажу и «липкостью» на N сообщений (SillyTavern, World Info). Урок для образца D357: у SillyTavern сработавшие знания и итог стоят в начале промпта и при смене темы ломают кэш префикса (issue SillyTavern #5852 просит обратного); знания по теме — в конец («Сейчас») или дописыванием в «Что было», а в «Что ты знаешь» — только ядро.

## 5. Чего не брать вообще

1. **Речь без проверки опоры.** Все семь проектов отдают речь модели игроку без проверки фактов: SkyrimLLMBridge проверяет только непустоту, Mantella и SkyrimNet — инструкции, CHIM — фразы «я ИИ». Нарушает нашу норму опоры сказанного (Н5).
2. **Кодовые заглушки вместо ответа.** «I cannot speak right now.» (`REPOS\SkyrimLLMBridge\bridge.py:199-211`), «I can't find the right words at the moment.» (`REPOS\Mantella\src\output_manager.py:482-484`), подмена текста сообщением об ошибке (CHIM). У нас запрет кодового запасного ответа (#220).
3. **Модель выдумывает людей и события мира.** Game Master SkyrimNet строит сцены из 4–6 шагов (`REPOS\SkyrimNet-GamePlugin\plugins\skyrimnet\base\prompts\gamemaster_scene_planner.prompt:1-50`), CHIM умеет действия «создать предмет / NPC» (`REPOS\CHIM-HerikaServer\functions\functions.php:17-70`), NarrativeEngine пишет письма и визиты свободным текстом. Противоречит «committed world не переписывается» и правилу «не придумывай людей, места, события» образца D357.
4. **Код выбирает поступок за NPC.** Подстановка первого варианта при плохом ответе (`REPOS\NarrativeEngine\src\PlotPlanning.cpp:1216-1228`) и перечисление фраз игрока под действия (`REPOS\Mantella\src\game_manager.py:191-214`) — превращают игру в набор заранее перечисленных случаев (формула проекта), а первое ещё и решает за NPC вопреки норме (#966, п. 4).
5. **Вызов модели по таймеру при неизменной обстановке.** Оценка раз в 90 с (NarrativeEngine), самопроизвольные реплики по вероятности без перехода (CHIM «скука»). Противоречит D352: типовую реакцию даёт код, модель — только эскалация.
6. **Молчаливая правка и пропуск.** Пропуск заявки вне политики без следа (`REPOS\SkyrimLLMBridge\llm_reply_processor.py:127-129`), чистка текста речи постфактум (Mantella), отправка действия без проверки, что оно есть (Mantella-Spell), чистка ответа без следа (SillyTavern). У нас каждый отказ виден в журнале и ведёт к repair или отказу хода.
7. **Облачные и чужие модели в игре, дообучение.** Скриншот в облачную модель зрения (Soulgaze AIFF, пост Reddit), облачные провайдеры SkyrimNet и NarrativeEngine, дообучение Gemma (SkyrimLLMBridge). У нас в игре — только локальная Qwen; смена модели — решение владельца.
8. **Раздутая постоянная часть ради озвучки.** Формат ответа и аудио-теги SkyrimNet — около 6 тыс. токенов; у нас текстовая игра.
9. **Английский промпт.** Все проекты; у нас правила по-русски (D289).
