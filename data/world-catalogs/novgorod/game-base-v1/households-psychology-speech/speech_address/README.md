# speech_address — речь, обращения, этикет (candidate, priority M3)

Таблицы генерирует `../scripts/build.py`, проверяет `../scripts/check.py`.

## speech_registers.csv — 71 строка (по одной на роль), confidence C (rework 2026-09-26)

`register` ∈ {`formal_literate`, `plain_oral`, `everyday_oral`}.

**Была сломана.** `literacy_expectation` — шаблонный текст, одинаковый на
всех 71 строках («низкая по умолчанию; выше у элиты, церкви, писцов и
купеческих доверенных»). Старое правило искало «выс»/«низ» в этом
константном тексте, что срабатывало на каждой строке одинаково, и реально
решало вопрос только через `social_rank`-фолбэк — из-за чего
`nov_role_church_scribe`, `priest`, `deacon`, `igumen`, `merchant_clerk`
получали `plain_oral` (хотя сам шаблон называет их грамотными), тысяцкий
получал `plain_oral`, а `everyday_oral` не выпадал вообще ни разу.

**Новое правило** (`build.py:literacy_register`) читает именно те именованные
группы-исключения, которые сам шаблон называет (элита, церковь, писцы,
купеческие доверенные), и матчит роль по `social_rank ∈ {elite,high}`,
`role_group = церковь`, или `role_title`/`historical_term` содержит
писец/дьяк/приказчик/доверенный → `formal_literate`; `social_rank ∈
{low,dependent,outcast}` → `plain_oral`; иначе → `everyday_oral`. Результат:
22 formal_literate / 36 plain_oral / 13 everyday_oral (было: 4 / 67 / 0).

Это остаётся подстановкой за отсутствующее в TSV поле
`typical_speech_register`, упомянутое в брифе, — его на самом деле нет ни в
`novgorod_occupations_v1_enriched.tsv`, ни в `novgorod_social_roles_v1_enriched.tsv`
(проверено grep по обоим файлам, 0 совпадений).

## address_forms.csv — адресные формы и явные пробелы D-3

64 строки: засвидетельствованные варианты и явные пробелы. `channel=written` содержит «Поклон от…», «От X к Y», «Грамота от X к Y», «Приветствую тебя», письменные «Господин брат» и «госпожа моя». Они не покрывают устную речь. `channel=oral` содержит, среди прочего, «Господин», «господине», «Господине мой», «Дети мои», «Братия», «княже» и «Владыко». Книжный топос и перенос формы на другую пару ограничены confidence C. `form_gospodine` и `form_bratie` восстановлены после удаления в D-3; прежняя общая форма «братие» заменена источниковой «Братия» (`book:641352 §278`). Это допустимые варианты, а не обязательные формы по статусу.

Для 22 пар субъектов, выведенных из 16 стартовых PF и G5-привязок, проверены 44 направления. Устная форма имеется лишь там, где свидетельство поддерживает её применение; остальные направления имеют точный `no_source`. Пустые роли в строках коллективной или письменной формулы не считаются покрытием пары. Названное отношение между конкретными NPC должно быть установлено отдельно.

Пробелы по устному обращению соседей, товарищей у перевоза/берега/леса, к попу и к торговцу: проверены собственный `sources/books-evidence-v1/households-psychology-speech.csv`, соседние `occupations-activities.csv`, `transport-health-recreation.csv`, `social-strata-law.csv`, WK `production-v1/reconstructed-public-world-v1.json` и `residual-language-education-v1.json`, а также MASTER `normalized_source_tables/occupations/{professions,activities,economic_links}.csv`. Нужная словоформа для этих конкретных направлений не подтверждена; соответствующие строки остаются `no_source`.

## Гэпы (существенные — fill_method=research не выполнен)

- Корпус берестяных грамот (gramoty.ru) не собран построчно в этом проходе:
  ни одна из ~1100 новгородских грамот не прочитана и не сопоставлена с
  формулами обращения. Бриф явно требует этот источник как основной (A).
- WK `residual-language-education-v1/v2` (approved) не прочитан в этом
  проходе.
- rus13tpl `name_pools status_based_address` (5, draft) не найден/скопирован
  в `sources/` для этой группы и не использован.
- Приветствия, прощания, клятвы, благословения, брань и её правовой вес —
  не покрыты вообще (0 строк).
- Языки общения с иноземцами — не покрыты (в брифе упомянуты, есть
  costume `foreigner_profiles.csv` в скопированных источниках, но он не
  прочитан в этом проходе).

**Итог:** этот домен собран только частично; критик в задании уже отметил
(gaps_ru), что каталог не ссылается на WK-семейство everyday-literacy
(partial) — это подтверждается. Следующий проход должен явно открыть
берестяно-грамотный корпус (см. BOOK EVIDENCE / gramoty.ru в задании) прежде
чем помечать домен готовым к M3.
