## Один следующий шаг

Заморозить production prompt и вход; прогнать **неизменённый** `input.private.json` один раз через фактический provider/role-runner target model с его JSON response mode и параметрами, записать raw response и независимо оценить по тем же четырём критериям. Это первая проба, снимающая confound «coding agent притворяется runtime writer» и проверяющая реальный delivery boundary. Если target недоступен, честно оставить причину неустановленной; результаты surrogate agents годятся для поиска гипотез, не для выбора production prompt. Следующую paired A/B prompt-пробу на той же модели проводить только после такого baseline и с заранее одной содержательной гипотезой, сохранив общий world/story boundary у writer и auditor и unseen-equivalent scene.
