# Новгородская земля — Graphify G1-G4

Пакет содержит полную карту G1-G4 в формате Graphify-like output.

## Файлы

- `graphify-out/graph.html` — интерактивный просмотрщик.
- `graphify-out/graph.json` — полный node-link граф.
- `graphify-out/GRAPH_REPORT.md` — отчёт по структуре.
- `graphify-out/nodes.csv` — узлы в табличном виде.
- `graphify-out/edges.csv` — связи в табличном виде.
- `source_tsv/` — исходные TSV из архива для проверки.

## Масштаб

- G1: 70 узлов.
- G2: 1046 узлов.
- G3: 911 узлов.
- G4: 9332 узлов.
- Связей всего: 41537.

## Примечание

`graph.html` содержит компактную копию полного графа и не требует сервера. Для машинной обработки используй `graph.json`.
