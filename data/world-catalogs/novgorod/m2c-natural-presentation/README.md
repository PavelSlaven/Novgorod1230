# M2c natural presentation authoring

`candidate.json` contains 32 exact G4 presentation profiles and 416 layer descriptors: 271 visual, 29 acoustic and 116 explicitly unprojected. `approval-attestation.json` records independent Astra authoring approval for the exact immutable candidate hash. Import and activation are not authorized by this approval.

Each `natural_profile_ref.payload_digest` pins the canonical compiled payload built by `tools/runtime-catalog-activation/src/g4-natural-compiled-records.js`: schema, profile identity, exact G4, exact scene features and natural profile, serialized with the existing runtime-catalog `canonicalStringify` and hashed with SHA-256. It does not hash the whole authoring row.

Descriptions preserve the approved baseline's broad classes and limitations. Seasonal floodwater does not imply current water or sound. Temporal state and unadmitted wind sound remain with their existing owners. Acoustic loudness 1 is an editorial P22 ordinal, not a measured decibel value.

Runtime must load approved compiled catalog membership, bind each source to an exact committed scene position, admit its current physical cause and run P22 visibility/acoustic resolution. A baseline or descriptor alone grants no perception. No actor-position fallback, direct sensory merge or runtime authoring-file lookup is permitted. This artifact does not establish production first-screen readiness.
