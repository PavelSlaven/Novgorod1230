## Метод (D7)

- **Инерция 1–3 дня.** Шаг — 6 ч, в сутках 4 шага. Для состояния с `persistence_days = d` вес «остаться» = `(4d − 1) × Σ весов остальных доступных состояний`. Тогда ожидаемая длина серии — d суток (геометрическое распределение). `d` = 3 для ubiquitous, 2 для common, 1 для прочих; для тумана, грозы и ветровых состояний всегда 1.
- **Климатологические веса вместо равных.** Доля интервалов считается из числа дней с явлением (сводка «Климат Новгорода», наблюдения 1892–1980) с явной поправкой на то, какую часть суток явление занимает (осадки 0,5; туман 0,33; гроза 0,25; метель 0,33). Вес входа = `round(100 × доля / d)`, поэтому стационарная доля цепочки совпадает с климатической (отчёт — в JSON: например, зимой пасмурно 0,268 при цели 0,283, метель 0,095 при цели 0,091). Класс 8/4/2/1 приведён для справки.
- **Держащееся отклонение температуры.** Отдельная цепочка аномалий с шагом к соседнему состоянию и удержанием около 3 суток. Зимние величины откалиброваны симуляцией по числу дней с оттепелью (станция: декабрь 12, январь 8, февраль 6; модель: 10,5 / 8,8 / 9,3).
- **Вид осадков зависит от температуры.** `T = норма(юл. месяц, интервал) + аномалия + поправка состояния`, затем снег, мокрый снег или дождь по порогам (Jennings et al. 2018). Если для грозы ниже +8 °C, она реализуется как обложные осадки.
- **Юлианский календарь.** Все современные даты сдвинуты на −7 дней. Нормы юлианского месяца — линейная интерполяция григорианских.

## Приёмка (скрипт `check.mjs` — OK)

- Для каждого сезона × исходного состояния сумма весов — целое число > 0.
- Снег невозможен в диапазонах mild, warm, hot, дождь — в severe_cold и cold. Это проверено по матрице и по симуляции (0 нарушений за 5844 шага).
- Каждое доступное в сезоне состояние достижимо из другого состояния. Гроза зимой недоступна.
- `persistence_days` ∈ 1..3. У всех строк есть `source_refs` и уверенность A/B/C; ссылки на WK существуют.
- Средняя длина серии в симуляции — 1,45 суток.

## Известные пробелы

- **Климат 1230 г. не реконструирован количественно.** Используется аналог XX века (до современного потепления); поправка не вводится. Klimenko & Solomina 2010 приведены только как контекст, статья целиком не прочитана.
- Число пасмурных дней в январе–феврале и марте–апреле, дни с сильным ветром и зимние метели по станции (есть только по области) интерполированы или оценены (C).
- Величины аномалий и поправки состояний — редакторские (C), калибровка только по оттепелям.
- Снежный покров и лёд по дням не моделируются: даны окна явлений и правила; накопление снега — задача кода `@rus/environment-state`.
- Сводка novgorodpogoda.ru не сверена с печатным изданием «Климат Новгорода».
- Черновые профили rus13tpl (жара, метель и др.) поглощены состояниями v2, но отдельно не импортированы.
