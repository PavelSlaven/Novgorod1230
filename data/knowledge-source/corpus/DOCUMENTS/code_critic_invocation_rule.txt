# Compatibility redirect: independent audit and Contract Auditor

Status: superseded.

The old rule requiring a critic after every code or behavior change no longer applies.

Use:

1. root `AGENTS.md`, section 25, for risk-based independent audit;
2. `CONTRACT_INDEX.md`, section 8, for the read-only Contract Auditor, its triggers, source sets and finding format.

An ordinary local fix does not require a separate critic when CHIEF proves that public behavior, contracts, owner boundaries, persistence/schema, LLM authority and active profile status are unchanged.

Elevated-risk work remains subject to mandatory independent audit as defined by root `AGENTS.md`.
