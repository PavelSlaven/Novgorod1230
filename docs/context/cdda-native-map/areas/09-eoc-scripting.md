## 2. Нативное, о чём планы не упоминали

## 3. Точки расширения

- **EOC events**: подписка на готовые `event_type` без C++ (`eoc_type: EVENT`, `required_event`); для нового события - `event.h` (enum + `event_spec`) + `src/event.cpp` (имя ~126, поля ~224) + `get_event_bus().send<>` в месте факта.
- **Очереди**: `effect_on_conditions::queue_effect_on_condition` (`effect_on_condition.h:99`) из C++ - запуск EOC извне с задержкой; `process_effect_on_conditions` (`.h:102`).
- **Таблицы эффектов/условий**: запись в `npctalk.cpp:8601-8738` или `condition.cpp:2537` - узкое C++ расширение без смены архитектуры.
- **Math-функции**: таблица `math_parser_diag.cpp:1903-1965` (формат `{ "имя", { scope, число_аргументов, eval, ass, kwargs } }`) и `math_parser_func.h:150`; JSON-функции `math_parser_jmath.cpp`.
- **Хуки данных**: `completion_eoc`/`do_turn_eoc`, `result_eocs`, предметные/заклинательные EOC (§2.6).
