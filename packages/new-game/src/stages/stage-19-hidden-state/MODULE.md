# Stage 19 — Full hidden scene state

Instance/state drafts are never generated or repaired by an LLM. Code validates stable IDs, approved references, reveal/discovery links, triggers, consequence hooks and the character-knowledge boundary.

Sibling stage implementations, legacy, provider SDK, DB, UI and server are forbidden.
