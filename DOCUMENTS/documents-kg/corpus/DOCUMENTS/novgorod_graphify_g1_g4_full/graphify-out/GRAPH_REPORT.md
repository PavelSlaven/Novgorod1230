## Как пользоваться

1. Открой `graphify-out/graph.html` в браузере.
2. По умолчанию показан уровень G1; через панель справа можно включить G2, G3 и G4.
3. Для тяжёлой карты удобнее искать узел по названию или ID и открывать режим «Фокус + соседи».
4. `graphify-out/graph.json` содержит полный граф для дальнейшего Graphify/GraphRAG/Neo4j-пайплайна.
5. `nodes.csv` и `edges.csv` добавлены как редакторские таблицы для быстрой проверки.
