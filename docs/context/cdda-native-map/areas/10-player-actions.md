## 2. Родные механизмы, которых нет в документах Новгорода

- Автоход `set_destination` / `get_next_auto_move_direction` (`character.cpp:7293, 7375`) — многошаговый маршрут без ввода на каждый шаг; черновик его не упоминал.
- `ACT_GENERIC_EOC` + `u_assign_activity` (`player_activities.json:1095`, `npctalk.cpp:5673`) — JSON-путь «реплика = N секунд».
- `ACT_SOCIALIZE` / `socialize_activity_actor` (`activity_actor.cpp:12893–12951`) и `ACT_WAIT_NPC` — родная социальная активность.
- `ACT_FURNITURE_MOVE`, `ACT_TREAT_WOUND`, `ACT_FIRSTAID`, `ACT_PULL_CREATURE`, `ACT_OPEN_GATE` — готовые небоевые действия.
- `Character::use(item_location, pre_obtain_moves, method)` (`character.cpp:8128`) — единый вход «использовать предмет» с выбором `use_action` по строке без меню. Прямой кандидат на замену разных ручек по типам предметов.
- `avatar_action::*` (`avatar_action.h`): `eat`, `eat_here`, `eat_or_use`, `move`, `swim`, `autoattack`, `mend`, `plthrow`, `plthrow_wielded`, `unload`, `fire_wielded_weapon`, `fire_turret_manual`, `check_stealing` — сырые вызовы действий без keybinding.
- `activity_type` `completion_eoc` и `do_turn_eoc` (`activity_type.cpp:101–102`) — JSON-хуки на завершение и каждый ход активности.
- `uistate.open_menu` (`uistate.h:308`) — единственный родной «обратный вызов» вместо чтения клавиши в `handle_action` (`handle_action.cpp:3186–3191`).
- `debug_console` `step_controller::tick` (`debug_console.cpp:610–651`) и `debug_capture`/`debug_actions_table` — готовый образец внешнего пошагового управления ходом и журнала событий/EOC-трассы.
- `tests/player_helpers.cpp:247` (`process_activity`) — образец прогона активности без `handle_action`, для проверок без curses.
- `Character::drop(const drop_locations&, …)` и `Character::consume` (`character_inventory.cpp:684`, `consumption.cpp:2074/2108`) — меню-свободные пути.
- Эффекты EOC: `u_pickup_items` (`EFFECT_ON_CONDITION.md:2613`), `u_cast_spell` (:4630), `u_message` (:4581), `u_make_sound` (:4280), `u_consume_item_sum` (:4454), `u_activate` (:5318) — действие игрока из JSON.
- `item use_action` `effect_on_conditions` (`iuse_actor.cpp:5973–6043`) и `consumption_effect_on_conditions` для еды (`iuse_actor.cpp:6009`).
