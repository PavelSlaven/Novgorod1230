Главное правило проекта - Код не сочиняет мир. Мир, персонажей, причины, связи, предметы, исторические смыслы и последствия создаёт LLM. Код только хранит, передаёт, валидирует структуру, фиксирует утверждённые данные и защищает состояние от противоречий и выдаёт случайное число по запросу LLM при бросках D20..
Любая новая смысловая сущность мира должна появляться только как утверждённый результат LLM-процедуры.
Любая процедурная догадка кода о мире считается нарушением архитектуры.
Основное правило: Этапы новой игры и базового хода строятся по принципу изолированных блоков. Блок получает строго определённые данные на вход, внутри функционирует как независимый модуль без внешних зависимостей, и возвращает результат. Последовательность таких блоков образует конвейер обработки.
Правило Чёрного Ящика и Конвейера
Каждая смысловая операция в проекте оформляется как этап конвейера.
Этап — это функция / модуль / класс, который:
Получает строго определённые данные на вход.
Работает только с ними, не касаясь глобального состояния.
Возвращает результат (новый набор данных).
Никакой этап не знает о существовании других этапов.
Последовательность этапов, соединённых данными, образует полный игровой цикл.
