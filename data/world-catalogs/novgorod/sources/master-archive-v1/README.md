# Novgorod1230 MASTER ARCHIVE v1.0.0

Единый автономный мастер-архив четырёх переданных каталогов и построенного поверх них экономико-социального слоя для Великого Новгорода и Новгородской земли около 1230 года.

**Статус аудита:** `PASS`  
**Собран:** `2026-08-30T06:33:32+00:00`  
**Канонический namespace:** `n1230:`

## Что считать источником истины внутри архива

1. `data/canonical/entities.json` — единый реестр сущностей с исходными записями и provenance.
2. `data/relations/relations.json` — проверенный граф явных связей.
3. `data/economy_social/` — единая экономико-социальная модель.
4. `data/canonical/id_crosswalk.json` — переход от legacy-ID четырёх каталогов к каноническим ID.
5. `data/audit/audit_report.json` — машиночитаемый итог аудита.
6. `MASTER_ARCHIVE_MANIFEST.json` и `.sha256` — контроль целостности файлов.

`source_snapshots/` сохраняет все исходные файлы в распакованном виде для provenance и повторной проверки. Для работы с мастер-базой четыре исходных ZIP не нужны.

## Важная граница данных

`historical_amount` хранит сумму или термин источника. `base_price_beu` хранит только нормализованный игровой диапазон. BEU не является исторической валютой. Модельные числа всегда помечены `numeric_confidence = model_only` и `evidence_class = GAMEPLAY_NORMALIZATION`.

Каталог не является whitelist действий, предметов или ordinary-материи. Он задаёт проверяемые сведения, категории и причинные связи; свободное действие и materialization должны оставаться внутри authoritative envelope проекта.

## Форматы

Ключевые таблицы представлены одновременно в JSON и CSV. Вложенные поля в CSV сериализованы компактным JSON. Исходная запись каждой сущности целиком сохранена в `source_record`.

## Начало работы

- Поиск legacy-ID: `data/canonical/id_crosswalk.csv`.
- Поиск по типу/имени: `data/canonical/entity_index.csv`.
- Граф: `data/relations/relations.csv`.
- Цена предмета: `data/economy_social/item_price_models.csv`.
- Доход профессии: `data/economy_social/income_models.csv`.
- Исторические суммы: `data/economy_social/historical_price_evidence.csv`.
- Примеры Python: `scripts/query_examples.py`.

## Ограничения

Точные заработки, нормальные цены многих вещей, единый курс денежных терминов и часть социальных институтов не восстанавливаются источниками с требуемой точностью. Такие вопросы перечислены в `data/audit/unresolved_questions.json`; вместо ложной точности применяются диапазоны с provenance и confidence.
