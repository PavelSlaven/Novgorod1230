# Novgorod weather gameplay reconstruction v2

This profile is a finite gameplay state machine, not a medieval climatological probability model. Seasons use equal candidate weights to avoid false precision. Six-hour boundaries use the NOAA synoptic-hour cadence only as a neutral simulation grid. Composite weather states are mutually selectable snapshots; concurrent details outside the selected snapshot require another approved profile. Movement factors are conservative game-authoring conventions and are not measurements.
