# craft_tools_gear — инструменты ремесла, промысла и земледелия (candidate)

## Что здесь

- `tools_gear.csv` — 157 понятий-инструментов (уровень категории, не экземпляра). Группы: плотницкие 16, общие и личные 18, кузнечные 15, литейно-ювелирные 14, земледельческие 13, рыболовные 13, охотничьи 9, ткацкие 6, сапожные 6, гончарные 6, письмо и печати 6, тонкая деревообработка 5, кожевенные 5, прядильные 4, лодочные 4, волокно 3, косторезные 3, металлургия 2, стекло 2, дёготь и уголь 2, шитьё 2, бондарные 1, красильные 1, бортничество 1.
- `occupation_tools.csv` — 356 связей для 68 занятий: 146 носимых при себе (`carried`) и 210 на рабочем месте (`workplace`). Эти связи заменяют групповые `typical_tools` («специализированный инструмент ремесла…») поимённым списком.
- `occupation_tools.csv`, правило (правка 2026-09-26): `confidence` связи = `min(confidence занятия из scripts/src/occupation-tools.cjs, confidence самого инструмента в tools_gear.csv)` — TSV занятий называет инструменты только общими словами, поэтому связь не может быть увереннее ни занятия, ни инструмента. `source_refs` связи = `source_refs` самого инструмента (а не общая ссылка на `src:occupations-v1`, которая называет только группы инструментов, а не конкретные предметы); если инструмент не найден, ссылка падает обратно на `src:occupations-v1` и это уходит в предупреждения сборщика.

## Поля tools_gear.csv

`tl_id, name_ru, name_en, craft_group, category_id, category_status, item_template_ref, wk_concept_ref, matcult_refs, material, material_class, size_class, mass_band, mass_band_range, mass_basis, mass_attested, v5_policy_mass_g, v5_policy_band, used_in_process_refs, used_by_occupations, in_workshops, workplace_pf_id, condition_states, mark_slots, region_id, source_refs, confidence, status, note`

- `category_id`: если есть шаблон v5, берётся его категория `cat_item_object_<slug>_v1` (`existing_v5`, 76 строк); иначе предлагается новая категория (`proposed_new`, 81). Новые категории требуют CR.
- `material`: только `mt_id` из `materials_registry`, первый — основной.
- `used_in_process_refs`, `used_by_occupations`, `in_workshops` — считаются скриптом из цепочек, карты занятий и мастерских. `used_in_process_refs` также содержит WK-понятия процессов, которые здесь не расписаны по шагам (пахота, обмолот, покос, сетной лов, бортничество).
- `workplace_pf_id` — id семейства места из WK `place-first-cartography.json`.

## Правило массы (детерминированное, `scripts/build.cjs`)

1. Если в источнике есть масса (`mass_attested` в граммах), класс берётся по ней: `mass_basis = attested`. Так сделано у 5 инструментов: клещи до 1350 г, гвоздильня 730 г, ювелирная наковаленка 1460 г, ювелирный молоточек 33–34 г, буллотирий 446 г. У кузнечного молотка известна только масса головки (210–290 г) — она нижняя граница, класс не ниже правила (`attested_head_only;rule_for_whole`).
2. Иначе класс = таблица «класс основного материала × размер» (`mass_basis = rule:<материал>x<размер>`):

| материал \ размер | tiny <10 см | hand 10–30 | long_hand 30–80 | long 80–250 | fixture | soft_goods |
|---|---|---|---|---|---|---|
| metal | M0 | M1 | M2 | M3 | M4 | M3 |
| wood | M0 | M1 | M2 | M3 | M4 | M3 |
| stone | M0 | M2 | M3 | M4 | M5 | M3 |
| clay | M0 | M1 | M3 | M4 | M5 | M3 |
| light (кость, кожа, волокно, кора) | M0 | M0 | M1 | M2 | M3 | M3 |

Классы: M0 <50 г, M1 50–300 г, M2 300 г–1,5 кг, M3 1,5–5 кг, M4 5–25 кг, M5 >25 кг. Точную массу экземпляра задаёт код внутри класса.
3. **Именное переопределение для тонких, длинных, мягких или пустых вещей** (`mass_basis = estimated_physical`, правка 2026-09-26). Таблица шага 2 верна для типичных ручных орудий, но давала физически невозможный класс для нескольких форм: тонкое длинное древко стрелы или разметочного шнура, лук, удочка, силок, отвес, пустой мешок, носимый оселок, тяжёлая квашня. Для них в `mass_attested` записана обоснованная физическая оценка со словом «оценочно» (не археологическая находка), и класс берётся по ней так же, как по атрибутированной массе: `tl_hunting_arrow` ~40 г → M0, `tl_hunting_bow` ~800 г → M2, `tl_fishing_rod` ~200 г → M1, `tl_snare`/`tl_marking_cord`/`tl_whetstone` ~20–40 г → M0, `tl_plumb_line`/`tl_sack` ~100–150 г → M1, `tl_kneading_trough` ~8000 г → M4.
4. Для сравнения показаны массы игровой политики v5 (`v5_policy_mass_g`, источник `src_gameplay_physical_policy_v3`, не измерение). У 76 инструментов есть v5-масса, у 27 из них класс расходится (список — в `validation-report.json`; до правки 2026-09-26 было 30, часть закрыта переопределениями из п. 3).

## Состояния и приметы (правило по классу материала)

- `condition_states`: metal — serviceable, dull_edge, nicked, rusted, loose_handle, cracked, broken; wood — serviceable, worn, cracked, warped, rotten, broken; stone — serviceable, chipped, worn_groove, broken; clay — intact, chipped, cracked, broken; light — serviceable, worn, frayed_or_torn, wet, rotten, broken.
- `mark_slots`: для дерева и лёгких материалов — owner_sign_carved, repair_trace, wear_pattern; для металла — repair_trace, wear_pattern. У орудий с наварным лезвием добавлен `weld_seam_visible` (Колчин). У поплавков, пряслиц и бирок добавлен `owner_sign_or_inscription`: знаки собственности на поплавках описаны у Рыбиной 2015 (A), подписанные пряслица — у Колчина, Янина и Ямщикова 1985 (B), бирки — у Колчина 1968 (класс).

## Проверено по заданию

- Пилы: засвидетельствованы, 8 экземпляров (Колчин) и WK claim:population-woodwork-saw. При этом доски в основном колют и тешут; механической распиловки нет.
- Охотничьи ловушки: железный капкан **не засвидетельствован** и запрещён (`dl_steel_trap`). Петли, силки, давящие самоловы и птичьи сети отмечены C (этнографическая аналогия): у Рыбиной 2015 их нет, археологически выделены только луки, стрелы и томары.
- Коса-горбуша — B: WK знает косы XI–XII вв. со стальной полосой, а тип «горбуша» указан по matcult. Соха — B, рало и сошники — A.
- Ткацкий стан: тип выбирается по контексту. WK описывает горизонтальный стан по найденным деталям; вертикальный с грузилами — вариант.

## Приёмка (validate.cjs)

- 68 из 68 занятий имеют не меньше 2 инструментов. 67 из 68 набирают 2 инструмента только из существующих шаблонов v5; исключение — `nov_occ_beggar_alms` (посох и мешок пока `proposed_new`).
- 157 из 157 инструментов используются хотя бы одним процессом или занятием.

## Пробелы

- Масса и размеры по МИА 65 взяты из конспекта. Нужна сверка с PDF, после неё B станет A.
- Колчин 1968 «Деревянные изделия» (бирки, токарные изделия, снасти) постранично не выписан.
- Устройство горна, мехов и гончарного горна для Новгорода XIII в. — реконструкция (C).
- Инструменты солевара (црен) и мельника — C; солеварня описана не здесь, а в экономике.
- Занятия без собственного списка в TSV: литейщик-ювелир, косторез, токарь, стекольщик, сельский металлург, красильщик. Их инструменты описаны здесь, а занятия нужно добавить в домен occupations.
- `tl_seal_blank_mould` (форма для свинцовых заготовок печатей) сама в Новгороде не найдена; это реконструкция по механике буллотирия (ИА РАН), не по первоисточнику Янина. Первоисточник не сверен — остаётся C.
- `src:kyy1985-applied` процитирован только на страницах о печатях и о стекле; ссылки на него у `tl_stylus`, `tl_wax_tablet`, `tl_seal_blank_mould` заменены на подтверждающие WK claims или `src:iaran-bullotirion` (правка 2026-09-26). Остальные ссылки на этот источник за пределами двух прочитанных страниц (в других файлах группы) этой правкой не тронуты — см. VERIFICATION.md.
