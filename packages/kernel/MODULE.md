# @rus/kernel

## Назначение

Минимальные технические примитивы, на которых строятся остальные модули: типизированный результат, стабильная сериализация, SHA-256 и иммутабельность.

## Владеет

- `Result`-подобным контрактом `ok`/`err` и `KernelError`;
- детерминированной сериализацией данных;
- вычислением технических digest;
- глубоким замораживанием утверждённых структур.

## Не делает

- не содержит игровых правил;
- не обращается к БД, LLM, UI или файловой системе приложения;
- не создаёт сущности мира и не интерпретирует смысл данных.

## Публичный API

`ok`, `err`, `unwrap`, `KernelError`, `stableStringify`, `sha256`, `deepFreeze`.

## Контракты

Принимает только явно переданные технические значения. Digest вычисляется над стабильным представлением; функции не читают глобальное состояние.

## Допустимые зависимости

Только стандартная библиотека Node.js.

## Запрещённые зависимости

Любые `@rus/*`, `apps`, `legacy`, БД, provider SDK и UI.

## Инварианты

Kernel остаётся нижним слоем графа зависимостей и не импортирует более высокие модули.

## Ошибки

`KernelError` и стандартные ошибки неверного технического вызова.

## Тесты

Покрываются модульными тестами foundation и всеми пакетами, использующими digest/result primitives.

## Совместимость

Изменение стабильной сериализации или digest считается контрактным изменением.
