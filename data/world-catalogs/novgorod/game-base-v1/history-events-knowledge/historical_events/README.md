# historical_events — события 1230–1250 и их фазы

Домен брифа `historical_events`, приоритет M3. Статус: **candidate**, не утверждено.

## Что это

`events.csv` (35 строк, не менялся в проходе 2026-09-26) и `event_phases.csv` (177 строк, переработан
2026-09-26 — см. `../VERIFICATION.md`, раздел «Исправления 2026-09-26»): переупакованный черновик LLM
`data/world-catalogs/novgorod/sources/nov-region-audit-v1/novgorod_historical_timeline_1230_1250_v1.json`
(`status: draft`, `requires_human_historical_audit: true`, привязка к карте v6). Событие = голод и мор
1230–31, смены князей/посадников, пожары, поход, вече, торговля, знамения. Каждая фаза (background → omens →
escalation → impact → aftermath) несёт видимые признаки, слухи, эффекты на дороги/торг/власть/NPC/предметы,
разрешённое и запрещённое игроку знание, а с 2026-09-26 также `summary`/`historical_context` черновика и
маркер флага ручного аудита `needs_review`.

Региональные ссылки `regions_affected[].region_id` используют id узла G0: `region_novgorod_land`.

## Метод

Скрипт `scripts/build_events.cjs` (переименован из `.js` 2026-09-26: корневой `package.json` задаёт
`"type": "module"`, а скрипт использует `require()`):
1. читает все 175 записей `timeline[]` черновика;
2. группирует их по `event_id` → `events.csv` (одна строка на событие) — не менялось в этом проходе;
3. переносит фазовые поля в `event_phases.csv` по ключевым полям брифа (`visible_signs`, `rumors`,
   `effect_roads/market/power/npc/items`, `player_knowable`, `forbidden_knowledge`, `node_refs_v6`,
   `chronicle_ref`, `source_refs`, `confidence`), и с 2026-09-26 также `summary`, `historical_context`,
   `market_goods_affected`, `is_game_time_anchor`, `needs_review`, `needs_review_note` — эти поля были в
   черновике, но терялись при первой сборке (см. VERIFICATION.md, item 2);
4. **проверка по книжным свидетельствам** (заменяет прежний кросс-чек по sqlite/ключевым словам, см. ниже):
   для 5 событий (25 фаз), где само содержание фазы было построчно сверено с конкретными пронумерованными
   записями `servak:/srv/novgorod-work/data/books/evidence/history-events-knowledge.csv`, `confidence=B` и
   `source_refs` содержит `book:<id> §<section> ¶<para>`. Остальные 30 событий (150 фаз) — `confidence=C`
   с честной пометкой «не сверено построчно» в `audit_note`;
5. `chronicle_ref` теперь явно помечен как черновой пересказ LLM, а не цитата издания или ссылка на
   статью/страницу (см. «Известные ограничения», п. 4);
6. `scripts/validate_events.cjs` проверяет acceptance-критерии брифа: у каждой фазы есть `chronicle_ref`
   (черновой пересказ источника, если его не даёт черновик — фаза попадает в `rejected_report.json`), дата
   (`date_range`) внутри 1230–1250, печатает долю фаз с нерешённым `node_refs_v17` и число `needs_review=true`.

## Что изменилось 2026-09-26 (было `rework`, см. VERIFICATION.md)

- **Прежний кросс-чек по sqlite и ключевым словам заменён книжными свидетельствами.** Старая версия
  повышала `confidence` до `B` для любой фазы 1229–1231 гг., совпавшей по году и общему слову (голод,
  Ярослав, вече…) с одной из 16 записей sqlite `events`, без проверки, что совпавшая запись действительно
  описывает именно эту фазу. Из-за этого у `nov_hist_1231_002`, `nov_hist_1230_002` и `nov_hist_1230_004`
  ссылки были на неподходящие даты sqlite (см. VERIFICATION.md, item 4). Теперь `confidence=B` дают только
  5 событий (`nov_hist_1230_001..004`, `nov_hist_1231_002`), у каждой из 25 фаз которых `source_refs`
  содержит конкретную книжную цитату (`book:667380`, `book:301539`), а не sqlite-дату по ключевому слову.
  Оставшиеся 30 событий книжными свидетельствами в этом проходе не сверялись — это тот же остаточный
  пробел (86% → теперь 30/35 событий, 150/175 фаз), что и раньше, просто честно посчитанный без
  фиктивного B.
- **Вернуты поля черновика**, которые первая сборка отбрасывала: `summary` (175 уникальных значений),
  `historical_context` (35 уникальных на событие), `market_goods_affected` (7 наборов товаров вместо
  одного шаблонного `effect_market`), флаг `needs_review` + `needs_review_note` (5 фаз события
  `nov_hist_1245_002` с примечанием «Сверить по русскому тексту эпизоды у Торопца, Жижича и Усвята» — было
  потеряно полностью), и `is_game_time_anchor` (174/175 `true`; помечает, что час в `date_range` —
  игровое допущение календаря, а не историческая точность).
- **`chronicle_ref` переформулирован.** README раньше называл его «дословной цитатой из перевода
  Michell & Forbes»; на деле это английский пересказ, написанный LLM черновика. Текст колонки теперь
  явно говорит «черновой пересказ LLM (не цитата издания и не ссылка на статью/страницу)».
- Шаблонность содержимого фаз (`visible_signs`, `rumors`, `effect_*`, `player_knowable`,
  `forbidden_knowledge` — по одному уникальному значению на весь файл или на тип фазы) **не устранена**:
  это игромеханический слой брифа (см. `../VERIFICATION.md`), а не историческое содержание; историческое
  содержание теперь несут восстановленные `summary`/`historical_context`/`market_goods_affected`.
- В фазах исправлены названия и датировка четырёх событий, указанных в повторной
  проверке. `events.csv` всё ещё содержит исходные заголовки и даты: это
  отдельный открытый разрыв между двумя таблицами до правки `events.csv`.
- Голодная фаза начинается не ранее 14.09.1230; мор, скудельницы и немецкий
  хлеб 1231 г. выделены в отдельные фазы с точностью источника до года.

## Результат проверки (см. вывод скрипта)

- 177/177 фаз имеют непустой `chronicle_ref` и дату в диапазоне 1230–1250 (часть дат — только год).
- 27/177 фаз подтверждены книжными свидетельствами (`confidence=B`), включая две добавленные
  фазы голода 1231 г.; остальные 150 фаз — `confidence=C`.
- 5/177 фаз (`nov_hist_1245_002_*`) помечены `needs_review=true` с восстановленным примечанием черновика.
- `rejected_report.json`: пусто (0 жёстких отказов по этим двум критериям в этом проходе).
- `node_refs_v17` — пусто во всех 177 строках. Это осознанный разрыв, не потеря: см. ниже.

## Известные ограничения (не потеряно, зафиксировано)

1. **Полный построчный аудит по тексту НПЛ не выполнен.** У этого коллектора нет бюджета перевести и
   построчно сверить церковнославянский текст НПЛ (izbornik.org.ua, старший извод: `novg06.txt` 1219–1232,
   `novg07.txt` 1233–1265; младший извод: `novg24.txt` 1230–1243, `novg25.txt` 1244–1257 — файлы, на
   которые ссылался этот README раньше, уже удалены из scratch, см. VERIFICATION.md item 6) против всех
   175 черновых фаз. Сделана только точечная сверка (2026-09-26: по книжным свидетельствам вместо
   ключевых слов) для 5 событий (14% фаз). Оставшиеся 30 событий (`confidence=C`) требуют отдельного
   прохода историка/старшей модели с текстом НПЛ или с оставшимися 184−25=159 строками книжных
   свидетельств группы, которые в этом проходе не были задействованы для остальных событий.
2. **`node_refs_v6 → node_refs_v17` не переведены.** Черновик даёт узлы графа v6
   (`gn_nov_g1_..._g3_...`); в v17 иная схема мест (`data/world-catalogs/novgorod/m2c-natural` и др. в
   PR #98 worktree). Мэппинг ~11 тыс. узлов требует владельца spatial/place_names — не выдумано, оставлено
   пустым в `node_refs_v17`, `node_refs_v6` сохранён для будущего перевода.
3. Событие `nov_hist_*` объединяет фазы одного `event_id`; `events.csv.source_titles` берёт источники только
   первой фазы (обычно совпадают со всеми фазами события в черновике, но это не проверено построчно).
4. Заголовки `nov_hist_1242_002`, `nov_hist_1243_001` и `nov_hist_1245_001` теперь собираются из
   `correctedEvents`; `events.csv` пересобран для совпадения с генератором. Для 1242_002 и 1245_001
   поле `events.csv.year` всё ещё расходится с фазовыми датами 1243/1246 (см. `../VERIFICATION.md`);
   это отдельные незакрытые исторические расхождения. Ошибка заголовка и фаз `nov_hist_1230_004`
   исправлена в проходе 2026-10-06; актуальная атрибуция приведена ниже.

## Уточнение дат nov_hist_1230_004

Название в `events.csv` и пяти фазах указывает Новгород как место расправы и Торжок как направление отъезда. Дата отъезда Водовика с Ростиславом расходится: `book:301539 §4366` даёт 8 декабря, `book:667380 §486` — 9 декабря. Первый источник датирует убийство Семёна Борисовича следующим утром, второй описывает последующие убийства и грабежи. Возвращение Ярослава датировано 30 декабря (`book:301539 §4366`; `book:667380 §486`). После этого источник сообщает об отъезде Ярослава «через две недели», не называя точный день; годовая граница aftermath 1231 — реконструкция, а не точная летописная дата. Подготовительная фаза также обозначена только годом. Эти фазовые даты не являются точными игровыми часовыми якорями.

## Пересборка

```
node scripts/build_events.cjs
node scripts/validate_events.cjs .
```

Без аргументов builder читает pinned timeline из `novgorod/sources/nov-region-audit-v1` и пишет в эту
папку. Прежний аргумент `sqlite_dump.json` удалён: builder разбирал файл, но не читал ни одного поля.
