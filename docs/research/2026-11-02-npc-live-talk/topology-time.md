# Время ответа NPC по топологиям вызовов — оценка из записи

Строка подгонки и таблица ниже — вывод скрипта `tools/topology_time.py` (`python -I tools/topology_time.py research/wire-capture.jsonl <файл вывода>`); провод — 77 вызовов записи npc-talk; допущения ниже — те же, что в скрипте.

Модель времени — наименьшие квадраты по 27 вызовам записи с некэшированным входом не больше 12 тыс. токенов (планировщик и аудитор с попаданием кэша; диапазон: 866–12 000 новых токенов, 11–252 токена выхода): время = постоянная + доля на тысячу новых токенов входа + доля на сотню токенов выхода. Вызовы с 20–72 тыс. новых токенов в подгонку не входят: там время растёт быстрее линии.

Допущения оценки (проверяет стенд, шаг 4):
- знаков на токен для русского текста — 2,5 (оценка образца D357), разброс 2,0–3,0; на проводе записи не измерить: кириллицы во входе 7 %;
- часть 1 (правила) — 1 600 знаков, одна для всех NPC и всегда из кэша (после перезапуска сервера модели — +0,3 с на первый вызов); части 2–3 — остаток предела;
- три случая некэшированного входа NPC: «худший» — части 2–3 целиком новые при входе на пределе (первая фраза с NPC после долгого разговора с другими, смена сцены); «половина» — новая часть 3; «обычная следующая фраза» — 600 знаков (новая пара реплик и услышанная реплика дописаны после кэшированного начала, критерий 2 CR);
- для проверки: в записи аудитор с попаданием кэша — 866 новых токенов, 19 токенов выхода — 0,74 с (вызов 44); по модели — 0,89 с;
- выход NPC — 60 токенов (строки «Выбор», «Речь», «Поступок», «Опора», «Неправда», «Утаил»); выход аудитора — 5 токенов («годно»);
- отдельный аудитор (D357): его правила и часть 2 — из кэша прошлого вызова аудитора у того же NPC; аудитор продолжением — запрос NPC целиком из кэша, новые — ответ NPC и указание аудитору (150 + 300 знаков);
- планировщик после шага 5: 1 000 новых токенов (реплика героя в конце, остальное из кэша), выход строками 40 токенов — 1,1 с; при выходе JSON на 200 токенов — 1,8 с (+0,7 с к А и Б); в записи планировщик — медиана 4,0 с;
