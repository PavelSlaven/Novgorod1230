**Выводы**
1. Главный выигрыш даёт **подготовка пакета кодом** (B против A):
   - выдумок вдвое меньше;
   - каталогов нет;
   - сцена лучше;
   - вызов быстрее, потому что пакет короче.
2. **Проверка и правка вторым и третьим вызовом** (D) ещё немного снижает выдумки: 0,67 → 0,47, без ошибок 27% против 20%. Зато литературное качество и «сцена» чуть падают, а время растёт в 2,3 раза.
3. Хуже контроля:
   - **отбор деталей самой моделью** (C): слабая модель теряет главное, верность 2,73;
   - **письмо по зонам** (E): текст разваливается при сборке.
4. **Противоречия** (0,5–0,8 на текст) почти одинаковы во всех стратегиях. Их источник — данные и подача, а не стратегия:
   - птица «перевозчик» становится человеком;
   - черёмуха «цветёт и с плодами» читается как «отцвела»;
   - звуки гребли при пустом берегу;
   - время суток пересказано неверно.

   Лечится подачей:
   - однозначные названия («кулик-перевозчик»);
   - состояния по-русски целиком;
   - время суток словами («раннее утро, 7 часов»);
   - звуки людей только при людях.

**Решение для R-3**
- **Стратегия B — по умолчанию**: код ранжирует, 12–18 деталей, по-русски, зоны, явные «нет», без служебных полей. Инструкция первого прихода — короткая русская.
- **D** — опциональный второй проход «проверка → правка», если бюджет хода позволяет. Проверку лучше сначала делать кодом (имена, время, наличие людей), а LLM-проверку — только по подозрительным местам.
- **C и E не использовать.**
