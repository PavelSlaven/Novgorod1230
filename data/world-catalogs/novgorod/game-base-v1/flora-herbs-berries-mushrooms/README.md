## Поля

Общие для трёх таблиц: `fl_id` (префиксы `fl_hb_`, `fl_br_`, `fl_fu_`, `fl_cu_`), `name_ru`, `name_lat`, `name_en`, `life_form`, `habitat_classes` (исходная авторская разметка), `habitat_presence` (сводка pf_id:класс и сезоны), `visible_months`, `flowering_months`, `phenology_by_season` (JSON по сезонам, генерируется скриптом из месяцев), `winter_look`, `perceptual_cues` (для прозы), `uses`, `medicinal_practice_epoch`, `toxicity`, `lookalike_ids` + `lookalikes`, `edibility`, `yield_unit` (корзина, лукошко, горсть, пучок, охапка, вязанка, сноп…; количество задаёт код), `evidence_1230`, `source_refs`, `confidence`, `gbif_usage_key`, `gbif_nw_count`, `status`, `notes`.

Дополнительно:
- ягоды и грибы: `kind` (berry|fungus), `subkind`, `ripening_months`, `ripening_period`, `allowed_seasons` (из месяцев созревания), `refresh_class=season`, `preparation_needed`, `food_ingredient_ref` (MASTER `ING*`), `gbif_nw_obs_months`;
- культуры: `crop_kind`, `allowed_1230` (yes|uncertain|no), `sowing_months/period`, `harvest_months/period`, `field_look_by_season`, `archaeobotanical_attestation`, `place_family_refs`.

**Универсальный и региональный слой** (замечание критика): таксон универсален (`universal_taxon=true`, `region_id` пуст); регион задаётся только в строках присутствия (`flora_habitat_presence.region_id = region_novgorod_land`). Для другого региона добавляются новые строки присутствия, таксоны не копируются.
**Связь с категориями кода**: `category_ref = proposed:flora/<группа>` — предложение; реального `category_id` в category_registry пока нет, связь надо установить в домене категорий.

## Метод

1. Сначала имеющиеся знания: WK production-v1 (claims по флоре и культурам найдены скриптом по ключевым словам и проверены вручную), research md (WFM-01..10, WLS-01, SC-26), MASTER food_system (ингредиенты и месяцы), прежние обзоры `flora-fauna.json`, `archive-sweep.json`.
2. Реальные пробелы закрыты исследованием:
   - **культуры и сорняки Новгорода**: Кирьянова 1979 (СА № 4) — таблицы разобраны скриптом (`scripts/extract-sources.py` → `cache/kiryanova1979.json`). Для Новгорода X – первой половины XIII в.: рожь (основная), пшеница, ячмень, овёс, просо, бобы, горох, чечевица, конопля; гречихи нет (появляется позже). Сорняки в зерне: куколь, подмаренник, пикульники, горец вьюнковый, смолёвка, костры, бородавник, метлица, марь белая, щавель, василёк; костёр ржаной и метлица — признак озимой ржи;
   - **ягоды**: ул. Боркова, выгребная яма середины XIII в. (Сережникова и др. 2024; через MASTER FSRC001 и пересказ) — клюква, морошка, голубика, смородина, малина, черника, брусника, вишня, хмель;
   - **грибы**: диссертация Калининой 2020 (БИН РАН), аннотированный список с находками в Новгородской обл., месяцами и частотой (разобран скриптом → `cache/kalinina2020.json`);
   - **лишайники**: Чхобадзе, Филиппов 2015 (болота Вологодской обл.) — аналогия, уверенность C;
   - **болотная флора**: Хмельщикова 2023 (НП «Валдайский») — уверенность B для современного присутствия;
   - **современный ареал** каждого вида проверен скриптом по GBIF (bbox 56,5–60° с. ш., 29–36° в. д.; `scripts/fetch-gbif.cjs` → `cache/gbif.json`); для грибов месяцы наблюдений с долей ≥10% (при n≥20) добавлены к `visible_months`.
3. Перенос современной флоры в 1230 год: по Кирьяновой, климат и границы растительных зон в историческое время почти те же; поэтому современное присутствие аборигенного вида даёт уверенность C (или B при научном региональном источнике), а археоботаника Новгорода — A.
4. Всё производное (разворот мест и сезонов, фенология по сезонам, календарь поля, счёты, проверки) делает скрипт.

## Правила

- **Классы частоты** (8/4/2/1 = ubiquitous/common/contextual/rare): авторская оценка роли вида в типе местообитания — 8 фон/доминант (по источнику или общей экологии), 4 характерный, 2 встречается в подходящих микроместах, 1 редкий. Это игровая предпочтительность выбора внутри места, а не биологическое обилие. Для грибов с частотой у Калининой ориентир: «Часто» ≈ 4, «Нередко» ≈ 2, «Редко/единственная находка» ≈ 1 (частоты Калининой относятся только к широколиственным лесам).
- **Местообитание → места**: 23 класса местообитаний в `scripts/src/habitats.json` разворачиваются в pf_id из WK `place-first-cartography.json` (pf_id = id семейства WK без изменений). При пересечении берётся максимальный класс.
- **Сезоны**: winter = XII–III, spring = IV–V, summer = VI–VIII, autumn = IX–XI (ids как в v17 nature-successor-candidate-v2). Строка присутствия создаётся на сезон, если в нём есть хотя бы один месяц из `visible_months`; `visible_state` = fruiting / flowering / vegetative / winter_form (для культур ripe_or_harvest).
- **Уверенность**: A — археоботаника или пыльца Новгорода (или одобренный WK claim с историческим контекстом); B — научный региональный источник (Калинина, Валдай) или одобренный универсальный WK claim; C — современный ареал, общая экология, реконструкция или аналогия.
- **Лечебное применение**: заполняется только при источнике для эпохи; в этой выборке такого нет, поэтому везде «не засвидетельствовано для Новгорода XIII в.», а поздние народные практики помечены в `uses` как поздние.
- **Анахронизмы**: `anachronism_denylist_flora.csv` проверяется скриптом по именам и по `uses`/`perceptual_cues` всех трёх таблиц. Гречиха (`allowed_1230=no`) в таблице есть как явный запрет, строк присутствия у неё нет. Культуры `uncertain` (укроп, свёкла, морковь, огурец, хрен и 7 сорняков без находки) имеют строки присутствия с весом 1–2; потребитель должен требовать для них отдельного допуска.

## Проверки (`scripts/validate.cjs`, результат 0 ошибок, 17 предупреждений)

- id уникальны, префиксы, лат. имена уникальны в таблице, у каждой строки есть source_refs, статус candidate;
- все pf_id есть в WK place-first-cartography; веса ∈ {8,4,2,1};
- ссылки резолвятся: 807 ссылок, в т.ч. WK claim id в runtime-bundle.json, `src:*` в реестре, MASTER `ING*` в ingredients.csv, research md и якоря, статьи Wikipedia (HTTP 200, `check-urls.cjs`);
- травы: в каждом болотном, луговом, прибрежном и лесном семействе мест ≥8 таксонов летом и ≥3 видимых зимой (факт: летом 21–61, зимой 4–30);
- у всех ядовитых трав заполнены toxicity и lookalikes; у ядовитых грибов тоже (кроме энтоломы — только текст без id);
- ягоды и грибы: ripening_months ⊂ 1..12, allowed_seasons совпадают с месяцами созревания и есть в присутствии, refresh_class=season; каждый съедобный гриб, указанный ядовитым как двойник, ссылается на него обратно;
- культуры: нет кукурузы, сои, картофеля, подсолнечника, томата и прочих из denylist; у каждой допустимой культуры есть сев и уборка (многолетники — `perennial`) и календарь поля; у каждой есть археоботаника или C с примечанием;
- перекрёстная проверка с источниками: культуры, отнесённые к табл. 2 Кирьяновой, реально стоят у Новгорода; грибы с пометкой «Новгородская обл.» реально имеют новгородскую находку у Калининой.

Предупреждения: 13 съедобных грибов без двойника (у многих опасного двойника нет), 4 вида с 0 наблюдений GBIF в bbox (Bryoria furcellata, Lactarius resimus, Russula emetica, Entoloma sinuatum — редкая регистрация, не отсутствие).

## Пересборка

```
cd scripts
python extract-sources.py   # только при обновлении источников (сеть)
node fetch-gbif.cjs         # только новые имена (сеть); --refresh для всех
node check-urls.cjs         # статус ссылок (сеть)
node build.cjs              # офлайн, детерминированно
node validate.cjs           # офлайн; читает WK из main checkout (NOVGOROD_MAIN)
```

Исходная авторская разметка — `scripts/src/*.tsv`; правится она, затем пересборка.

## Известные пробелы

- Статья Сережниковой и др. 2024 целиком не прочитана: состав таксонов взят из MASTER FSRC001 и пересказа 53news; DOI из MASTER скриптом не резолвится (404) — нужно проверить DOI и таблицу находок.
- Кирьянов 1959 (МИА 65) — только через Кирьянову 1979; скан МИА 65 без OCR. Статья Мазея и др. 2024 (MASTER SRC044) не скачалась (пустой ответ сервера).
- Троицкий раскоп (Monk, Johnston 2012) — только через WK claims, полный список таксонов (в т.ч. сорняки и луговые) не извлечён.
- Нет источника по лишайникам и мхам самой Новгородской области (только Вологодская аналогия и GBIF); мох в конопатке срубов — этнографическая аналогия (C), научной ссылки нет.
- Грибы хвойных лесов и болот (лисичка, маслята, рыжик, горькушка, паутинник) — без регионального научного списка, только GBIF и общая экология (C).
- Сроки сева и уборки — реконструкция по месяцам свежести MASTER и агрономии (C); точного календаря полевых работ Новгорода XIII в. нет. Форма пшеницы (озимая/яровая) для Новгорода не установлена.
- Огородные культуры (свёкла, морковь, укроп, огурец, хрен) не подтверждены археоботаникой Новгорода.
- Частоты — авторская оценка по описанию местообитаний; нет количественных данных обилия.
- Связь `category_ref` с реестром категорий кода — предложение, id категорий нет.
- Деревья и кустарники (включая багульник, вереск, мирт болотный, рябину, шиповник) — в домене `flora_trees_shrubs`; здесь только ссылки.
