# Прозаический тест данных, 2026-09-26

Метод владельца: сильной модели подаётся ровно тот пакет данных, который получила бы игровая LLM, и она пишет сцену. Если даже сильная модель не справляется, данных не хватает или они плохо поданы. Вне репозитория.

## Что прогнано

- 7 дел. C1–C5 — первый приход на место стартовой территории v17:
  - C1 — берег, август, утро;
  - C2 — бор, январь, полдень;
  - C3 — крестьянский двор, июнь, вечер;
  - C4 — пойма, май, рассвет;
  - C5 — перевоз, июль, день.
- C6 — разговор перевозчика и рыбака. C7 — жизнь двора от рассвета до полудня.
- Пакеты строит детерминированный скрипт из `game-base-v1`: бросок присутствия по ppm, погода и свет — из данных. Скрипты: `build/*/build.mjs`.
- Две подачи:
  - «visible» — русский пакет того, что человек видит и слышит;
  - «v17» — те же данные в формате запроса рассказчика v17 с его настоящей системной инструкцией.
- Писатели — Sonnet и qwen 27B (домашний сервер). Судьи — Sonnet high, по одному на дело. Все тексты лежат в `runs/`, оценки в `judgments.json`.

## Главные выводы

1. **Бросок вещей нереалистичен.** `item_place_frequency.csv` (rework) описывает археологические находки, а не живую сцену:
   - на двор выпадает около 630 вещей, на перевоз — 258;
   - среди них отходы кузницы, гончарни и стеклоделия, обломки судна во дворе, «кусок зубной эмали», «роговая чешуйка копыта»;
   - на диком берегу и в бору лежат бельё, дёготь и шкурки без всякой причины, что противоречит правилу владельца: рукотворной вещи нужна причина;
   - есть дубли.
2. **Нет того, что определяет место.**
   - На перевозе нет лодки или плота, во дворе нет построек.
   - Нет данных о воде (течение, звук, цвет, ширина), о рельефе берега, о ветре, морозе и снеге, о запахах, о расположении вещей.
   - Людей нет вовсе (известный блокер M2c).
3. **Подача путает модели:**
   - английские коды (`in_leaf`, `loose_dropped`, `dry`) и служебные поля;
   - нет приоритета: сотни равнозначных строк;
   - «видно» означает лишь совместимость по времени активности, а не реальное наблюдение;
   - рыба дана без признака видимости;
   - птица «перевозчик» путается с человеком;
   - свет «день» в 04:30;
   - противоречия: грунт «сухой», но есть «ил на затопленном дворе».
4. **Рассказчик v17 для первого прихода не годится.**
   - Его инструкция — тысячи слов правил для хода с действием.
   - На «осмотреться» qwen либо выгружает каталог (качество 1), либо даёт пару строк.
   - Упаковка v17 теряет категории: видимых зверей, рыбу.
5. **Разговор в v17 пуст.** Модели разговора не передаются место, погода, облик собеседника, характер и цели (D1). В нашем пакете:
   - вещи не разрешаются в названия;
   - отношения между NPC — null;
   - характеры рыбака и перевозчика почти одинаковы;
   - знания WK общие, не по делу.
6. **Жизнь места в v17 до LLM не доходит.**
   - Распорядок дня только у 5 NPC старого сценария, и все его фазы помечены `decision_required: false`.
   - Погода и свет не подключены.
   - Распорядок двора в пакете взят из другого сценария, состав двора дан диапазоном.
7. **qwen стабильно хуже по верности (2 против 3–5).** Даже при тех же данных он противоречит им: сухо → «вязкий ил», 15:00 → «вечер», 5 июля → 15 июля. Он выдумывает цены и имена (Дмитр → Дмитрий). Для слабой модели подача должна быть короче, с приоритетом, по-русски, с явными «нет».

## Что исправлять

- **Данные (игровая база, слой «вещи»).**
  - Переделать частоты вещей под живую сцену по типу места.
  - Рукотворное в диком месте — только с причиной (стан, брошенная снасть).
  - Убрать дубли.
  - Разделить «находки при обыске» и «видно сразу».
- **Данные (места).** Главный объект места (лодка или плот на перевозе, постройки двора) и сенсорный профиль типа места по сезонам:
  - вода, рельеф, ветер, снег, запахи.
- **Данные (люди).** Правила присутствия людей, бросок состава двора, распорядки по занятиям для этого места.
- **Код (построение пакета для рассказчика).**
  - Русские формулировки вместо кодов.
  - Ранжирование по заметности и бюджет (10–20 главных деталей).
  - Группировка по зонам.
  - Честные «видно / слышно / следы».
  - Фазы света с рассветом и сумерками.
  - Явные «людей нет».
  - Без служебных полей.
- **Код (рассказчик).** Отдельная инструкция первого прихода вместо правил хода с действием.
- **Код (разговор).** Передавать место, погоду, время, видимый облик собеседника, характер и цели говорящего (D1), отношения.
- **Код (жизнь места).** Подключить погоду, свет и распорядки (известные долги v17).
