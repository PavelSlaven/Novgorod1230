В выборке: 216 (wrong), 211, 221 (minor). Вне выборки та же серия: row 201 «соха (раскладка)» (note сам говорит «нормы по поздним (XV в.) данным», но period=c1230), row 212 «сбор войска … по сохам», row 215 «рубленые люди» — сошный набор и «рубленые люди» документированы для XV в.; для 1230 не подтверждены.
2. **Датировка типов доспеха/терминов не проверена по «редкости» для 1230:** чешуя (160; ср. 622242/2109 — в домонгольской Руси только по изображениям), термин «яловец» (158). 3. **Спорные интерпретации военных историков без note:** Разин о гридях и пригородах (194, 195).
4. **Confidence:** 570382 оценено A по типу книги в индексе (archaeology_report), фактически исследование — B.
