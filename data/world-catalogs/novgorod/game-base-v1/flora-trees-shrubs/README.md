# flora-trees-shrubs — деревья, кустарники, кустарнички (game-base-v1)

Статус: **candidate**, не утверждено. Сборщик сам себя не утверждает (WR §21.1). Нужен отдельный проход утверждения (Opus high или владелец).

Домен каталога: `flora_trees_shrubs` (группа `flora-trees-shrubs`, приоритет M2c).

## Что здесь

Сюда вошли древесные растения южнотаёжной Новгородской земли около 1230 года. Это деревья, кустарники и небягодные кустарнички, которые человек видит и использует. Ягодные кустарнички и кустарники (Vaccinium, Rubus, Ribes, Empetrum, Arctostaphylos) и линнея относятся к домену `flora-herbs-berries-mushrooms`.

Таксоны — универсальные категории без региона. Разрешение для региона задаётся только строками присутствия с `region_id = region_novgorod_land`. Так закрыто замечание критика о том, что универсальный слой не отделён от регионального.

## Как пересобрать

```
node scripts/build.mjs      # scripts/src/*.json -> flora/*.csv + reports/build-report.json
node scripts/validate.mjs   # приёмка -> reports/validate-report.json, exit 1 при ошибке
```

Источники правятся только в `scripts/src/`:
- `taxa.json` — авторская таблица таксонов;
- `habitat_roles.json` — роль таксона в семействе мест, с основанием и ссылками;
- `sources.json`;
- `denylist.json`;
- `kolchin_table1.json` — перенос табл. I;
- `world_db_landscape_templates_snapshot.tsv` — снимок `psql` от 2026-09-26.

Скрипты читают `places-binding/places/place_families.csv`, `places-binding/presence/frequency_rule.json` и `world-knowledge/production-v1/runtime-bundle.json`.

## Метод

1. **Сначала имеющиеся знания.** Из WK взяты все approved claims о деревьях: residual-tree-properties (12), wild-flora (Daphne), static-plant-use (лещина, яблоня), environment-ecology (Троицкий раскоп), environment-biology (Salix alba), final-nature-gap-closure (листопадность, луб), строительные и материальные claims (сосна и ель в срубах, дубовая дрань, осиновая обшивка, лыковая вица и сосновая смола на лодке №1, ясеневый лук XIII в., берестяные туеса, берёзовый дёготь, межевой дуб). Всего в таксонах и строках проверено 1423 ссылки; все wk-ссылки находятся в `runtime-bundle.json`. Использованы также:
   - MASTER: ING0067 (рябина, археоботаника), ING0072 (яблоки), ING0074 (лесной орех), OMI00033–00160 (прутья, береста, еловые и сосновые корни, живица, дёготь);
   - кандидат богатства PR #98 (роды Pinus, Picea, Betula, Salix, Alnus);
   - `landscape_templates.dominant_vegetation`.
2. **Главный исторический источник — Колчин 1968** (САИ Е1-55; локальный скан, прочитан визуально, с. 11–13 и 49–50). По нему:
   - в лесах Новгородской земли преобладали хвойные, главным образом ель, сосны меньше;
   - ель росла по низинам и на более плодородных землях, сосна — на сухих песках;
   - липа и ольха растут повсеместно, клён тоже, но занимает меньше места;
   - дуб и ясень растут только в южных районах;
   - встречаются осина, берёза, вяз, ильм, черёмуха, рябина;
   - в изделиях определено 19 местных и 8 привозных пород;
   - описаны свойства и применение каждой породы.
3. **Экология и фенология видов** взяты из статей энциклопедии (ru.wikipedia, открыты 2026-09-26; confidence источника B) и Плантариума. Региональные данные дают Валдайский национальный парк, Летопись природы Рдейского заповедника за 2012 год (зарастание полей) и обзор nbcrs. Месяцы в источниках современные (григорианские) и относятся в основном к средней полосе. В сезоны они переводятся скриптом по словарю places-binding/temporal-v4: winter 12–2, spring 3–5, summer 6–8, autumn 9–11. Распускание листьев относится к весне по данным о климате: «вегетация начинается обычно в начале мая». Листопад относится к осени по WK claim `final-nature-deciduous-…`. Где источник не дал месяцев, поле пустое, а событие выводится только из формулировки («до распускания листьев»).
4. **Классы частоты выводятся по заявленному правилу** (`habitat_roles.json#rule`). Сборщик читает формулировку источника и присваивает роль, а класс следует только из роли:
   - edificator → 8;
   - component → 4;
   - occasional → 2;
   - rare → 1.

   `probability_ppm` считается по формуле places-binding: round(1e6·w/8). Счёт изделий у Колчина **не** используется для классов, потому что это определения изделий, а не обилие в лесу. Семейства-наложения `pf_forest_track` и `pf_hunting_ground` скрипт выводит как максимум по лесным семействам (для hunting_ground ещё по опушке и болоту). Присутствие древесных не меняется по сезонам; по сезонам меняются `seasonal_state` и `visible_above_snow`.
5. **Confidence.** A — таксон подтверждён археоботаникой XIII в. (рябина, лещина). B — Колчин называет породу местной или региональный источник называет вид. C — присутствие выведено по современному ареалу или основание помечено «(C)». Строка присутствия получает худшее из confidence таксона и confidence основания.

## Проверки (validate.mjs, всё PASS)

- у каждого таксона есть хотя бы одна строка присутствия; `pf_id` есть в `place_families.csv`; класс и вес ∈ {8,4,2,1}; ppm пересчитывается; сезон есть в словаре;
- нет дублей (fl, pf, season); id уникальны; `lat` уникален;
- все `source_refs` резолвятся: wk в runtime-bundle, src в реестре с http(s) или существующим файлом, master — строка есть в файле;
- ни один таксон не совпадает с denylist ни по латинскому имени, ни по русскому ключевому слову;
- в каждом лесном семействе не меньше 5 древесных таксонов на каждый сезон;
- фенология заполнена на все 4 сезона; статус candidate;
- категории согласованы;
- сумма табл. I = 909.

## Находки для других владельцев

- **world_db landscape_templates** (draft) называют для шаблонов региона непригодные породы:
  - `lt_boreal_taiga_coniferous_forest` — лиственницу;
  - `lt_temperate_coniferous_forest` — пихту;
  - `lt_wooded_floodplain` — тополь. Из тополей в Новгородской земле аборигенна только осина.

  Шаблоны универсальные, но для region_novgorod_land эти породы не материализовать (`landscape_template_woody_check.csv`).
- **Согласование с соседом flora-herbs-berries-mushrooms.** Сосед пишет `pf_id` без префикса (`bog`), а сезоны у него winter 12–3 и spring 4–5. Здесь используются `pf_*` из `places-binding/places/place_families.csv` и сезоны 12–2/3–5/6–8/9–11 из `places-binding/presence/frequency_rule.json`. Координатору нужно выбрать одно.
- **cultivated_plants:** садовая яблоня (сады XI в. на Десятинном, WK `household-apple-orchard`) и груша. Груша у Колчина — 7 изделий, «местная или из центральных районов Руси»; дикая груша в Новгородской земле источниками не подтверждена, поэтому в таксоны не включена.
- **Хмель** (Humulus lupulus, лиана; WK: Троицкий раскоп, опоры и вода) не вошёл ни в этот домен, ни в список трав соседа. Нужно назначить ему владельца.
- **natural_materials / craft_processes:** `wood_use_kolchin1968.csv` даёт породы по видам изделий (клён — ложки и точёная посуда, ясень — только точёная посуда, дуб — полозья, бочки, лопаты, самшит — гребни, лиственница — судовые детали). Годится для проверки «из чего можно сделать вещь».

## Известные пробелы

- **name_old_ru пуст у всех таксонов.** Древнерусские формы (Срезневский, берестяные грамоты, топонимы) не проверялись. Заполнены только народные названия из энциклопедических статей (верес, бредина, ветла, белотал, тальник, чернотал, волчье лыко, багно и др.). Для 1230 года они — C.
- **Нет количественного обилия по местам.** Есть только роли по формулировкам источников. Современный состав лесного фонда (берёза около 35 %, сосна 28 %, ель 22 %, осина 11 %) нашёлся лишь во вторичном пересказе без проверяемой ссылки и не использован. Палинологию Приильменья (Spiridonova & Aleshinskaya 2012) открыть не удалось: dokumen.pub сбрасывает соединение. Используется только одобренный claim WK о переувлажнении у Рюрикова городища.
- **Нет региональных дат фенофаз.** Летопись Рдейского заповедника за 2012 год фенологии растений не содержит, другие годы не скачались. Месяцы взяты из общих статей о видах (средняя полоса). Для Новгорода фазы, вероятно, на 1–2 недели позже; отдельно не сдвигались. Юлианский календарь 1230 года отстаёт от григорианского примерно на 7 дней; сдвиг не вводился.
- **Месяцев цветения и плодоношения нет** у сосны, берёз, осины, ивы ушастой, ивы мирзинолистной, крушины, яблони (плоды) и вяза гладкого (плоды): источник их не дал.
- **Перцептивные признаки** (кора, лист) частью взяты из общей морфологии вида (например, «лопастные листья» дуба, «непарноперистые» ясеня); это уровень C. Звуки на ветру есть только у осины (трепет листьев), дуба (сухая листва зимой) и медоносов (гул пчёл). Снеговая нагрузка описана качественно в `winter_look`, без чисел.
- **Не включены по недостатку данных** (не подтверждено присутствие в Новгородской земле):
  - Betula nana — Плантариум называет Красные книги Тверской, Псковской и Ярославской областей, Новгородской в списке нет;
  - Myrica gale — северо-запад России в целом, побережья;
  - Rhamnus cathartica;
  - Salix phylicifolia и S. lapponum;
  - Salix fragilis;
  - Populus nigra.
- **Salix alba оставлена с confidence C и классом rare.** Аборигенность на северо-западе источником не подтверждена.
- **Колчин даёт «вяз» и «ильм» без латыни.** Отнесение ильма к U. glabra, а вяза к U. laevis — реконструкция.
- **Wood Use in Medieval Novgorod (Brisbane & Hather 2007)** использован только по поисковой выдержке (HTTP 403). Там тот же список местных пород.
- **Не использованы:** Кирьянов (МИА 65) и Колчин 1968 глава о лыке/бересте в полном объёме. Взяты только с. 49–50.
- **Удалено при переделке 2026-09-26 (не нашлось источника):** народное название «вересчаток» у вереска (в статье ru.wikipedia не найдено) и использование «кровля» у вереска (в статье не найдено — судя по всему западноевропейская кровельная традиция, отдельно не подтверждённая ни для вереска, ни для Новгорода). См. `VERIFICATION.md#Исправления 2026-09-26`.
