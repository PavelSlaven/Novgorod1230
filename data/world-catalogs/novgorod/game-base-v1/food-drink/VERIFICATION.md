## Исправления 2026-09-26

Исправлен файл, помеченный `rework`: `dishes/meal_slot_rules.csv`.

- **Причина.** В `scripts/build.py` (строка 543, до правки) `slot_names_ru` строился как `[x['name_ru'] for x in RUL['meal_slots']['slots'] if x['slot_id'] in s['slots']]` — фильтрацией по фиксированному порядку определения слотов (`morning, midday, evening, field_carry, feast`), а не по порядку `s['slots']` конкретного правила. Для правил, где `field_carry` стоял между `morning` и `evening` (`ms_02`, `ms_03`, `ms_04`), это давало порядок `morning, evening, field_carry` вместо `morning, field_carry, evening` — `field_carry` подписывался как «вечеря», а «еда, взятая с собой» съезжала на последнее место.
- **Правка.** `scripts/build.py`: добавлен словарь `_slot_name_by_id = {x['slot_id']: x['name_ru'] for x in RUL['meal_slots']['slots']}`; `slot_names_ru` теперь строится как `[_slot_name_by_id[sid] for sid in s['slots']]` — по порядку самого правила `s['slots']`, а не по порядку определения. Правило `by_class_season` в `scripts/curated/curated_rules.json` не менялось — ошибка была только в сборке, не в исходных данных.
- **Пересборка.** `python scripts/build.py` запущен целиком (детерминированный полный ре-run группы `food-drink`); все 14 выходных файлов regenerated. `ms_02`, `ms_03`, `ms_04` в `dishes/meal_slot_rules.csv` теперь дают `slot_names_ru=["утренняя еда", "еда, взятая с собой", "вечеря"]` для `slots=["morning", "field_carry", "evening"]` — выровнено корректно. Остальные строки (`ms_01`, `ms_05`–`ms_10`) не изменились, порядок слотов у них уже совпадал.
- **Проверка.** `python scripts/check.py` перезапущен: `RESULT PASS 0`, 4045 ссылок, 0 срабатываний denylist — совпадает с исходным прогоном верификатора. Счётчики строк во всех 14 файлах (в т.ч. `dishes/meal_slot_rules.csv` = 10) не изменились и совпадают с README.
- **Другие файлы.** Не трогались сверх того, что генерирует общий `build.py` при полном ре-run (остальные 13 выходных файлов регенерированы тем же прогоном без содержательных изменений, кроме известного и не входящего в это исправление недетерминированного порядка `spoilage_states` в `dishes/dishes_meals.csv`, отмеченного верификатором отдельно и не входящего в состав `rework`-файла).
- **README.** Изменений количества строк не требовалось — README `dishes/meal_slot_rules.csv = 10` уже соответствует пересобранному файлу.
- **Не исправлено в этом проходе (вне scope `rework`).** Остальные `approve_with_limits`-замечания верификатора (`sensory_lexicon.match_subcategory`, `build.py:450` sorted(cats), `storage_forms`/`preservation_storage.fd_ids`, `taxon_refs.expected_sibling_domain`, уверенность деталей `recipe_steps`) не тронуты — они относятся к другим файлам, не помеченным `rework` в этой задаче.
