# Material/craft readiness assessment — compiled 420 pack

**Status:** independent read-only assessment. Checked current
`production-v1/runtime-bundle.json` (420 claims, 378 concepts) and the stated
family cells in `archive-v1/coverage-matrix.json`. No matrix, source,
authoring, production, or pipeline artifact was changed.

## Method and boundary

Each row asks whether a production-shaped unseen request can be grounded by
composing existing historical/physical premises. It does **not** require a
scene item, stock, owner, permission, completed craft, numerical mechanics,
one recipe per object, or exhaustive material taxonomy. Those remain state,
materialization, access, process, and mechanics owners. A row stays partial
only where a real prerequisite lacks both historical and physical support.

Raw core lexical retrieval was used only as a diagnostic; production uses
planner/hybrid retrieval, so an exact player wording miss alone is not a
family gap. Conversely, a generic physics fact is not substituted for a
missing historical material/process premise.

## Uncompiled TRC boundary

The five verified `TRC-*` candidates are **not** counted as implemented. If
root later compiles them with their verification limits, TRC-01 would narrow
only specialist limestone/shell-rock quarry procurement for monumental
projects, TRC-03/05 only specialist brick/plinth context, and TRC-02/04 only
project labour/masonry context. They would not close household ceramic,
ordinary stone/soil source, lime/glass, or terrain-source gaps.

## Verdict

Recommend only `wk:material:nonferrous` as **covered** at stated family scope.
All other listed cells retain `partial` with the concrete research paths above.
This is not a request for closed craft recipes, scene inventory, exact modern
numbers, or ontology completion; it preserves missing real historical/physical
premises where they materially affect an unseen production attempt.
