# activities_new_occupations.csv

20 кандидатных наблюдаемых действий на 19 занятий. `pf_id` резолвится в
`places-binding/places/place_families.csv` как возможный контекст сцены;
присутствие или количество людей этим не устанавливается. Для костореза и
токаря входной материал и выходная вещь резолвятся в каталоги материалов и
предметов. У остальных входы/выходы пусты, поскольку конкретные пары
предметов не подтверждены. Два действия токаря образуют цепочку: изготовление
точёной миски в мастерской → показ готовой миски на торгу. Показ не создаёт
сделку, цену или нового владельца.

Полный presence crosswalk остаётся у C002. Этот файл не активирует действия.

`rule:occupation_property_to_pf` — ручной выбор возможного семейства места
по описанию занятия, без привязки присутствия. У известежога ближайший
контекст — край города (`pf_town_wall_edge`), точная семья обжиговой ямы
не установлена (`no_source:exact_lime_kiln_place_family`); видимый обжиг
ограничен летом и осенью. У каменщика рабочий сигнал — весна–осень,
у остальных сезонный сигнал не подтверждён расписанием и пока охватывает
четыре сезона. `confidence=C` у каждого сигнала: перенос описания занятия
в наблюдаемую сцену — кандидатное правило, не новая аттестация. Сигнал
показывает одну сцену в своём `pf_id`; торговые сцены не совмещаются с
мастерской или двором.
