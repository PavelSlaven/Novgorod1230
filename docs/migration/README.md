# Архив завершённой архитектурной миграции

Статус: **завершено**. Архив зафиксирован 13 июля 2026 года после объединения финального восстановительного PR и успешного прохождения clean-clone CI, полного набора тестов, проверок схемы, корпуса и generated artifacts.

Этот раздел хранит исторические планы, отчёты, parity-материалы, evidence и контракты периода перехода на модульную архитектуру. Он не является основной документацией текущего проекта и не должен использоваться как источник актуального статуса игры.

Актуальные точки входа:

- [`README.md`](../../README.md) — описание игры и текущая структура репозитория;
- [`MODULE_INDEX.md`](../../MODULE_INDEX.md) — индекс действующих модулей;
- [`docs/architecture`](../architecture) — действующие архитектурные правила;
- [`docs/pipelines`](../pipelines) — действующие конвейеры;
- [`data/knowledge-source`](../../data/knowledge-source) — нормативный корпус;
- [`infra/world-base`](../../infra/world-base) — схема канонической базы мира.

## Состав архива

- `plans/` — планы завершённых фаз;
- `reports/` — отчёты, проверки и release evidence;
- `contracts/` — карты контрактов периода перехода;
- `parity/` — отчёты сопоставления модульной и прежней реализаций;
- `finalization/` — материалы операторской и владельческой проверки;
- `archive/` — перенесённые корневые сводки;
- `SOURCE_PROVENANCE.md` — происхождение исходного кода, корпуса и архивов;
- `CANONICAL_PATHS.json` — исторический реестр путей, использовавшийся при переходе.

## Ограничение

Завершение перехода не означает автоматического удаления rollback-кода или исторических evidence-файлов. Их удаление допускается только отдельным осознанным изменением после проверки действующих зависимостей.
