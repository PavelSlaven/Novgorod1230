# health_body — здоровье, тело, болезни, уход (candidate)

## Что здесь

- `health_entities.csv` — 54 сущности, агрегированные скриптом из верифицированной книжной доказательной базы (`../sources/book_evidence_transport_health_recreation.csv`, домен `health_body`, 68 фактов), включая специализированную монографию по медицине Древней Руси (book_id 728823). Состав по `kind`: роли лечения (лечец, резалник, мирской лечец, иноземные лекари — 6), народная практика (волхвы, знахарки, заговоры, наузы — 5, помечены `historical practice only, not medical advice`), баня и роды (5), болезни (лихорадка/огневица, проказа, эрготизм, утин — 6), травмы (рана мечом, побои, трепанация, охотничьи травмы — 4), уход (уход за ранеными/больными, княжеская милостыня — 3), эпидемии/мор (мор в Новгороде 1187 г., Смоленске 1230 г., Пскове и Изборске 1237 г., Полоцке 1092 г.; четыре записи с «мором»), голод и холопство от голода (3 отдельные сущности; смоленский мор 1230 г. не отождествляется с голодом 1230–31 гг.), детство и взросление (постриг, посажение на коня, кормильцы — 4), демография (продолжительность жизни, палеопатология городского населения — 2), институциональная забота (монастырская больница, монастыри — 2), конский мор (1), прочее — Вопрошание Кирика, диета по месяцам, скудельница и др. (11).

## Метод

Идентичен `transport_travel`: `scripts/build.cjs` группирует книжные факты по `entity_ru`, строит `facts_summary`, `source_refs` (`book:<id> §<section> ¶<para>`), консервативную `confidence`. `kind` — классификация по регулярным выражениям (детерминированная); для `мор` граница слова распознаёт кириллические буквы, а специальная форма `конский мор` остаётся болезнью животных. Поле `period_care_practice_note` помечает народную/языческую практику как историческую, не медицинский совет; у `hlb_020` оно хранит региональную оговорку и три пробела источника.

## Источники

- Книжная доказательная база: 54 сущности / 68 фактов, включая монографию по медицине Древней Руси (историко-медицинский раздел X–XIII вв., устав Владимира о церковных людях, «Вопрошание Кирика»), «Древняя Русь. Быт и культура» (баня, роды, детство, палеопатология). Верификация — `../sources/book_evidence.VERIFICATION.md`; отклонённых строк по домену нет.
- WK production-v1, упомянутые в брифе (не читались построчно в этой сессии, только имена файлов подтверждены наличием в `data/world-catalogs/novgorod/world-knowledge/production-v1/`): `biology-physiology.json` (476 approved), `reconstructed-human-lifeways-v1.json` — вероятный носитель `reconstructed-healer-practice-v1` и `residual-postpartum-v1` (точные id claim не сверялись, требуется точечный `rg` по claim id в следующем проходе).
- `temporal-v4 body_time_effect_profiles` (4, approved) — упомянут в брифе, не найден в скопированных `sources/`; вероятно живёт в основном checkout вне зоны чтения этой сессии (только `Novgorod-game-base` и явно перечисленные пути были read-only доступны).

## Пробелы (для владельца/следующего прохода)

- Структурированных полей `course_stages` (течение болезни по стадиям), `visible_signs` (видимые признаки) и `season_risk` нет в CSV-схеме. Для `hlb_020` источник сообщает о массовых захоронениях после мора в Смоленске, но не описывает течение болезни, видимые признаки или сезонный риск; эти три пробела прямо указаны в `period_care_practice_note`. Пробелы не заполняются реконструкцией клинической картины.
- Для остальных состояний сведения о видимых признаках частично остаются в `facts_summary` (например, огневица/лихорадка, проказа — кожные признаки), без отдельного построчного поля.
- `hlb_020` сохраняет событие 1230 г. в Смоленске. Источник не относит этот мор к Новгороду и не даёт оснований связывать его с новгородским голодом 1230–31 гг.; отдельная новгородская запись о море не создаётся.
- Ссылки `WK biology_physiology 476` не резолвились построчно (нет id-уровневого сопоставления сущность↔claim); задача для авторского прохода с доступом к полному WK claim registry.
