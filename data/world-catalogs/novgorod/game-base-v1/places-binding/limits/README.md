Статус: **candidate**. Скрипт: `scripts/build-generation-limits.mjs`. Черновик аудита используется только для сверки и не копируется.

## Что здесь

| Файл | Строк | Что |
|---|---|---|
| `place_generation_limits.csv` | 105 | 29 строк по типу места (place_template × scale_class × текст оценки из v6), 44 строки по семейству мест, 32 строки по G4 v17. |
| `audit_comparison.csv` | 256 | Сверка с `nov-region-audit-v1/novgorod_region_generation_limits_v1.json` (draft LLM): 53 равны, 182 расходятся, 21 без нашего значения. |

## Правила

- **R1. Дворы.** Из `household_estimate` реестра v6 (`novgorod_g3_scale_register_v6.tsv`, 911 строк) берётся первый диапазон «N-M», за которым первым существительным идёт «двор» (двора, дворов, дворы; прилагательное «дворовых» не считается). Если текст начинается с «1 … двор с …», к обеим границам прибавляется 1 главный двор. Итог: 27 из 29 типов. Нет дворов у pt_monastery (численность «задаётся сценой») и у pt_administrative_court (указаны люди, а не дворы).
- **R2. Жители.** Заполняются, только если после диапазона стоит «людей» или «человек». Такой тип один: pt_administrative_court, 10–80. В WK, MASTER и v6 нет источника «человек на двор». Поиск в вебе (2026-09-26) не дал цитируемой цифры для XIII века; первые переписи Новгородской земли — конец XV века. Поэтому остальные жители — gap.
- **R3. Число G4-зон.** Берётся из `g4_target` v6.
- **R4. Значимые предметы по семейству.** Максимум `max_concrete_items` по профилям MASTER `spawn_profiles`, чьи архетипы места переведены в это семейство (`places/crosswalk_master_location_archetypes.csv`). Значение есть у 29 семейств из 44.
- **R5. G4 v17.**
  - `npc_present_min/max` берутся из `min_count/max_count` pr98 `m2c-npc/candidate.json` `g4_compositions` (candidate_approval_pending). Это авторская игровая реконструкция, а не оценка населения.
  - `g5_anchor_max` — число канонических G5-детей (закрытый набор).
  - `items_notable_max` — значение R4 для основного pf узла.

## Известные пробелы

- **Нет базы.** `containers_max` пуст везде, как и жители для всех типов, кроме одного.
- **Нет v6 для v17.** Дворов для узлов v17 нет: стартовая территория (низовья Двины) не входит в граф v6.
- **Нет DDL-колонок.** В `world_base.place_generation_limits` (06.sql) нет колонок дворов и жителей: там `max_total` и `density_logic`. Для переноса нужен CR на DDL или сопоставление полей.
- **Проводки нет.** Потребителя в v17 нет: нужна проводка в `@rus/materialization`.
