# Стартовая материализация G5 v1

Назначение: зафиксировать процедуру создания первой точной сценической сцены G5 внутри уже выбранной G4-локации при старте партии.

## Что делает пакет

1. Берёт уже выбранный G4-контекст из генератора новой партии.
2. Подбирает региональный G5-шаблон по `g4_type_id`.
3. Проверяет существующее party-state, чтобы не дублировать факты.
4. Через LLM материализует G5-минилокации, якоря сцены и короткие G5-связи.
5. Аудирует видимость, доступ, владение, свидетелей, риски, предметы и NPC.
6. Формирует безопасный видимый пакет для вводной прозы.
7. Пишет результат в `party_database_v1` только после commit gate.

## Главное ограничение

G5 не создаётся заранее для всей карты. Он создаётся только внутри существующего G4 и только при причинном основании. Код не создаёт якоря, предметы, NPC или скрытые факты вместо LLM.

## Статус

`draft_for_implementation`. Пакет готов как спецификация, набор контрактов, CSV/XLSX-аудит и каркас оркестратора.
