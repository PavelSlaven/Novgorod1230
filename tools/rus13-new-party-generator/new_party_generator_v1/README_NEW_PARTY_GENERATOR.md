# Генератор новой партии v1

Назначение: зафиксировать порядок создания новой партии из свободного описания игрока без процедурного сочинения мира кодом.

Пакет связывает:

1. read-only `world_base`, уже импортированный и FK-проверенный;
2. `party_database_v1`, где хранится изменяемое состояние конкретной партии;
3. LLM-контракты генерации стартовой рамки, места, персонажа, NPC, предметов, маршрутов и вводной прозы;
4. validation/repair gates, которые возвращают ошибочный смысловой результат LLM на доработку.

## Главное правило

Код не создаёт персонажей, места, предметы, причины, связи и исторические последствия. Код только передаёт контекст, проверяет структуру, фиксирует утверждённые результаты и откатывает транзакцию при ошибке.

## Состав

- `new_party_generator_v1.json` — основной манифест.
- `new_party_generator_v1.xlsx` — человекочитаемая таблица этапов, контрактов, записей и правил.
- `contracts/*.schema.json` — JSON Schema для контрактов LLM.
- `prompts/*.md` — шаблоны промтов агентов.
- `sql/new_party_generator_transaction_outline_v1.sql` — порядок фиксации старта партии.
- `scripts/new_party_generator_orchestrator_v1.py` — безопасный скелет оркестратора без code-side world generation.
- `csv/*.csv` — импортируемые таблицы для аудита.

## Статус

`draft_for_implementation`. Это спецификация и каркас. Для production нужно подключить реальные LLM-вызовы, JSON validation, SQL transaction layer и repair pipeline.
