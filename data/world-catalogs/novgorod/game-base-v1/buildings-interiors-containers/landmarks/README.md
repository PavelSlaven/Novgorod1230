# landmarks — названные объекты и учреждения Новгорода 1230 (candidate)

Домен: `city_landmarks_institutions` (приоритет M3). Authority-записи, чтобы LLM не выдумывал храмы, дворы и улицы.

`landmarks.csv` — 76 строк: импорт курированной SQLite `novgorod_1230(1) (1).sqlite` (city_features 35, ends 5, streets 15, institutions 12) + 9 дополнений (Хутынский, Юрьев, Антониев монастыри, Рюриково Городище, пять вымолов Торговой стороны).

Категории: church 16, street 15, institution 12, building_type_ref 6, end 5, wharf 5, court 4, monastery 3, fortification 2, foreign_court 2, infrastructure 2, bridge 1, market 1, building 1, burial 1. Статус 1230: существует 67, вероятно существует 7, строится/эксплуатируется 1 (Великий мост, 1229–1230), создаётся 1 (скудельница 1230 г.). Уверенность: A 38, B 35, C 3.

## Метод

- Поля SQLite переносятся без правки (дата, материал, status_1230, confidence, reconstruction, sources S01–S30 → `nov1230db:S##`).
- `category` нормализована скриптом; `building_type_ref` — строки SQLite о типах (избы, амбары, бани, мастерские), они продублированы как типы в `buildings/`.
- Дополнения: Хутынский монастырь — основан 1192, деревянный, затем каменный храм Спаса (ref:novgorodmuseum_khutyn, B); Юрьев и Антониев — по датам соборов (B018, B019); Городище — nov1230db P002; вымолы — claim WK `river-landing-named-list` (Устав, датировка дискуссионна, B).
- `v6_name_match` — совпадение имени с v6 naming_register (подстрока); пусто = новое имя с источником (41 предупреждение validate).

## Приёмка

У каждого объекта есть `status_1230` и `source_refs`; объектов с датой постройки после 1250 нет (проверка скриптом по годам в `founded_or_built`).
