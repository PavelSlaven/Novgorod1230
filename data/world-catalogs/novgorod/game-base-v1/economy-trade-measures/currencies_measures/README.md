# currencies_measures — денежные единицы и меры (candidate)

Домен группы `economy-trade-measures`, коллектор `collect-economy-trade-measures`. Статус: **candidate** (не утверждено; утверждение — отдельный проход старшей модели, не сборщика).

## Что здесь

- `currency_units.csv` (15 строк) — денежные единицы Новгорода ~1230 г.: гривна серебра, гривна кун, ногата, куна, резана, векша/бела, рубленое серебро, иноземная монета, немецкий слиток-марка, киевский шестиугольный слиток, меховые деньги (эпизодично), явный anachronism-guard против «кожаных денег», товар как форма платежа.
- `measure_units.csv` (20 строк) — меры длины (пядь, локоть, локоть иванский, сажень и её виды, верста), веса (пуд, берковец, капь, безмен, золотник, почка), сыпучих и жидких (кадь, уборок, лукно, голважня, ведро, бочка новгородская, дежа, коробья).
- `scripts/build_currencies_measures.mjs` — детерминированный генератор обеих таблиц из зафиксированных в скрипте фактов с source_refs (запускать при правке данных).
- `scripts/validate_currency_ratios.mjs` — проверяет: (1) у денежных единиц с `ratio_to_kuna` физического типа задан `item_template_ref`; (2) числовые соотношения образуют непротиворечивый граф (гривна кун=20 ногат=50 кун, гривна серебра=4 гривны кун, круговой пересчёт даёт 1); (3) базовые единицы 1230 г. покрывают `1230-1250` в `period_validity`. Текущий результат: **PASS** (1 намеренный gap помечен, см. ниже).

## Метод

1. Извлечение из уже одобренных источников: `data/world-catalogs/novgorod/sources/master-archive-v1/data/economy_social/{currencies,units_and_measures}.csv` (region audit, approved), `wk:trade-economy-gap-closure-v1` / `wk:trade-economy-batch-03-gap-closure-v1` (WK production-v1, approved), matcult `material_items.csv` (item_template_ref: TRD0046 гривна-слиток, CRF0068 слиток серебра, TRD0043/FRN0046 иноземная монета).
2. Закрытие реального разрыва «соотношения единиц не утверждены» — через book-evidence по группе `economy-trade-measures`, независимо проверенный на удалённой машине 26.09.2026 (`economy-trade-measures.VERIFICATION.md`, выборка 37/244, ok 81%, minor 19%, wrong 0%) и затем исправленный (`economy-trade-measures.FIXES.md`, 38 строк исправлено, 0 удалено, `d_validate` 244/244). Основной источник числовых соотношений — В. Л. Янин, «Денежно-весовые системы домонгольской Руси…» (2009), с прямой привязкой к Смоленскому договору 1229 г. для гривны серебра/гривны кун. Полные библиографические данные — `../sources/books.csv`.
3. Каждая строка с числовым соотношением проверена скриптом на цикличность (пересчёт по кругу = 1); строки без числа (векша, берковец/капь на 1230 г., большинство мелких сыпучих мер) оставлены как `unresolved`/`context_dependent` с confidence C и явной оговоркой в `ratio_basis`, а не с придуманным числом (правило проекта: «Frequencies/weights только по стате правилу, никогда не выдуманные числа»).

## Известные ограничения и gaps

- **Векша/бела**: курс к гривне для 1230 г. не устанавливается источниками (норма 1/200 гривны — только источники XV в.). Оставлено `unresolved`.
- **Берковец, капь**: точные числовые соотношения к пуду зафиксированы договорами 1269/1269 гг. — ПОЗЖЕ 1230 г. Единицы существуют раньше (капь — по грамоте №439, договор 1229), но их курс к пуду для 1230 г. не подтверждён; помечено C с явным anachronism-guard в `ratio_basis`.
- **Кадь**: метрический эквивалент (≈229 кг) — ретроспективный пересчёт через позднейший московский пуд (Никитский), не прямое измерение 1230 г.; региональная вариация подтверждена (кадь ростовская ≠ новгородская). Не давать один универсальный литровый/килограммовый эквивалент по всем контекстам.
- **cu_german_ingot_import** не имеет `item_template_ref` в текущем matcult-каталоге (флагировано скриптом) — реальный gap: нет предмета «немецкий слиток-марка» в material_items.csv.
- **Уборок, лукно, голважня, дежа, ведро**: единицы засвидетельствованы Правдой Русской/берестяными грамотами (confidence A по прямому первоисточнику), но их физический объём не установлен ни одним источником этого корпуса — оставлены как named units without a metric value, а не как выдуманные литры.
- Соотношение денежной и весовой систем опирается на ОДНУ теоретическую реконструкцию (Янин); альтернативные счётные варианты (напр. «А се бещестие»: гривна серебра=7.5 гривны кун) существуют в источниках, но хронологически не привязаны к ~1230 г. — не включены в основную систему, зафиксированы только в `ratio_basis`-примечаниях как контекст, не как альтернативная строка таблицы (чтобы не создавать противоречивую параллельную систему).
- `item_template_ref` для мер длины/веса/сыпучих (не денег) не заполнялся — сами меры это счётные величины, а не предметы; отдельный gap для «эталонов мер как предметов» (напр. иванский локоть-эталон, вощаный пуд) уже отмечен в `trade_goods_markets` (Иванское сто/эталоны).
