# Общий gate `needs_check`

`scripts/check-needs-check.mjs` компилирует активные authoring-очереди в `needs_check_blockers.v1.json` и сверяет снимок с генераторами. Малые очереди блокируют по имени. Archive-строка блокирует по имени, когда `reason_code=unresolved` и `note` либо `source_request` содержит запрос источника (`запросить`, `требуется источник`, `source request`); все остальные archive-коды блокируют по своему ID. Name-блок archive-записи также проверяет её ID при включении entity; ID-блок не применяет scope, потому что ID уникален. Записи по имени используют `block_scope=global`, если в самой строке нет обоснованного исключения неоднозначности. `block_exception` — JSON-массив точных контекстов, снимающих совпадение.

ID-блок не запрещает уже разрешённые ссылки на archive item в частотах, размещении, trace, inventory или presence. Name-блок действует во всех сущностях и item-bearing таблицах. Проверяются `items-household-personal/items/{item_place_frequency,item_context_relations,item_place_trace_relations}.csv`, `occupations-activities/carried_inventories/carried_inventories.csv`, `buildings-interiors-containers/interiors/scene_items.csv`, `places-binding/presence/{presence_rules,environment_presence_authoring}.csv`, `clothing-appearance/garments/costume_disposition.csv`, `time-calendar-church/religion/church_practice.csv` и `items-weapons-armour/items/weapon_source_crosswalk.csv`. Совпадение по имени исключается из generated table только с gap-строкой, содержащей queue ID, причину и исходную строку. Runtime name-admission — следующий этап после PR #98; он использует тот же matcher и не читает живые authoring CSV.

Снять блок можно после проверки и решения по D38: утвердить запись в соответствующем каталоге или перенести позднюю форму в denylist, затем удалить её из очереди и пересобрать snapshot через `node scripts/check-needs-check.mjs --write`. Если archive ID есть и в BIC, и в crafts, редакционное решение и удаление должны затронуть обе очереди одним изменением. Одна смена confidence блок не снимает.

Сборщики и проверки вызывают gate после записи выходов: BIC, clothing, crafts, fauna, flora, food, household items, carried inventories, presence, religion, item frequency и item trace. `--check` завершает сборку ошибкой при непокрытом совпадении, незаполненной активной записи, неизвестном scope или устаревшем снимке.
