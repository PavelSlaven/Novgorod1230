# Источники

Состояние ссылок и описаний проверено на 2026-08-29. Порядок доверия: археология/музей → корпус берестяных грамот → письменные источники → близкая иконография → академические реконструкции → современные реконструкции.

Уровень доверия относится к самому источнику, а не автоматически ко всем выводам из него. Источник с широким диапазоном XI–XV вв. требует предметной датировки перед использованием конкретной формы.

## SRC001 — «Лёгкой поступью по мостовой. Обувь древнего Новгорода X–XV вв.»

- **Тип:** официальный музей / археология
- **Ссылка:** https://novgorodmuseum.ru/visit/sobytiya/legkoj-postupyu-po-mostovoj.-obuv-drevnego-novgoroda-x-xv-vv.
- **Подтверждает:** обувь; сапожное ремесло; сезонные принадлежности; женская и детская обувь; статус
- **Уровень доверия:** A / очень высокий
- **Описание:** Официальное описание выставки Новгородского музея-заповедника: основные типы обуви, более 200 предметов, мастерские XII–XIII вв., материалы, стельки, носки, ледоходные шипы, костяные коньки, шпоры и защитные поршни поверх дорогой обуви.
- **Оговорки:** Хронологический охват X–XV вв.; конкретный тип следует привязывать к публикации/датировке, а не ко всей выставке целиком.

## SRC002 — «Средневековые кожаные изделия из археологической коллекции Новгородского музея-заповедника»

- **Ссылка:** https://novgorodmuseum.ru/o-muzee-zapovednike/novosti/srednevekovye-kozhanye-izdeliya-iz-arheologicheskoj-kollekcii-novgorodskogo-muzeya-zapovednika-na-vystavke-v-tatarstane
- **Подтверждает:** кожаная обувь; сумки; кошели; чехлы; кожевенное ремесло

- **Описание:** Официальное сообщение о коллекции более чем из 160 новгородских кожаных предметов XI–XV вв.: обувь, сумки, кошельки, чехлы и производственный контекст.
- **Оговорки:** Обзорная публикация без полного предметного каталога; формы отдельных вещей требуют специализированных публикаций.
