# Material Culture of Novgorod around 1230 — dataset v1

## Назначение

Исторически ограничивающая база материальной культуры Великого Новгорода и Новгородской земли первой половины XIII века, с центром на 1230 год. Она предназначена для Imagen, игровых ассетов, процедурного наполнения сцен, NPC-инвентаря и проверки анахронизмов. Одежда персонажей сюда не включена: для неё используется отдельная costume-база.

База **не является закрытым whitelist мира**. Она задаёт подтверждённые формы, исторические границы, source refs и anti-patterns. Ordinary-детали, которых нет в каталоге, могут конкретизироваться внутри той же исторической, пространственной и причинной рамки; формулировка игрока или генератора сама по себе не доказывает существование предмета.

## Уровни уверенности

- **A** — прямое новгородское archaeological/architectural/written подтверждение либо очень близкий датированный комплекс;
- **B** — хорошая реконструкция по нескольким источникам Руси XII–XIII веков;
- **C** — осторожная реконструкция; нужен конкретный visual reference;
- **D** — спорно или поздно; research only, не использовать автоматически.

## Как пользоваться

1. Выберите `scene_id` или `item_id`.
2. Прочитайте confidence, period, source_ids, construction, dimensions, do_not_confuse_with и generation_policy.
3. Для A/B используйте prompt и refs; для C обязательно прикладывайте concrete image/plan; D исключайте из production generation.
4. Для сцены берите все required_item_ids, только часть allowed_item_ids и соблюдайте forbidden_item_ids.
5. Схематические PNG архива — навигационные, а не первичные источники. Внешние музейные/археологические страницы имеют статус `link_only`.

## Ограничения

- Центр — 1230; строгое окно 1200–1240; сравнительное 1180–1260.
- Голод 1230–1231 оформлен отдельным scene variant и не должен менять каждый дом/рынок.
- Деревянные здания часто известны по footprint и нижним венцам; крыша, верх и окна реконструктивнее.
- Поздний кирпичный Кремль, изба XIX века, современные породы, латный доспех и корабли Нового времени запрещены.
- Локальные PNG не копируют музейные фотографии и не подменяют sources.

## Структура

- `docs/` — методология, хронология, источники, visual rules и anti-patterns;
- `catalog/` — человекочитаемый каталог по разделам;
- `data/` — CSV/JSON;
- `images/` — local authorial schematic crops;
- `reference_sheets/` — thematic sheets;
- `prompts/` — master, scene и priority-item prompts.
