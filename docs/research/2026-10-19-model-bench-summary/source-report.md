# Стенды моделей: сводка результатов

Все стенды выбора моделей для команды Novgorod1230 (Codex и Claude). Здесь только итоговые числа и выводы; постановка, эталоны, ответы и оценки судей — в папке каждого стенда. Новый стенд — новый раздел сверху, с датой, решением владельца и ссылкой на папку.

Общие оговорки:

- **Прогонов мало.** На стендах с одним прогоном на ячейку разница меньше 1–3 баллов — шум. На стенде субагентов было 3 прогона на ячейку, и шум там — около 0.5 балла.
- **Цена.** Codex — по токенам из rollout и ставкам OpenAI; кредиты Codex = USD × 25. Claude — по токенам из транскриптов и прайсу API Anthropic. В подписке лимиты расходуются по своим правилам.
- **Судейство слепое, по кодам.** Карта кодов → моделей хранилась вне папки, которую видели судьи. С 20.10 судья и ревьюер — только Opus (D225).

## Сквозной вывод: бриф исполнителю

Исполнители — Codex, Sonnet и Haiku — чаще всего понимают и выполняют задание буквально. На противоречие в брифе они реагируют по-разному, но ни одна реакция не надёжна:

- **молча обходят противоречие** — 9 моделей Codex переписали тест, 6 ослабили его;
- **разрешают его по-своему** — Sonnet;
- **останавливаются** — Haiku, в 3 прогонах из 21.

Поэтому бриф пишется подробно и однозначно, без внутренних противоречий:

- пути;
- рамки правок;
- исключения из запретов;
- что считать готовым;
- чем проверить;
- что делать при конфликте задания с кодом.

Итог исполнителя координатор проверяет сам — по тестам и diff, а не по отчёту.
