# Dev-проба CDDA

**Не P3 GO; T09 не закрыт. Проза — «черновик, не сохранено».**
Сцена — вымышленный двор мастера; вне него остаётся обычный мир CDDA.

Из корня репозитория в PowerShell:

```powershell
.\tools\cataclysm-prototype\run-p3-dev.ps1
```

Launcher берёт существующие настройки Qwen из `%LOCALAPPDATA%\Novgorod1230\llm-settings.json`
по правилу владельца game-server. Файл не копируется и не меняется.
Для другого файла заранее задайте `$env:RUS_LLM_SETTINGS_PATH`.

Первый запуск требует подготовленного WSL-runtime в корне `~/cataclysm-recovery/task03-dev` (на ext4):
каталоги `runtime/cataclysm` (бинарник), `runtime/data`, `runtime/gfx` и `fixture/save`, без символьных ссылок.
Без `-NativeOnly` нужны ещё WSL Node v22.23.3 в `~/.local/share/novgorod/` и читаемый файл,
на который указывает `RUS_LLM_SETTINGS_PATH`. Иначе launcher остановится с сообщением.

Мир постоянный: WSL `/home/slaven/cataclysm-recovery/task03-dev/userdir`.
Первый запуск копирует fixture; повторный продолжает сохранение.
Стрелки — движение, `.` — ждать, `g` — подобрать, `i` — вещи.
`F12` — свободная фраза. При 2+ доступных видимых NPC появится «кому говоришь?».
Родной предел ввода — 1024 экранные колонки; длинная строка прокручивается.
Один NPC выбирается автоматически. `Esc` в выборе — никому: действие выполняется,
но NPC не отвечает. Ответы смотрите в родном журнале `P`.
Попробуйте: «Скажи дословно: „Привет, слышишь меня?“», затем вторую реплику.
Сохранить и продолжить: `Esc` → `e` (родной Quicksave).
Сохранить и выйти: `Esc` → `S` → `Y`; главное меню: `Q` → `Y`.
Родной autosave включён: 3600 ходов / минимум 5 реальных минут.
Сброс: та же команда с `-Reset`; старый userdir остаётся в `userdir-before-reset-*`.
Без LLM: та же команда с `-NativeOnly`.
При запуске с LLM настройки передаются в WSL; coordinator завершается при выходе.

Граница: `move`, `use_item`, `open`, `wait`, `speak`, `pickup`, радиус 1;
вне её мир не меняется, игрок сообщения не видит; причина — в `run/coordinator.log`.
Долгая речь (`sustained`) не поддерживается: мир не меняется.
Повышенный голос и крик используют один родной уровень крика.
Шёпот (loudness 1) родной звук CDDA не доносит даже до соседней клетки, его не слышит никто;
тихую речь ближайший NPC слышит с loudness 2.
NPC помнит разговор: мост пишет у NPC сырые записи услышанного, сказанного и молчания,
они не удаляются, переживают родное сохранение и входят в запрос ответа.
Молчание — выбор NPC: игрок, который видит NPC, получает описание его поведения.
Ответ NPC получает не больше одного исправления формы и одного исправления смысла, всего не больше
7 вызовов модели на ход игрока. Ответ, не прошедший проверку, выводится как «ответа нет» с причиной,
а не как молчание.
Поколения/экран восстановления и назначенное движение NPC не готовы.
В новом fixture на servak (`/srv/novgorod-work/scratch/fix04e-devworld/fixture-800-ru`) мода `test_data` нет: после загрузки и одного хода родной журнал `P` не содержит `test recurrence` и `You lost the conduct` (`/srv/novgorod-work/scratch/fix04e-devworld/journal-search.txt`). Русская запись о нарушении ограничения сохранена; перевод прочих родных названий проверяется отдельно.
