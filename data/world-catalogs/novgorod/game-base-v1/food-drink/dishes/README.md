К ним добавлены 2 блюда, засвидетельствованные текстом:

- **овсяный кисель** — ПВЛ 6505/997: цеж из овса, пшеницы или отрубей, «в немже варять кисель»;
- **сыта** — там же: мёд из медуши велено «росытити» водой.

Оба — B, как аналогия для Новгорода.

Поля:

- **Состав:** `ingredients` [{fd_id, role, qty_rule}]. Количества — «modern_reconstruction» из master или «unknown»; исторических количеств нет.
- **Процесс:** `process_ref` (шаги в `recipe_steps.csv`) и `craft_process_ref` (`pc_food_<subcategory>`, ожидаемый id домена craft_processes).
- **Посты:**
  - `fasting_compatible` выводится скриптом из обязательных ингредиентов:
    - `false` — если есть мясо, молочное, яйца или животный жир;
    - `fish_days_only` — если есть рыба;
    - `conditional_alcohol` — для хмельного;
    - иначе `true`.
  - Итог: true 126, fish_days_only 70, false 65, conditional_alcohol 9 (подсчёт скриптом, 2026-09-26).
  - `fasting_omit_optional` — необязательные скоромные ингредиенты, которые в пост опускают.
  - `fasting_day_rule_ids` — применимые правила из `fasting_rules.csv`.
- **Трапеза и доступ:** `meal_slots` (правило `dish_slot_rule`), `class_access`.
- **Хранение и порча:** `preservation_method`, `storage_refs`, `shelf_life`, `spoilage_states`.
- **Голод:** `famine_role` = `thin_version_ok`, если блюдо собирается только из зерна, бобовых, корней, рыбы или зелени — такие можно варить жиже в голод (правило master).
- **Для прозы:** `sensory_*_ru` из `sensory_lexicon.csv`; заполнено у 250 из 270, остальные — процессы.
- **Тело:** `satiety_band` (filling / moderate / light / negligible — правило C, калорий нет) и `body_effects` (intoxication_possible, undercooked_or_spoiled_illness_risk).
- **Уверенность:** `attestation_confidence` (тип блюда, из master) и `recipe_confidence`. Рецепт = C, если в master evidence_type реконструктивный: 220 ingredient_based + 25 comparative + 3 ethnographic.

Расхождение с master одно — `ds_fish_pan_fry_cautious`. В master оно «conditional», скрипт ставит `false`: обязательный ингредиент — животный жир.

## famine_1230.csv — 23 (A 18, C 5)

По НПЛ 6738–6739, SQLite и Temporal v4:

- мороз на Воздвижение (14.09.1230);
- цены: хлеб 8 кун; рожь 20 гривен за кадь (в дворах «пол 30»); пшеница 40; пшено 50; овёс 13;
- засвидетельствованные заменители: конина, псина и кошки, мох, сосна, липовая кора, лист ильма, неясное «ушь», падаль, мертвечина и людоедство;
- аналогии XVI в. (C): мякина, лебеда, крапива;
- социальные последствия: поджоги дворов, где «слышали рожь»; детей отдавали гостям за хлеб; исход из города; скудельница 3030;
- помощь: немцы из-за моря привезли жито и муку (1231);
- модификатор порций master (C, `needs_approved_profile`).

`materialization_policy` задаёт, как можно использовать запись:

- `famine_phase_only` — появляется только в фазе голода;
- `narration_by_evidence_only` — псина, кошки и людоедство: только слух, свидетельство, суд или след, никогда не рецепт и не запас;
- `price_band_input`, `state_of_world`, `not_materialized`.

## Проверки (check.py) — последний прогон PASS

1. Каждый ингредиент блюда, шага, профиля и запаса разрешается в fd_id.
2. У блюда с `fasting_compatible=true` нет обязательного мяса, молочного, яиц, животного жира или рыбы.
3. Реконструированные рецепты имеют confidence C.
4. Denylist анахронизмов (с границей слова).
5. У каждой строки есть source_refs, confidence A/B/C и status=candidate.
6. Ссылки разрешаются.

## Пробелы

- **Рецептура.** Нет исторических рецептов с количествами. Все количества — современная реконструкция.
- **Блюда без рецептуры.** Нет щей, ухи, блинов или пирогов в современной форме: master их отклонил, `rejected_recipes.csv` в `scripts/source_snapshot/`. Отдельного блюда из гречки тоже нет.
- **Пиво.** Сусло и пиво по записям — ingredient_based C. Прямой текст о пиве в Новгороде 1230 здесь не найден. Есть солод (WK, грамота) и хмель (грамоты № 706, 709).
- **Трапезы.** Трапезы по классу и сезону, число трапез и праздничные меню — реконструкция C.
- **Тело.** Насыщение дано только полосами. Связь с состоянием тела (M3) требует отдельного домена health_body.
- **Процессы.** `craft_process_ref` ждёт домен craft_processes.
