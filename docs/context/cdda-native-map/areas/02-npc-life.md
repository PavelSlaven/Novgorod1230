## 3. Точки расширения без форка

- **EOC по событиям**: `eoc_events::notify` (effect_on_condition.cpp:575) кэширует EOC типа EVENT по `event_type`; alpha-talker выбирается из ключей avatar_id, character, attacker, killer, npc. Полезные события (event.h): `camp_taken_over` :289, `character_wakes_up` :524, `character_falls_asleep` :532, `character_attempt_to_fall_asleep` :541, `falls_asleep_from_exhaustion` :680, `npc_becomes_hostile` :836. `event_bus.h` — `subscribe`/`unsubscribe` для C++-подписчиков.
- **Глобальный EOC с `recurrence`** (effect_on_condition.cpp:95-100, 121-124) + **`u_run_npc_eocs`(unique_ids)** — тик расписания для любых NPC, в т.ч. вне пузыря. `run_for_npcs: true` (:378-388) — только для NPC пузыря.
- **`effect_on_condition.load_existing_character`** вызывается из `npc::on_load` (npc.cpp:3557-3680) — хук догона времени при загрузке NPC.
- **JSON-флаги/данные**: `npc_class.work_hours`, `mission`, `attitude`, трейты (`RETURN_TO_START_POS`), `faction_mission`, `mission_definition`, `npc_behavior.json` (дерево и веса) — без пересборки.
- **Моды**: всё перечисленное в JSON/EOC — через мод. Новые предикаты/score BT (behavior_oracle.cpp:40-90) и новые работы в `find_job_to_perform` — только C++.
