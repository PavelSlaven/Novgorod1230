# @rus/game-web

Активный browser-клиент Novgorod1230. Он получает versioned player-safe read
models от `@rus/game-server` и не вычисляет игровые последствия.

- Границы модуля и публичный API: [MODULE.md](./MODULE.md).
- Production-пейзажи: [AUTHORED_LANDSCAPE_CONTRACT.md](./AUTHORED_LANDSCAPE_CONTRACT.md).
- Production-портреты Нижней Двины: [AUTHORED_PORTRAIT_CONTRACT.md](./AUTHORED_PORTRAIT_CONTRACT.md).
- `/portrait-lab` — отдельный экспериментальный процедурный renderer; он не
  является production actor/interlocutor path.
