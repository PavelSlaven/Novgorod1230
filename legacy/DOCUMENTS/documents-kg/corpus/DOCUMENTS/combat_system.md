## Боевая система

Бой — это рискованное действие в сцене, где персонажи пытаются нанести вред, защититься, сбежать, удержать позицию, обезоружить, схватить, запугать или выжить.

Бой не является отдельной мини-игрой с гарантированным обменом ударами. Он обрабатывается как серия намерений, проверок и последствий внутри текущей сцены.

Короткая цепочка:

`заявка → возможность действия → проверка → результат → вред/состояние → реакция NPC → последствия сцены`

Главный принцип: один боевой бросок должен давать и результат действия, и силу последствия. Не нужно отдельно бросать попадание, потом урон, потом броню и потом мораль, если сцена не требует особой детализации.

---

### 1. Когда начинается бой

Бой начинается, если в сцене есть прямая физическая угроза:

1. персонаж атакует;
2. NPC атакует;
3. кто-то достаёт оружие и пытается применить силу;
4. начинается борьба, захват, погоня или попытка удержать;
5. одна сторона пытается причинить вред, а другая сопротивляется;
6. угроза становится немедленной и требует реакции.

Если стороны только угрожают, спорят, держатся за оружие или пытаются давить авторитетом, это ещё не обязательно бой. Это может быть социальный конфликт с риском перехода в бой.

Бой начинается не из-за слова «атакую», а из-за ситуации, в которой физическое насилие стало немедленным и требует обработки последствий.

---

### 2. Что нужно определить перед боем

Перед боевым действием нужно определить:

1. кто участвует;
2. кто кого видит;
3. кто готов к бою;
4. кто застигнут врасплох;
5. дистанцию;
6. оружие и предметы в руках;
7. броню или защиту;
8. состояние тела;
9. нагрузку и занятые руки;
10. свидетелей;
11. право и последствия насилия;
12. возможность отступить, спрятаться, позвать помощь или сдаться.

Короткая формула:

`бой = участники + дистанция + оружие + защита + состояние + место + свидетели + риск`

Если один из элементов неизвестен, LLM не должна автоматически выбирать наиболее удобный вариант. Нужно вывести его из уже зафиксированной сцены, инвентаря, положения персонажей и правдоподобия места.

---

### 3. Боевой ход

Один боевой ход — это короткий отрезок времени, в котором персонаж делает одно значимое действие.

Примеры боевых действий:

1. ударить;
2. выстрелить;
3. уклониться;
4. закрыться щитом;
5. парировать;
6. схватить;
7. повалить;
8. вырваться;
9. отступить;
10. сбежать;
11. достать оружие;
12. поднять предмет;
13. бросить предмет;
14. позвать помощь;
15. запугать;
16. сдаться;
17. прикрыть другого;
18. удержать проход;
19. попытаться обезоружить;
20. добить беспомощного.

Формула времени:

`новое время = старое время + длительность боевого хода`

Обычно один боевой ход занимает секунды или меньше минуты. Точное время важно только для погони, огня, кровотечения, прибытия NPC, закрытия двери, падения, побега или другого отложенного события.

В коротком бою не нужно пересчитывать почасовый расход состояний после каждого удара. Расход Бодрости считается после боя или после заметного затягивания конфликта.

---

### 4. Боевая проверка

Боевая проверка показывает, получилось ли выполнить заявленное действие и насколько сильным оказался результат.

Формула:

`атака = d20 + бонус характеристики + бонус боевого навыка + модификатор состояния + модификатор снаряжения + обстоятельства`

В проверке всегда используется бонус характеристики, а не сырое значение характеристики.

Формула бонуса характеристики:

`бонус характеристики = floor((значение характеристики − 10) / 2)`

Состояние 0–100 не прибавляется к броску напрямую. В формулу попадает только отдельный модификатор состояния: обычно `0`, `−1`, `−2` или `−4`.

Для ближнего боя обычно используются:

`бонус Силы или Ловкости + бонус Ближнего боя`

Для дальнего боя:

`бонус Ловкости или Внимания + бонус Дальнего боя`

Для борьбы, удержания, толчка или повалить:

`бонус Силы или Ловкости + бонус Атлетики / Ближнего боя`

Для запугивания оружием:

`бонус Влияния + бонус Общения`

или, если давление идёт именно через боевую уверенность:

`бонус Влияния + бонус Ближнего боя`

Характеристика выбирается по способу действия:

| Действие | Характеристика |
| --- | --- |
| мощный удар, толчок, захват, удержание | Сила |
| быстрый удар, уклонение, кинжал, манёвр | Ловкость |
| выдержать бой, боль, усталость, кровопотерю | Выносливость |
| выстрелить, выбрать момент, оценить дистанцию | Ловкость или Внимание |
| понять слабое место, оценить тактику | Разум или Внимание |
| запугать, приказать, заставить отступить | Влияние |

Навык выбирается по действию:

| Действие | Навык |
| --- | --- |
| удар, защита вблизи, оружие в руке | Ближний бой |
| стрельба, бросок, оценка дистанции | Дальний бой |
| борьба, захват, толчок, удержание | Атлетика / Ближний бой |
| скрытно достать оружие или ударить из засады | бонус Скрытности + бонус релевантного боевого навыка |
| запугать оружием | Общение / Ближний бой |
| понять запрет, право ношения или риск насилия | Обычай и закон |

---

### 5. Защита цели

Защита цели показывает, насколько трудно провести результативное действие против этой цели прямо сейчас.

Формула:

`защита цели = 10 + защитный бонус цели + активная защита + позиция`

Защитный бонус цели:

`защитный бонус цели = бонус Ловкости или Внимания + бонус релевантного навыка защиты`

Обычно для защиты в ближнем бою используется Ближний бой. Для борьбы — Атлетика или Ближний бой. Для реакции на дальнюю угрозу — Ловкость, Внимание, укрытие и обстоятельства.

Если цель не умеет защищаться, навык не добавляется.

Ориентиры защиты:

| Ситуация | Защита |
| --- | ---: |
| цель беспомощна, связана, спит или не сопротивляется | 5 |
| цель застигнута врасплох | 8 |
| цель видит угрозу, но не готова | 10 |
| обычная защита | `10 + защитный бонус` |
| щит, парирование, укрытие или выгодная позиция | `+2` |
| полная защита вместо атаки | `+4` |
| цель упала, зажата, окружена или ранена | `−2` |
| атака со спины или из засады | `−2…−4` |

Пример:

`обычный человек: защита = 10`

`опытный дружинник: 10 + Ловкость +1 + Ближний бой +3 + щит +2 = 16`

Так защита становится связанной с параметрами персонажа. Обычный человек не превращается в цель со сложностью 15 без причины, а подготовленный боец действительно защищается лучше.

---

### 6. Активная защита

Активная защита — это действие или позиция, которые мешают противнику провести результативный удар.

К активной защите относятся:

1. уклонение;
2. щит в нужный момент;
3. парирование;
4. удержание дистанции;
5. укрытие;
6. выгодная позиция;
7. полная защита вместо атаки;
8. помощь союзника;
9. отступление с сохранением защиты.

Обычная активная защита даёт `+2` к защите цели.

Полная защита даёт `+4`, но персонаж в этот ход не атакует и не выполняет другое сложное действие.

Щит полезен только если персонаж держит его готовым, видит угрозу и может закрыться. Щит не помогает от удара со спины, если персонаж не успел развернуться. Укрытие не помогает после выхода из него. Броня не защищает открытое лицо, кисть или ногу, если удар пришёлся туда.

Один и тот же предмет защиты не должен без причины полностью учитываться дважды. Если щит уже дал активную защиту к защите цели, он снижает вред только если по описанию действительно принял удар.

---

### 7. Итог проверки

После броска считается разница:

`разница = атака − защита цели`

| Разница | Итог | Качество попадания |
| ---: | --- | ---: |
| `−10` и ниже | тяжёлый провал | — |
| `−5…−9` | провал с последствием | — |
| `−1…−4` | слабый результат без серьёзного вреда | 0 |
| `0…+4` | обычное попадание | 1 |
| `+5…+9` | хорошее попадание | 2 |
| `+10…+14` | сильное попадание | 3 |
| `+15` и выше | критическое попадание | 4 |

Результат не обязан быть только «попал / не попал».

Слабый результат `−1…−4` обычно не снимает здоровье. Он может дать давление, вынудить цель отступить, сбить дыхание, испугать, задеть одежду, создать шум, изменить позицию или открыть следующий ход.

Провал не всегда означает, что ничего не произошло. Он может означать потерю равновесия, шум, открытую защиту, повреждение оружия, потерю времени, внимание свидетелей или ухудшение позиции.

Тяжёлый провал создаёт заметную цену: персонаж падает, теряет оружие, открывается под удар, задевает не того, ломает предмет, получает травму от среды или вызывает опасную реакцию NPC.

---

### 8. Вред

Вред — это не только уменьшение здоровья. Вред может создавать активное состояние: рана, кровотечение, хромота, сломанная рука, оглушение, страх, боль, потеря сознания.

Формула вреда:

`балл вреда = качество попадания + опасность оружия + уязвимость − защита брони`

Где:

1. `качество попадания` зависит от разницы броска;
2. `опасность оружия` зависит от типа предмета и способа применения;
3. `уязвимость` зависит от положения цели и места попадания;
4. `защита брони` зависит от брони, щита, одежды, укрытия и положения, если они действительно закрывают угрозу.

Если качество попадания равно `0`, вред обычно не считается как телесная рана, кроме ситуаций, где само действие опасно: падение, огонь, ледяная вода, толпа, лошадь, обвал, ловушка.

---

### 9. Опасность оружия

Оружие не даёт универсальный бонус. Оно определяет доступные действия, дистанцию, риск, социальный смысл и возможный вред.

Опасность показывает не гарантированный урон, а способность предмета причинить вред при успешном применении.

| Опасность | Оружие или ситуация |
| ---: | --- |
| 0 | не оружие, вред только случайно |
| 1 | кулак, лёгкая палка, малый бытовой предмет |
| 2 | нож, дубина, малый топор, камень |
| 3 | боевой топор, копьё, меч, тяжёлая дубина |
| 4 | лук, арбалет, тяжёлое оружие, удар с разгона |
| 5 | добивание, падение, огонь, ледяная вода, удар по беспомощному |

Формула:

`опасность = базовая опасность типа + состояние + способ применения`

Плохое, сломанное, тупое, мокрое, неудобное или неподходящее оружие может:

1. дать `−1` или `−2` к проверке;
2. снизить опасность на `1`;
3. сломаться при провале;
4. стать опасным для самого персонажа;
5. оказаться бесполезным на текущей дистанции.

Оружие не создаётся заявкой игрока. Оно должно быть в руках, на теле, доступно в инвентаре или причинно присутствовать в сцене.

---

### 10. Уязвимость

Уязвимость показывает, насколько ситуация делает попадание опаснее или слабее.

| Ситуация | Модификатор |
| --- | ---: |
| обычное попадание | 0 |
| цель упала, зажата, открыта, без оружия или удар пришёлся в слабое место | +1 |
| беспомощная цель, добивание, удар в опасное место, смертельно опасная ситуация | +2 |
| удар по ситуации не может причинить полноценный вред | −1 |

Уязвимость нельзя добавлять без причины. Она должна вытекать из позиции, дистанции, состояния цели, засады, падения, захвата, отсутствия защиты или явно опасного места попадания.

---

### 11. Броня и снижение вреда

Защита не делает персонажа неуязвимым. В бою нужно различать два слоя:

1. активная защита повышает защиту цели;
2. броня и укрытие уменьшают вред после попадания.

Формула:

`итоговый балл вреда = качество попадания + опасность оружия + уязвимость − защита брони`

Снижение вреда:

| Защита | Значение |
| --- | ---: |
| нет защиты | 0 |
| плотная одежда, мех, частичное укрытие | 1 |
| лёгкая броня, шлем, щит принял удар | 2 |
| хорошая броня, щит и шлем, выгодная позиция | 3 |
| сильная защита или подготовленное укрытие | 4 |

Снижение вреда применяется только если защита действительно закрывает нужную угрозу.

Примеры:

1. щит не снижает вред от удара в спину;
2. шлем не защищает бедро;
3. кольчуга не отменяет перелом от тяжёлого удара, но может снизить разрез;
4. меховая одежда помогает против холода и лёгких ударов, но плохо защищает от копья;
5. укрытие работает только пока персонаж за ним.

Броня может создавать цену:

1. вес;
2. усталость;
3. шум;
4. заметность;
5. подозрение;
6. ограничение входа в некоторые места;
7. штраф к скрытности, бегству, плаванию или лазанию.

---

### 12. Потеря здоровья и активные состояния

Здоровье показывает общий запас тела. Рана показывает конкретную проблему.

Они фиксируются отдельно.

Формула:

`новое здоровье = старое здоровье − потеря здоровья`

Таблица вреда:

| Балл вреда | Последствие | Потеря здоровья | Активное состояние |
| ---: | --- | ---: | --- |
| 0–1 | нет серьёзного вреда | 0 | давление, испуг, сбитое дыхание, царапина |
| 2–3 | лёгкий вред | −5 | лёгкая рана или ушиб, `−1` к связанным действиям |
| 4–5 | средний вред | −12 | средняя рана, `−2`, возможно кровотечение |
| 6–7 | тяжёлый вред | −25 | тяжёлая рана, `−4` или запрет части действий |
| 8+ | критический вред | −45 | критическая рана, потеря сознания или риск смерти |

Активное состояние записывается так:

`активное состояние = место + степень + причина + эффект + условие лечения`

Примеры:

`рана правой руки + средняя + удар топором + −2 к ударам, щиту и работе рукой + нужна перевязка`

`ушиб рёбер + лёгкий + падение + −1 к бегу, борьбе и тяжёлому дыханию + пройдёт после отдыха`

`кровотечение бедра + тяжёлое + копьё + −4 к движению, таймер ухудшения + нужна срочная перевязка`

Потеря здоровья не обязана быть единственным последствием. Один удар может одновременно снизить здоровье, сломать предмет, испугать NPC, вызвать крик свидетелей и изменить доступные действия.

---

### 13. Здоровье, поражение и смерть

Если здоровье выше `20`, персонаж может действовать, но раны и состояния могут давать штрафы.

Если здоровье в диапазоне `1–20`, персонаж в тяжёлом состоянии. Он получает `−2` или `−4` к релевантным действиям, часть действий может стать невозможной.

Если здоровье падает до `0`, персонаж не может нормально действовать. Он падает, теряет сознание, становится беспомощным, не может защищаться или оказывается в смертельной опасности.

Смерть не наступает автоматически от обычного успешного удара. Смерть наступает только при наличии причины:

1. критическая рана без помощи;
2. добивание беспомощного;
3. сильное кровотечение и прошёл таймер;
4. утопление;
5. пожар;
6. мороз;
7. падение с высоты;
8. раздавливание;
9. здоровье `≤ 0`, а сцена не даёт шанса на помощь;
10. иная смертельная среда.

Формула смертельного таймера:

`таймер смерти = причина + время до ухудшения + условие спасения`

Примеры:

`тяжёлое кровотечение → через 5–10 минут −10 здоровья, если не перевязать`

`критическая рана → через 1–5 минут потеря сознания или смерть, если нет помощи`

`ледяная вода → ухудшение каждый короткий интервал, пока персонаж не выбрался и не согрелся`

---

### 14. Состояния в бою

Состояния влияют только там, где это логично.

Рекомендуемые штрафы:

| Значение состояния | Эффект |
| ---: | --- |
| 50–100 | штрафов нет |
| 21–49 | `−1` к релевантным проверкам |
| 1–20 | `−2` к релевантным проверкам, часть действий может быть недоступна |
| 0 | критическое последствие |

Активные состояния могут давать отдельные штрафы:

| Активное состояние | Влияние |
| --- | --- |
| рана руки | удар, удержание, щит, стрельба, ремесло |
| рана ноги | движение, уклонение, бегство, равновесие |
| рана корпуса | борьба, бег, дыхание, выносливость |
| кровотечение | здоровье, страх, слабость, таймер ухудшения |
| оглушение | внимание, защита, координация |
| страх | атака, защита, речь, бегство |
| холод | ловкость пальцев, скорость, выносливость |
| усталость | реакция, защита, бой на износ |
| голод | выносливость, сила, внимание, восстановление |
| болезнь | выносливость, внимание, восстановление |

Если одновременно мешают несколько состояний, не нужно складывать всё бесконечно. Обычно берётся один главный штраф от худшего релевантного состояния. Если ситуация действительно тяжёлая, можно добавить второй штраф, но итоговый штраф состояния обычно не должен быть ниже `−4`.

Формула:

`модификатор состояния = худшее релевантное состояние, обычно 0…−4`

---

### 15. Бодрость и усталость после боя

В коротком бою Бодрость не пересчитывается после каждого удара.

После боя или после заметного затягивания конфликта считается расход:

`расход Бодрости = базовая тяжесть боя + нагрузка + особые условия`

Базовая тяжесть:

| Бой | Расход Бодрости |
| --- | ---: |
| короткая стычка, 1–2 действия | 2 |
| обычная драка | 4 |
| тяжёлый бой, бег, борьба, страх | 6 |
| долгий бой, броня, раны, погоня | 8–10 |

Нагрузка:

| Нагрузка | Модификатор |
| --- | ---: |
| лёгкая | 0 |
| средняя | +1 |
| тяжёлая | +2 |
| предельная | бой почти невозможен |

Особые условия могут добавить `+1…+4`: холод, жара, глубокий снег, грязь, ночь, страх, ранение, бой в воде, бегство, переноска груза или тяжёлый доспех.

Сытость обычно не меняется от короткого боя. Она меняется, если бой стал частью долгой дороги, осады, погони, тяжёлой работы или многочасового напряжения.

---

### 16. Дистанция

Для боя достаточно четырёх дистанций.

| Дистанция | Смысл |
| --- | --- |
| Вплотную | борьба, нож, захват, короткое оружие |
| Ближняя | удар рукой, топором, мечом, копьём |
| Средняя | бросок, короткий выстрел, быстрый рывок |
| Дальняя | лук, арбалет, бегство, укрытие |

Дистанция влияет на возможность действия.

Формула:

`действие возможно = оружие подходит к дистанции`

Если оружие не подходит к дистанции, действие получает штраф или невозможно.

Примеры:

1. копьё неудобно вплотную;
2. нож опасен вплотную, но слаб на средней дистанции;
3. лук требует дистанции, рук, видимости, снаряда и времени;
4. топор опасен вблизи, но мешает в тесной борьбе;
5. щит помогает удержать ближнюю дистанцию и закрыться.

---

### 17. Инициатива без отдельной системы

Отдельная сложная инициатива не нужна. Первым действует тот, кто имеет причинное преимущество.

Порядок определяется так:

1. внезапное действие;
2. готовность к бою;
3. дистанция;
4. оружие в руках;
5. внимание;
6. скорость;
7. состояние;
8. обстоятельства сцены.

Если порядок очевиден, бросок не нужен.

Если порядок неочевиден:

`d20 + бонус Ловкости/Внимания + модификатор состояния + обстоятельства >= сложность реакции`

Или встречная проверка:

`реакция стороны A против реакции стороны B`

Ориентиры:

| Ситуация | Сложность реакции |
| --- | ---: |
| персонаж ждал угрозу | 10 |
| угроза внезапна, но видима | 15 |
| засада, темнота, шум, толпа | 20 |
| почти невозможно успеть | 25 |

---

### 18. Защитные действия

Защита может быть явным действием или частью защиты цели.

Защитные действия:

1. уклониться;
2. закрыться щитом;
3. отступить;
4. спрятаться за укрытие;
5. парировать;
6. удержать дистанцию;
7. принять удар на броню;
8. позвать помощь;
9. сдаться;
10. бежать;
11. прикрыть другого.

Если персонаж заранее защищается, атака по нему сложнее.

Формула:

`защита цели = 10 + защитный бонус + активная защита + позиция`

Если персонаж полностью уходит в защиту, он получает `+4`, но не атакует и не выполняет сложное действие в этот ход.

Если персонаж пытается одновременно атаковать, отступать, прикрывать союзника, держать дверь и доставать предмет, LLM должна выбрать главное действие, а остальное дать как штраф, риск или неполный результат.

---

### 19. Борьба и захват

Борьба используется, когда цель пытаются удержать, повалить, обезоружить, связать, заткнуть рот, вытолкнуть или не дать уйти.

Формула:

`d20 + бонус Силы/Ловкости + бонус Атлетики/Ближнего боя + модификатор состояния + обстоятельства >= защита цели`

Или встречная проверка:

`проверка захвата против проверки сопротивления`

Для сопротивления используются:

`бонус Силы + бонус Атлетики`

или:

`бонус Ловкости + бонус Атлетики/Ближнего боя`

Возможные результаты:

1. не удалось схватить;
2. частичный захват;
3. полный захват;
4. цель упала;
5. оружие выбито;
6. обе стороны падают;
7. шум и внимание свидетелей;
8. травма от падения;
9. переход в удержание;
10. цель вырывается, но теряет предмет или позицию.

Борьба редко должна сразу наносить большой вред, если нет падения, оружия, удушения, огня, воды, копыт, высоты или другой опасной среды.

---

### 20. Дальний бой

Дальний бой возможен, если есть оружие, снаряд, линия видимости, дистанция и возможность выстрела или броска.

Формула:

`d20 + бонус Ловкости/Внимания + бонус Дальнего боя + модификатор состояния + модификатор снаряжения + обстоятельства >= защита цели`

Нужно проверить:

1. есть ли само оружие;
2. есть ли снаряды;
3. есть ли линия видимости;
4. подходит ли дистанция;
5. есть ли время подготовиться;
6. свободны ли руки;
7. не мешают ли погода, толпа, темнота, страх или усталость;
8. есть ли риск попасть не в того.

Что повышает защиту цели или даёт штраф стрелку:

1. дальность;
2. движение цели;
3. плохой свет;
4. туман, дождь, снег, ветер;
5. укрытие;
6. спешка;
7. толпа;
8. страх попасть не в того;
9. плохое состояние оружия;
10. мокрая или повреждённая тетива;
11. недостаток места для выстрела.

Промах в толпе или тесной сцене может создать отдельный риск: попасть в другого, выдать себя, сломать предмет, вызвать панику или начать конфликт с третьей стороной.

Снаряды считаются расходуемыми предметами.

Формула:

`остаток снарядов = старый остаток − использованные + найденные/купленные/подобранные`

---

### 21. Оружие, доступность и занятые руки

Оружие в инвентаре не всегда готово к применению.

| Положение | Доступ |
| --- | --- |
| в руках | можно использовать сразу |
| за поясом / на ремне | можно быстро достать |
| в верхнем мешке | нужно короткое действие |
| глубоко в мешке | нужно время на поиск |
| в закрытом контейнере | сначала открыть контейнер |
| не при персонаже | нельзя использовать сейчас |
| у другого держателя | нужно попросить, отнять, купить или украсть |

Формула:

`готовность оружия = положение + занятые руки + состояние + условия сцены`

Занятые руки:

`доступные руки = 2 − занятые руки`

Примеры:

| Предмет | Руки |
| --- | ---: |
| нож, малое оружие, факел | 1 |
| щит | 1 |
| одноручное оружие | 1 |
| двуручное оружие | 2 |
| лук / арбалет при стрельбе | 2 |
| повод, мешок, сундук, раненый | 1–2 по ситуации |

Если обе руки заняты, персонаж не может нормально держать щит, стрелять, лазать, лечить, вскрывать, хватать и быстро доставать предметы.

Оружие в одной руке и щит в другой — допустимая боевая конфигурация, но она оставляет `0` свободных рук.

---

### 22. Вес и нагрузка в бою

Боевой предмет всегда влияет на вес, если персонаж несёт его при себе.

Формула:

`общий вес = вес оружия + вес брони + вес щита + вес снарядов + вес прочих вещей`

Коэффициент нагрузки:

`коэффициент нагрузки = общий вес / Сила`

Категории нагрузки:

| Нагрузка | Условие | Эффект |
| --- | --- | --- |
| лёгкая | общий вес `≤ Сила × 2` | штрафов нет |
| средняя | `Сила × 2 < общий вес ≤ Сила × 4` | `−1` к действиям, где вес мешает |
| тяжёлая | `Сила × 4 < общий вес ≤ Сила × 6` | `−2` к движению, скрытности, бегу, уклонению, долгому бою |
| предельная | общий вес около предела | часть действий невозможна |
| сверх предела | общий вес `> Сила × 6` | нужно бросить груз, тащить, волочить или получить помощь |

В бою нагрузка влияет на:

1. уклонение;
2. бегство;
3. скрытность;
4. долгий бой;
5. лазание;
6. плавание;
7. расход Бодрости;
8. скорость реакции;
9. возможность быстро сменить позицию.

Нагрузка не штрафует всё подряд. Она влияет только на действия, где вес реально мешает.

---

### 23. Модификаторы и пределы расчёта

Чтобы бой не разваливался от десятков мелких бонусов, используется ограничение:

`один главный бонус + один главный штраф + состояние`

Обычные пределы:

| Источник | Диапазон |
| --- | ---: |
| снаряжение | `−2…+2` |
| состояние | `0…−4` |
| обстоятельства | `−4…+4` |
| численное давление | `−2…+2` |
| активная защита | `+2` или `+4` к защите цели |

Примеры модификаторов снаряжения:

| Ситуация | Модификатор |
| --- | ---: |
| подходящее снаряжение | +1 |
| хорошее или точное снаряжение | +2 |
| плохое состояние | −1 или −2 |
| неподходящий тип | −1 или невозможно |
| тяжёлое снаряжение мешает | −1 или −2 |
| нет нужного предмета | действие невозможно или сложнее |

Если обстоятельств много, LLM не должна суммировать всё подряд. Нужно выбрать главный фактор сцены.

Пример:

Персонаж атакует в темноте, по грязи, с хорошим оружием, но уставший. Не нужно считать пять отдельных поправок. Достаточно:

`снаряжение +1, обстоятельства −2, состояние −1`

---

### 24. Бой с несколькими участниками

Численное преимущество важно, но не должно превращаться в автоматическую победу.

Простое правило:

`численное давление = количество активных противников вокруг цели`

Эффекты:

| Ситуация | Эффект |
| --- | --- |
| двое против одного | `+1` к атаке группы или `−1` к защите цели |
| трое и больше | `+2` к атаке группы или `−2` к защите цели |
| цель окружена | сложнее отступить и защищаться |
| союзник прикрывает | снижает давление |
| тесное место | численное преимущество может не работать полностью |

Если участников много, не нужно бросать за каждого фонового NPC. Достаточно группового результата сцены.

Пример:

`двое держат, третий бьёт → один бросок главного действия + численное давление + последствия захвата`

Фоновые NPC не должны получать подробную боевую карточку без причины. Если NPC реально вступает в бой, влияет на сцену, запоминает игрока или создаёт последствия, его профиль повышается до сценического или ключевого.

---

### 25. Социальные последствия боя

Насилие почти всегда имеет последствия.

После боя нужно проверить:

1. кто видел;
2. кто услышал;
3. чей порядок нарушен;
4. чья вещь или кровь затронута;
5. кто может пожаловаться;
6. кто будет мстить;
7. кто испугается;
8. кто запомнит;
9. какой слух появится;
10. какое право или обычай нарушены.

Формула:

`социальный риск = свидетели + статус жертвы + значимость места + нарушение права/обычая + заметность насилия − оправдание`

Результат может быть:

1. страх;
2. бегство;
3. крик;
4. вызов старшего;
5. слух;
6. обыск;
7. месть;
8. штраф;
9. изгнание;
10. плен;
11. казнь;
12. долговременная вражда;
13. требование виры, выкупа, компенсации или суда;
14. отказ в ночлеге, торговле или проходе.

Оружие и броня сами по себе могут быть социальным событием. Видимый меч, чужой топор, служебный щит, кровь на одежде или трофей с узнаваемой меткой могут изменить реакцию NPC ещё до начала боя.

---

### 26. NPC в бою

NPC действует по роли, страху, статусу, задаче и состоянию.

NPC не обязан сражаться до смерти. Он может:

1. бежать;
2. звать помощь;
3. закрыться;
4. сдаться;
5. защищать имущество;
6. защищать старшего;
7. удерживать проход;
8. пытаться не убивать;
9. ударить первым;
10. отступить;
11. запомнить игрока;
12. распространить слух;
13. попытаться договориться;
14. бросить оружие;
15. добивать, если жесток, обучен или загнан в крайность.

Формула реакции NPC:

`реакция NPC = роль + страх + долг + состояние + отношение к игроку + риск`

Типичные реакции на вред:

| Вред | Типичная реакция NPC |
| --- | --- |
| лёгкий | злость, испуг, отступление, крик |
| средний | попытка отступить, звать помощь, сдаться, прикрыться |
| тяжёлый | падает, бросает оружие, теряет волю, просит помощи |
| критический | выведен из сцены, без сознания или умирает |

Боевые NPC держатся дольше. Случайные крестьяне, слуги, торговцы, возчики, ремесленники и свидетели почти никогда не дерутся до смерти.

---

### 27. Окончание боя

Бой заканчивается, когда немедленная физическая угроза исчезла.

Варианты окончания:

1. одна сторона убежала;
2. одна сторона сдалась;
3. одна сторона потеряла способность действовать;
4. стороны разошлись;
5. пришли свидетели или власть;
6. бой перешёл в погоню;
7. бой перешёл в разговор;
8. бой перешёл в плен;
9. бой перешёл в лечение;
10. бой перешёл в обыск;
11. бой перешёл в добивание;
12. бой прерван внешним событием.

После боя фиксируются:

1. здоровье;
2. активные состояния;
3. расход Бодрости;
4. повреждённые вещи;
5. потерянные и перемещённые предметы;
6. занятые руки и новое положение оружия;
7. следы крови и борьбы;
8. свидетели;
9. слухи;
10. память NPC;
11. изменение отношений;
12. социальные и правовые последствия;
13. отложенные события.

Формула:

`после боя = тело + предметы + следы + свидетели + слухи + память + последствия`

---

### 28. Лечение после боя

Лечение не отменяет рану сразу. Оно может остановить ухудшение, снизить вред или ускорить восстановление.

Формула:

`d20 + бонус Разума/Внимания + бонус Лечения + модификатор предметов + обстоятельства >= сложность раны`

Ориентиры сложности:

| Рана | Сложность |
| --- | ---: |
| лёгкий порез, ушиб, простая перевязка | 10 |
| средняя рана, кровь, грязь, плохой свет | 15 |
| тяжёлая рана, сильное кровотечение | 20 |
| критическая рана, риск смерти | 25 |
| почти безнадёжно без условий и помощи | 30 |

Результаты:

1. не помогло;
2. остановлено кровотечение;
3. снижено ухудшение;
4. рана стабилизирована;
5. началось восстановление;
6. стало хуже из-за ошибки, грязи или спешки.

Для лечения нужны время, доступ к ране, подходящие предметы, свет и безопасные условия.

Лечение не должно превращать тяжёлую рану в отсутствие раны одной фразой. Оно меняет состояние раны: останавливает кровь, уменьшает риск, даёт шанс восстановиться.

---

### 29. Боевые отложенные события

Некоторые последствия боя срабатывают позже.

Примеры:

1. кровотечение ухудшается через несколько минут;
2. стража приходит на шум;
3. слух расходится к вечеру;
4. NPC возвращается с помощниками;
5. рана воспаляется позже;
6. украденное оружие узнают;
7. место закрывают после драки;
8. родственники жертвы ищут виновного;
9. владелец вещи предъявляет претензию;
10. раненый NPC умирает без помощи.

Формула:

`боевой таймер = причина + время срабатывания + последствие`

`если текущее время >= время срабатывания → последствие срабатывает`

Отложенное событие не создаётся на всякий случай. Нужна причина, время или условие срабатывания и понятное последствие.

### 30. Примеры расчёта

#### Пример 1. Топор против обычного человека

Персонаж: Сила 14 (`+2`), Ближний бой `+2`, топор опасность `3`.

Противник: обычный человек, Ловкость 10 (`+0`), боевого навыка нет, защиты нет.

`атака = d20 + 2 + 2`

`защита цели = 10`

Игрок выбросил `9`.

`атака = 13`

`разница = 13 − 10 = +3`

`качество попадания = 1`

`балл вреда = 1 + 3 + 0 − 0 = 4`

Итог: средний вред, `−12 здоровья`, активное состояние `рубленая рана`, `−2` к действиям, где боль и кровь мешают.

#### Пример 2. Тот же удар против дружинника

Противник: Ловкость 12 (`+1`), Ближний бой `+3`, щит `+2`, лёгкая броня `2`.

`защита цели = 10 + 1 + 3 + 2 = 16`

Игрок выбросил `14`.

`атака = 18`

`разница = 18 − 16 = +2`

`качество попадания = 1`

`балл вреда = 1 + 3 − 2 = 2`

Итог: лёгкий вред, `−5 здоровья`, ушиб, сбитое дыхание или порез через защиту. Тот же персонаж опасен против беззащитного, но плохо пробивает подготовленного бойца.

#### Пример 3. Захват в тесном месте

Персонаж пытается схватить бегущего NPC.

Персонаж: Сила 13 (`+1`), Атлетика `+2`.

NPC: Ловкость 12 (`+1`), Атлетика `+1`, усталость `−1`.

`атака захвата = d20 + 1 + 2`

`защита NPC = 10 + 1 + 1 − 1 = 11`

Игрок выбросил `8`.

`атака = 11`

`разница = 0`

Итог: обычный успех. Персонаж схватил NPC, но ещё не повалил и не связал. Следующий ход решит, удержит ли он захват.

#### Пример 4. Стрельба в толпе

Персонаж стреляет по цели на средней дистанции в сумерках.

`атака = d20 + бонус Ловкости/Внимания + бонус Дальнего боя + модификатор состояния + модификатор снаряжения + обстоятельства`

Обстоятельства: сумерки и толпа дают главный штраф `−2`. Хороший лук даёт `+1`. Усталость даёт `−1`.

Если бросок провален на `−5…−9`, это не просто промах. Стрела может попасть в чужой предмет, ранить не того, вызвать крик, панику или обвинение.

### 31. Что нельзя делать

В бою нельзя:

1. считать заявку игрока автоматическим успехом;
2. создавать оружие, защиту или выход без основания;
3. игнорировать состояние тела;
4. игнорировать вес, занятые руки и доступность оружия;
5. игнорировать свидетелей и право;
6. делать NPC всезнающими или бесстрашными;
7. заставлять всех NPC драться до смерти;
8. превращать успех в отмену физики;
9. лечить тяжёлую рану одной фразой;
10. скрывать от игрока ощутимые последствия тела;
11. раскрывать скрытые мотивы NPC через рассказчика;
12. перегенерировать предметы после боя;
13. складывать бесконечные модификаторы;
14. применять броню, щит или укрытие там, где они не закрывают угрозу;
15. убивать персонажа обычным успехом без смертельной причины;
16. забывать социальные последствия насилия;
17. превращать бой в обмен одинаковыми ударами без изменения сцены.

### 32. Короткие формулы

`бой = участники + дистанция + оружие + защита + состояние + место + свидетели + риск`

`атака = d20 + бонус характеристики + бонус боевого навыка + модификатор состояния + модификатор снаряжения + обстоятельства`

`бонус характеристики = floor((значение характеристики − 10) / 2)`

`защита цели = 10 + защитный бонус цели + активная защита + позиция`

`защитный бонус = бонус Ловкости/Внимания + бонус релевантного навыка защиты`

`разница = атака − защита цели`

`качество попадания = 0 / 1 / 2 / 3 / 4 по разнице`

`балл вреда = качество попадания + опасность оружия + уязвимость − защита брони`

`новое здоровье = старое здоровье − потеря здоровья`

`активное состояние = место + степень + причина + эффект + лечение`

`расход Бодрости после боя = тяжесть боя + нагрузка + особые условия`

`готовность оружия = положение + занятые руки + состояние + условия сцены`

`доступные руки = 2 − занятые руки`

`общий вес = вес оружия + вес брони + вес щита + вес снарядов + вес прочих вещей`

`коэффициент нагрузки = общий вес / Сила`

`социальный риск = свидетели + статус жертвы + значимость места + нарушение права/обычая + заметность насилия − оправдание`

`реакция NPC = роль + страх + долг + состояние + отношение + риск`

`после боя = тело + предметы + следы + свидетели + слухи + память + последствия`

---

### 33. Главное правило

Бой должен быть коротким, опасным, причинным и связанным с миром.

Победа в проверке не отменяет тело, страх, кровь, закон, свидетелей, усталость, оружие, вес, погоду, место и дальнейшие последствия.

Система должна давать LLM понятный числовой позвоночник:

`параметры персонажа → шанс действия → качество успеха → вред → состояние → последствия`

LLM описывает сцену, но не импровизирует базовую математику каждый раз заново.
