# Stage 9 — start-node-selection

Этап формирует кодом конечный набор команд из candidate set Stages 5–8. При единственном варианте код выбирает его без LLM; при нескольких LLM возвращает только подписанный `bounded_decision_result_v2`. Полный `selected_start_node` строит и проверяет код. Этап не создаёт места, NPC, предметы, маршруты, G5-якоря или прозу.
