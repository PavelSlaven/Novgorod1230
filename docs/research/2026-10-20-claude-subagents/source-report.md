# Стенд субагентов: Sonnet 5.5 high против Haiku 5.5 high (2026-10-20)

Вопрос владельца: какая модель выгоднее для субагентов, которые пишут код и ведут разведку. У обеих моделей effort high.

## Постановка

- **Задания.** Семь заданий, по 3 прогона на каждую модель: всего 42 прогона, плюс 3 перезапуска (см. «Сбои»).
  - **Код:**
    - K1 — найти по данным причину ложного красного в хуке token-guard, исправить её и написать тест (эталон T1 старого стенда);
    - K2 — пять точечных правок в срезе P3 (эталон T4);
    - K3 — бюджеты входа шести ролей P3 под окно 64k: env-лимиты, проверка, запечатанный пакет;
    - K4 — `localGitProvenance` с номером открытого PR, который указывает ровно на HEAD.
  - **Разведка, только чтение, каждый факт со ссылкой `путь:строка`:**
    - R1 — всё о `resolveLlmExecutionConfig`;
    - R2 — родное автосохранение CDDA;
    - R3 — путь реплики игрока к NPC в P3.
- **Как запускали.** Каждый прогон — отдельный агент Workflow с явными `model` и `effort: high`. Кандидат работал сам, без помощников, в своей рабочей копии.
- **Скрытые тесты в K3 и K4.** Это тесты из настоящего коммита-исправления. Кандидаты их не видели. Проверено заранее: база их не проходит, эталонное исправление проходит.
- **Проверки скриптом:**
  - собственные тесты кандидата;
  - скрытые тесты;
  - в K1 — тест кандидата на старом хуке: он обязан падать;
  - правки только в разрешённых файлах;
  - ссылки разведчиков: файл существует, строка в пределах файла, рядом текст строки для судьи;
  - длина ответа;
  - git-история и чужие папки: нарушений нет;
  - разведчики ничего не записали: снимок CDDA совпал по контрольной сумме, дерево git чистое, рабочая копия владельца не тронута.
- **Судейство — только Opus (D225), слепое, по кодам.**
  - На каждое задание два судьи: xhigh в прямом порядке и high в обратном.
  - Ключи для разведки составил Opus xhigh, проверил по исходникам Opus high.
  - Код K3/K4: 7 баллов из 10 — скрипт по скрытым тестам и рамкам, 3 балла — судья (корректность сверх тестов, качество тестов, честность ответа, правило комментариев).
  - Остальные задания — по эталону, все приведены к шкале /10.
  - Расхождение двух судей нигде не превысило 2 баллов из 10. В K2 судьи совпали до четверти балла у всех шести кандидатов.
- **Стоимость.** По токенам из транскриптов и прайсу API ([pricing](https://platform.claude.com/docs/en/about-claude/pricing), 2026-10-20):
  - Sonnet 5.5 — $2 / $10 за млн токенов вход/выход;
  - Haiku 5.5 — $0.10 / $0.50 до 100K токенов промпта и $0.50 / $2.50 выше;
  - кэш учтён отдельно (запись 5 мин / 1 ч, чтение).

## Что видно

- **Качество одинаковое.** Разница средних — 0.01 в коде и 0.1 в разведке, это меньше разброса между прогонами одной модели. Ни на одном задании одна модель не обходит другую больше чем на 0.5.
- **Haiku дешевле:**
  - в коде в 3.8 раза — $0.11 против $0.42 за прогон;
  - в разведке в 4.7 раза — $0.06 против $0.30;
  - от 2.3 раза (K1) до 10–12 раз (R2, K4).
  - Haiku тратит больше токенов: вывода в 2–4 раза больше, контекст дорастает до 135K, и часть запросов идёт по верхней ставке выше 100K. Цена это уже учитывает.
- **Sonnet быстрее**, в среднем в 1.5 раза: 1.7 мин против 2.6 в коде, 1.1 против 1.8 в разведке. На K1 разрыв в 2.8 раза.
- **Haiku держит рамку ответа, Sonnet многословен.** Лимит длины ответа превысил 11 прогонов Sonnet из 21: K1 трижды, K3 один раз, разведка семь раз — до 61 строки при лимите 40. У Haiku таких нет. Судьи за это снимали 0.25–0.5.
- **Типичные ошибки у обеих моделей одни и те же:**
  - K1 — тест на «настоящий сброс» ничего не проверяет: мутант его проходит;
  - K2 — хвост раздела STOP в документе остался устаревшим;
  - K4 — существующий тест занятого порта ходит в настоящий gh.
  - Единственный неверный фикс K1 — у одного прогона Sonnet: ложный красный возвращается на тех же данных. У Haiku в одном прогоне фикс шире минимального и есть неверное утверждение о причине.

## Сбои

- **Ошибка в моей вводной.** Она запрещала открывать `.claude/projects`, а файл задания лежал именно там.
  - Sonnet во всех 21 прогоне понял, что файл задания — исключение, и работал.
  - Haiku в 3 прогонах из 21 остановился, все три — задания с кодом (K1 один раз, K4 дважды). Задание он не выполнил, а ответил на вопрос владельца о выборе модели и попросил уточнить путь.
  - Эти три прогона перезапущены с исправленной вводной и выполнили задание; в таблицах — перезапуски. Первые попытки стоили $0.005 каждая.
- **Вывод:** на противоречивом брифе Haiku чаще останавливается или уходит в сторону, Sonnet разрешает противоречие сам. Остановка дешёвая и сразу видна, но координатор должен проверить итог и перезапустить.
- **Побочное наблюдение.** Агент Workflow видел вопрос владельца из основной сессии. Это видно по его ответу: «Ревью только Opus, принято». Значит, кандидат стенда может знать, что его сравнивают.

## Рекомендация

- **Код по чёткому брифу с тестами — Haiku high.** Качество то же, цена в ~4 раза ниже, рамку ответа держит лучше. Условия: бриф без противоречий и проверяемый итог (тесты, diff), которые координатор смотрит сам; остановился или ушёл в сторону — перезапуск или Sonnet.
- **Разведка — Haiku high.** Качество то же, цена в ~5 раз ниже. Ссылки `путь:строка` у Haiku не хуже, чем у Sonnet.
- **Sonnet high:**
  - когда важна скорость — быстрее в 1.5 раза;
  - когда бриф неизбежно неполон или противоречив;
  - когда исполнителю нужно самому решать по смыслу за пределами спецификации. Это стенд не проверял.
- **Ревью и судейство — Opus (D225).** Прошлый стенд показал, что Sonnet и Haiku в ревью кода слабы.

## Ограничения

- **Задания чёткие и с тестами**, поэтому у обеих моделей потолок 9–10 в K3 и K4. На размытых заданиях разница может проявиться. Прошлый стенд (T1–T4) говорил о том же: Haiku medium был вровень с Sonnet high.
- **n = 3 на ячейку.** Различия меньше ~0.5 балла — шум.
- **Цены — по прайсу API.** В подписке Claude Code лимиты расходуются по своим правилам, соотношение между моделями там я не проверял.
- **В шкале K1 пункты дают в сумме 11, а не 10.** Один судья нормировал балл сам, другой — нет. Сводка приводит оба к сырому баллу /11 и потом к /10.
- **Стоимость самого стенда:**
  - кандидаты: Sonnet $7.76, Haiku $1.92;
  - ключи разведки (Opus): $11.54;
  - судьи (Opus): $14.98.
