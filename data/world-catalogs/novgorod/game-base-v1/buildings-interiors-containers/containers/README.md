## Правила

- **Ёмкость**: `capacity_slots` берётся из v5 `container_templates.capacity`, если у формы есть близнец v5; иначе — от ближайшей формы v5, названной в `capacity_basis`. Полоса: tiny ≤2, small ≤4, medium ≤12, large ≤24, bulk >24. Расхождение: v5 даёт ларцу 24 слота, matcult — 20–50 см; взято 4, отмечено в notes.
- **FREQ_RULE для содержимого**: ubiquitous — предмет обязателен в сцене matcult этого места; common — содержимое этой ёмкости/места прямо названо источником A/B (например, амбары: зерно, меха, воск, ткани — nov1230db B031; бочка солёной рыбы TRD0005; «горшок масла» в грамоте № 718); contextual — названо только черновым/кандидатным источником (rus13tpl, MASTER spawn) или C; rare — только совместимость v5 и функция места.
- **place_containers**: ubiquitous — форма обязательна в ≥50% сцен семейства; common — обязательна хотя бы в одной; contextual — только допустима в сцене или названа в spawn-профиле MASTER. Третий источник присутствия (исправление 2026-09-26): для каждого `content_profiles` профиля форма считается присутствующей в каждом из его `pf_ids` (кроме `*` — носимое, не привязано к семейству места) с классом = максимальный `frequency_class` среди его записей содержимого; `basis_ref` = `content_profile:<cp_id>`. Это закрывает пробелы покрытия для форм без сцены/spawn-совпадения (поленница, закром, ясли и т.п.) и добавляет `peasant_homestead`. MASTER-профили берут только `canonical_existing_item_ids` (не `context_anchor_item_ids`, который называет само место/постройку, например ARC0026 — сам погреб, а не предмет в нём) и не проецируют архетип `church` из профилей, где также стоит `construction_site` (там перечислены строительные инструменты стройки, а не обычное убранство готовой церкви).
- **D3, первое открытие** (`first_open_rule.json`): содержимое разыгрывается кодом один раз при первом открытии экземпляра, по seed (партия, экземпляр, период сезона при `per_season`), без LLM; пустота конкурирует как исход веса 1; запись включается с вероятностью weight/8; количество равномерно в [min, max] и обрезается ёмкостью; результат сохраняется как факт партии, переброса нет. Модификатор голода 1230–1231: пищевые категории опускаются на класс (nov1230db S01, B031, famine_prices; matcult SCN060). Владелец содержимого — владелец ёмкости (D14).

## Приёмка (validate.py)

- каждая запись содержимого — категория из словаря, входит в `compatible` формы, не в `forbidden_content`, и не запрещена отношением v5 `container_content_category_relations`;
- qty_max ≤ capacity_slots, qty_min ≤ qty_max; вес соответствует классу;
- у каждой формы из сцен интерьера и из `place_containers` есть ≥1 профиль (фактически профиль есть у всех 55 форм);
- все v5 категории форм и ссылки rus13tpl существуют.

## Известные пробелы

- 14 категорий содержимого предложены (`origin=proposed`) — нужно решение по `category_registry`.
- Ушат и корчага — C: отдельных находок в собранных данных нет (ушат по поздней этнографии; корчага — через амфору FOD0056). Проверить по Колчину 1968.
- Зерновые ямы как хранилище 1230 г. источниками группы не подтверждены — не включены.
- Большинство профилей жилища — contextual (основание rus13tpl/MASTER, draft/кандидат); прямых археологических данных о содержимом конкретных сундуков нет.
- Массы ёмкостей не заданы (в v5 есть mass_grams для 18 форм — не переносились, это домен category_parameters).
- В v17 записей содержимого 4 — нужна загрузка через импортёр item-container после утверждения.
