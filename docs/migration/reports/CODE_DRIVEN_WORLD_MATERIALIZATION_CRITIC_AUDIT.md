# Аудит перехода к кодовой материализации мира

**Результат:** PASS
**Дата:** 2026-07-14
**Область:** нормативы, runtime-материализация, DDL, JSON Schema, контракты новой игры и базового хода

## Решение

Агент-критик подтвердил, что блокирующие замечания устранены. После PASS документы получили итоговый статус:

- `CODE_DRIVEN_WORLD_MATERIALIZATION_ARCHITECTURE.md` — canonical normative и высший норматив по материализации и разделению ответственности кода/LLM;
- `WORLD_BASE_MATERIALIZATION_TABLE_REQUIREMENTS.md` — active technical normative по назначению, наполнению и развитию базы;
- `infra/world-base/schema.sql` и `infra/world-base/schema/*.sql` остаются исполняемым источником физической схемы;
- `infra/world-base/SCHEMA_REFERENCE.md` остаётся автоматически создаваемым справочником текущего DDL.

## Проверенные блокирующие условия

- Код не изобретает категории, исторические факты и отсутствующие варианты.
- Конкретные G5, NPC, предметы, контейнеры, размещение и владение материализуются только из утверждённых, version-pinned данных.
- Stage 13 проверяет точные G4 type/revision/region/period/season до candidate digest и RNG.
- Stage 15 и Stage 16 отклоняют кандидатов без явной временной и региональной применимости.
- LLM принимает только ограниченные решения из формального набора команд и не исправляет скрытую семантику или write plan.
- Autonomous update связан с точным снимком party state, разрешёнными таблицами, D-013 pins и code-owned seal.
- Party write set проверяется до атомарной транзакции; rollback и повторяемость покрыты тестами.
