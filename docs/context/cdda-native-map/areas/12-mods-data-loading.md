## 2. Родные механизмы области, которых наши документы не упомянули

- Порядок и зависимости модов: `MOD_INFO.dependencies` / `conflicts` / `core` / `obsolete` / `category` / `path` / `loading_images` — mod_manager.h:32-73; дерево зависимостей `dependency_tree`, `mod_manager::get_tree` (mod_manager.cpp:167); циклы зависимостей ловятся (`dependency_node::check_cyclicity` dependency_tree.cpp:62, `check_for_strongly_connected_components` :365), мод с ошибкой недоступен (`is_available` :42). Поле `core:true` + `path` позволяет мод-ядро без `dda` (`data/mods/dda/modinfo.json`: `"core": true, "path": "../../json"`); без ядра игра подставляет `dda` (game_io.cpp:522-526).
