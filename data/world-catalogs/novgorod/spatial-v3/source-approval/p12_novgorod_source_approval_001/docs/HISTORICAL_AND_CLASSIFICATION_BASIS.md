# Historical and scientific classification basis

The package does not add new named settlements, exact medieval polygons, precise channel geometry, owners, institutions or structures. It performs a level migration of already reviewed functional reconstruction data.

The approved-local G1 dossier describes the cell as a topological and functional reconstruction of a lower-river/estuary system. Exact channel and shoreline geometry for 1230 is explicitly not asserted. The transformed records preserve `evidence_status`, `reconstruction_method`, source IDs and claim IDs from each source row.

The target classification follows scale rather than labels:

- G3 remains a persistent concrete place;
- target G4 is the sector scope that owns traversal and canonical/generated G5;
- a legacy local zone with no independent internal spaces becomes a canonical G5 parcel;
- physical connections retain source topology and season/evidence metadata;
- scene templates are topological only and do not create buildings, quays, boats, NPCs, items or hidden resources.

This is consistent with the project rule that reconstruction may model functional spatial structure but must not present uncertain geometry or unrecorded particulars as directly attested facts.
